# 盘中 4h 买入模型 · 首版样本外报告

- 日期：2026-11-08
- 数据：`l2_min1` 分钟表 + 多时点特征（2024-01 ~ 2026-10，683 天）
- 模型：LightGBM，105 特征，截面 rank 标签
- 样本外：2026-01 ~ 2026-10（193 个交易日）

---

## 1. 一句话结论

**信号是真的，但还没到能直接上实盘的强度。**
模型有稳定的横截面排序能力（IC 0.081，安慰剂 0，规模/价格中性化后仍 0.054），
但 Top50 组合扣 0.25% 成本后每 4 小时只剩 **+0.097%**，且月度 IC 不稳（6 月为负）。
当前定位：**候选池排序器 / 过滤器**，不是独立策略。

## 2. 口径与切分

| 项 | 值 |
|---|---|
| 样本 | `(date, symbol, cutoff)`，cutoff ∈ {10:30, 11:30, 13:30, 14:30, 14:50} |
| 标签 | `ret_4h` = 下一交易日同一 cutoff 的价格 / 当前价 − 1（240 交易分钟，含隔夜），取截面分位，预测 `rank_4h - 0.5` |
| 特征 | 45 个分钟特征（价量/10 档盘口/逐笔成交/委托聚合）+ 58 个前一日日频上下文 + 当日累计涨幅 + 时点 |
| 过滤 | 剔除涨停封板（卖一无货）、停牌、次新（<60 日）；`label_ok` 限定标签在 ±35% 内 |
| 切分 | 训练 2024-01 ~ 2025-06（359 天）；验证 2025-07 ~ 2025-12（122 天）；测试 2026-01 ~ 2026-10（193 天）；两段交界各丢 4 个交易日（embargo） |
| 训练量 | 452 万行（50% 抽样），验证 312 万，测试 497 万 |

## 4. 前视审计（三道）

| 审计 | 结果 | 结论 |
|---|---|---|
| **安慰剂**：打乱训练标签重训 | IC = **−0.0004**（std 0.070，n=100） | 链路无泄漏 |
| **规模/价格中性化**：对 log(px)、log(流通市值) 截面回归取残差 | IC 从 0.060 → **0.054** | 不是市值/低价 beta |
| **面板口径**：昨收改用未复权日线（因子表 close 是后复权） | Top50 从 1.37% → 0.35% | 修复前的高收益是口径 bug |

特征重要性前 10：`concept_momentum_top3`、`concept_rotation_score`、`ret_open`、`mom_ret_1d`、`mom_ret_20d`、`ind_dispersion_20`、`mom_ret_5d`、`vol_std_20`、`mom_ret_3d`、`mom_ma_gap_5`。
—— 日频上下文（概念动量/行业离散度）贡献最大，L2 分钟特征（`vol_30m`、`ret_5m`、盘口）次之。

## 5. 成本敏感性（Top50，全时点）

| 单边成本假设 | 每 4h 净收益 |
|---|---:|
| 0.05% | +0.247% |
| 0.075% | +0.197% |
| **0.125%（当前保守假设）** | **+0.097%** |
| 0.2% | −0.053% |

> 结论：**成本是生死线**。L2 盘口执行若能压到单边 0.05-0.075%，策略才有肉；按散户滑点 0.2%，直接归零。

---

## 6. 局限与下一步

1. **月度不稳**：6 月失效、2/4/5 月弱。需要状态过滤（市场 regime、波动率）或集成。
2. **信号主要来自日频上下文**：分钟特征贡献次之；下一步应加强 L2 微观特征（盘口撤单、大单冲击、订单流不平衡的分钟变化率）。
3. **卖出模型未接**：当前按 4h 固定持有；接分钟卖出模型后，实际收益曲线可能改善也可能恶化，必须端到端对比。
4. **5h 标签未评**：面板已带 `ret_5h`，下一步对照。
5. **组合层**：更现实的做法是把本模型当**候选池排序器**，与现有策略（xg/ML7/14:50）叠加，而不是独立满仓。

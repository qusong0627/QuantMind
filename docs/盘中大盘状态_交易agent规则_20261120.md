# 盘中大盘状态规则（交易 agent 使用）

> 版本：2026-11-20　适用：盘中交易 agent / 决策轮 / 人工盯盘
> 研究依据：2016-2026 日频 + 2017-2026 分钟扫描（l2_min1，每 4 个交易日抽样 397 天）
> 结论一句话：**「没护住」不是卖出信号，是超跌信号；唯一稳定的偏空信号是「降温成功」；盘中 10:30/11:30 顺势，不逆势抄底。**

## 一、三个数（每天/盘中都能算）

1. **真实指数**：该市场成分内按前一日流通市值排序，剔除前 20% 权重股，剩余按流通市值加权（或等权）。
2. **裂口** = 官方指数涨跌 − 真实指数涨跌。
3. **篮子** = 被剔除的前 20% 权重股等权涨跌；**广度** = 下跌个股占比。

## 二、状态判定

| 状态 | 条件 | 含义 |
|------|------|------|
| 强护盘 | 裂口 ≥ +1.0% 且真实指数跌 | 权重硬托 |
| 护盘 | 裂口 ≥ +0.4% 且真实指数跌 | 权重相对抗跌 |
| 强降温 | 裂口 ≤ -1.0% 且真实指数涨 | 权重硬压 |
| 降温 | 裂口 ≤ -0.3% 且真实指数涨 | 权重相对滞后 |
| 中性 | 其余 | — |

子状态：
- 护盘成功 = 护盘 且 篮子涨；护盘失败 = 护盘 且 篮子也跌。
- 降温成功 = 降温 且 篮子跌；降温失败 = 降温 且 篮子还涨。

## 三、历史规律（agent 必须按这个用）

1. **护盘失败（权重股也跌）不是继续跌信号**：2016-2026 护盘失败后 5 日官方 +0.52%（t=2.7）、为负仅 41%；护盘成功 +0.38%（t=1.5）、为负 43%。失败组不比成功组差。
2. 篮子小跌（-1%~0%）的护盘日：未来 5 日 +0.69%（t=3.2），为负仅 36%——历史最好一档，属超跌。
3. 连续 2 天护盘失败：未来 5 日 +0.69%（n=16）；连续 3 天以上历史仅 2 次，样本不足。
4. 「托不住后指数补跌」的转折形态：未来 5 日 +0.19%~+0.35%，不显著，为负仅 27–35%。
5. **唯一稳定偏空 = 降温成功**（指数涨、权重被压）：未来 5 日官方 -0.26%（t=-1.6）、个股 -0.34%（t=-1.8）、57% 为负。
6. **盘中动量**：10:30/11:30 真实指数 > +1% → 下午剩余 +0.30%（t=3.3）、次日 +0.29%（t=2.0）；< -1% → 下午 -0.05%（不显著）、次日 +0.25%。逐年 corr 8 年里 7 年为正。
7. **不要用「早盘跌→下午反弹」**：该关系只在 2026-06~11 出现（corr -0.24），2017-2026 全历史是盘中延续（10:30 真实 vs 下午剩余，2024 +0.31、2025 +0.38、2026 +0.22）。
8. 裂口、30 分钟涨跌速与下午剩余的相关逐年变号，**不稳定，别单独当预测**。

## 四、agent 行为规则

### 盘中（10:30 / 11:30 检查一次）

| 看到 | 动作 |
|------|------|
| 真实指数 > +1% | 顺势：下午偏强，不逆势做空/不轻易减仓 |
| 真实指数 -1% ~ +1% | 中性：按个股与持仓逻辑，不用大盘信号 |
| 真实指数 < -1% | 下午不追空、不恐慌割肉；次日偏反弹（+0.25%），等次日修复 |
| 裂口大（权重托）+ 真实跌 + 篮子也跌 | 视为「护盘失败/超跌」，不追空；等反弹或次日 |
| 裂口负（权重被压）+ 真实涨 + 篮子跌 | 视为「降温成功」，**减仓/不追高**，5 日偏空 |

### 收盘后

- 记录当日状态（护盘/降温/中性 + 成功/失败），作为次日盘前参考。
- 若连续多日「护盘失败 + 真实指数持续下跌」，且**护盘篮子与指数同步下跌、指数开始补跌**，才升级为防守（2018 型失效）。

### 禁止

- 禁止把「护盘失败」当卖出信号。
- 禁止把「早盘跌幅」当下午反弹的买入依据（除 2026-06~11 特例，且需其他证据）。
- 禁止在缺少真实指数数据时用「指数涨跌」替代——指数会被权重扭曲，必须用剔除后的真实指数。

## 五、数据来源与实现

- 日频：QuantDB `daily_unadjusted`（原始价，分钟线同口径）+ `l1_factors.fun_float_mv`（前一日流通市值）+ `index_daily`。
  - **注意：l2_min1 分钟线是原始价，前收必须用 daily_unadjusted；用 qfq 的 daily_forward 会在 2024 年产生 11–16% 假收益。**
- 盘中：`l2_min1`（分钟线，2017-01 至 2026-11-17，2020–21 有缺失）或实时快照（热集 604 只近似）。
- 决策轮提示词：`backend/services/trade/services/decision_round_blocks.py` 的 `MARKET_STATE_RULES`，挂在【盘中市场状态】块后。
- 研究脚本（未提交）：`data/tmp/true_index_probe.py`、`stock_level_probe.py`、`national_team_probe.py`、`support_failure_probe.py`、`intraday_scan_probe.py`、`intraday_momentum_probe.py`。

## 六、限制

- 日频结论 2016–2026；盘中扫描为每 4 个交易日抽样（397 天），不是逐日全量。
- 2020–2021 分钟分区部分缺失。
- 前瞻窗口重叠，t 值偏乐观；未计交易成本。
- 2026 年 10–11 月是「护盘/反转信号连续失效」的持续下跌段，任何均值回归信号在该段都会失效——防守以「护盘篮子 + 指数补跌」为准。

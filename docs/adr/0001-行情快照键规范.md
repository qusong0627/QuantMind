# ADR-0001 行情快照键规范（Redis）

- 状态：已采纳（既成事实回填，2026-08 起）
- 背景：快照/时序被 stream 读、TDX Feed 写、模拟撮合/实盘预检/账户重估读，多写多读需硬契约。
- 决定：`market:snapshot:{前缀小写}`（Hash，字段 Now/Open/PreClose/High/Low/Volume/Amount/
  五档 bid1-5/ask1-5/bid_vol1-5/ask_vol1-5/timestamp/source，TTL 300s）+
  `market:series:{前缀大写}`（ZSET，score=ts，成员 JSON 含 price/is_stale/source，保留 6000 点，
  TTL 2 天）。写入方必须带 `source`（tdx_bridge/tdx_aidata_sub/qmt_big/tdx）；消费方按
  `shared/freshness` 分级使用，禁止裸读不看时间戳。
- 后果：多源可并存（席位语义区分主备）；键名大小写差异是刻意的（兼容既有消费方），改动=破坏性。

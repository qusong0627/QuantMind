# ADR-0002 股票代码分层口径（禁止跨层混用）

- 状态：已采纳（既成事实回填）
- 背景：QuantDB parquet/Qlib 用后缀式（600036.SH / qlib 小写 sh600036），PG/Redis 键/前端/
  大多数 API 用前缀式（SH600036），engine_signal_scores/特征快照用纯数字（600036）——
  错层会**静默查空**。
- 决定：转换唯一入口 `shared/stock_utils.StockCodeUtil`（to_suffix/to_prefix/to_qlib；
  digits() 归纯数字在 realtime_core）；快照 parquet/engine_signal_scores 口径=纯数字；
  QuantDB 因子源自读返回前缀式、边界归一在 script_runner 与 realtime_core。
- 后果：新增消费方必须先确认所处层的口径；跨层转换只许走工具函数（禁止手写切片）。

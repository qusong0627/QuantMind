# ADR-0006 行情多席语义（同契约不同源 / 席位互不打架）

- 状态：已采纳（T-P6-02 批，2026-09-17）
- 背景：单一源单点风险（TdxAiData 盘中零帧、QMT 桥离线），但多写方同键会抖动。
- 决定：多源写**同一标准键契约**、以 `source` 区分；席位规则=
  主源新鲜不覆盖（TDX 订阅写 tdx_aidata_sub）；备源席仅当键缺失/陈旧>stale_after_s 才写
  （qmt_big）；桥源席（tdx_bridge）为当前热集供数主源。新鲜度判断一律走
  `shared/freshness`（阈值唯一读取点）。
- 后果：席位行为可解释（谁写的、为什么没写，全在 status 面）；调 stale_after_s 见
  `qm:qmt:quote:backup:config`（与桥轮转 102s 对齐需 ≥150s）。

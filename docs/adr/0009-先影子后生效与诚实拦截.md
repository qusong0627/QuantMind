# ADR-0009 先影子后生效 / 闸门默认诚实拦截（fail-closed 文化）

- 状态：已采纳（P6 全批沉淀）
- 背景：新规则/新链路直接生效曾致误杀与"伪实时"（行情未到达仍发 T-1 分）。
- 决定：① 新规则先影子 N 日（判定照跑、动作不执行、落库留痕）达标再转正；
  ② 数据不足时**不产出**而非产出劣质产物：实时推理覆盖率闸门（live_coverage<min 不发布）、
  存量陈旧帧不落 L0.5、测试/修复失败如实 fail 不静默降级；
  ③ 一切"跳过/拦截"必须显式计数 + 可解释理由（rule_id/evidence/last_skip）。
- 后果：工程动作默认 fail-closed；任何"降级放行"必须是一次显式配置变更并留痕。

# ADR-0010 分支工作流与提交约定

- 状态：已采纳（2026-09-02 定版）
- 决定：`main/master` = 稳定运行版（只合并不直推）；日常改动一律提交 `next`；开发前先拉
  main 到本地更新再提交 next（next 永远基于最新 main）。多会话共享同一工作树：提交前先
  `git log` 对时、只 `git add` 具体文件（勿用暂存区残留）。本地提交**不主动 push**，用户
  明示才推（默认目标 gitee + upstream）。
- 后果：并行会话互不踩踏（临时文件/probe/截图不入库）；合流到 main 由用户过目决定。

# ADR-0005 热集键本地化（部署本地 Redis 单一事实源）

- 状态：已采纳（事故驱动，commit 3f8379d8）
- 背景：`qm:hot_set:symbols` 曾在公共行情服（全局键）被多实例交替覆写 → 订阅侧每小时级
  全量重订阅风暴（2026-09-17 盘中事故）。
- 决定：热集读写唯一入口 `shared/hot_set_store`（部署本地 Redis；builder/订阅 worker/
  备源席/regime/实时推理/验收器全链切换）；行情快照仍走远端公共服。
- 后果：热集=部署私有状态，公共服不再承载；新增热集消费方必须走 hot_set_store（禁硬编码键）。

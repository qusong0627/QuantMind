# 通达信交易桥 v1.0 — 发布说明

> 发布版本：v1.0.0
> 发布日期：2026-08-12
> 组件：Windows 桥（bridge-windows）+ 看门狗 + 网页控制台 + SQLite 缓存

---

## 一、功能总览

### 核心能力
| 能力 | 说明 |
|------|------|
| **全量通达信接口** | 62 个 tqcenter 方法全部接入（行情/财务/板块/公式/推送/交易）|
| **通用透传** | `POST /api/v1/tdx/call` 一个端点调任意方法，后期扩展免改桥 |
| **双向推送** | QuantMind → 通达信（选股/消息/预警/源码）+ 通达信 → QuantMind（账户/持仓/委托）|
| **网页控制台** | `http://<win-ip>:8550/ui` 状态监控 + 接口测试 + token 管理 |
| **SQLite 缓存** | K线/股票信息/财务/快照持久化，历史可查 |
| **内存缓存** | 高并发保护通达信，99% 请求走缓存 |
| **精确日志** | 所有查询/下单/推送记录含耗时/状态/委托号 |
| **自动重启** | 看门狗崩溃自动拉起，开机自启 |

### 安全能力（已审计）
| 防护 | 机制 |
|------|------|
| Token 鉴权 | 多 token + SHA256 哈希存储，每台电脑独立 |
| 限流 | IP 60次/分，写操作 10次/分，超限 429 |
| 暴力破解防护 | 错误 token 5 次封 IP 30 秒 |
| 注入防护 | 方法白名单，拦截 exec/__import__ |
| 请求防护 | 请求体 ≤512KB，Content-Type 白名单 |
| 审计日志 | 每次调用含 IP/方法/耗时/结果 |

## 三、部署步骤

### Windows 侧

1. **安装 Python 3.9+**（勾选 Add to PATH）
2. **启动通达信客户端并登录交易账号**
3. **在 TQ 策略管理器运行 tdx_keepalive.py**（保持运行，让 17709 常驻）
4. **右键 setup.ps1 → PowerShell 运行**
   - 自动装依赖 + 防火墙 + 启动桥
   - 自动打开控制台网页
5. **注册看门狗**：右键 `register_watchdog.bat` → 管理员运行
   - 桥崩溃自动重启 + 开机自启
6. **配置 token**（可选）：控制台 → Token 管理 → 生成客户端 token

### QuantMind / Linux 侧

```bash
# 挂载共享 (已配 fstab 自动挂载)
mount -a

# 配置 .env
ENABLE_TDX_PUSH=true
TDX_BRIDGE_URL=http://192.0.2.22:8550
TDX_BRIDGE_TOKEN=<主token>
ENABLE_REAL_TRADING=true
REAL_BROKER_TYPE=tdx
```

## 五、安全清单（已审计通过）

- [x] Token 常数时间比较（hmac.compare_digest）
- [x] Token SHA256 哈希存储，无明文
- [x] 无 SQL 注入（参数化 + 表名白名单）
- [x] 无命令注入（无 subprocess/shell）
- [x] 无路径遍历（路径白名单）
- [x] 限流 + 封 IP + 超大请求拦截
- [x] 审计日志（IP/方法/耗时）

## 六、稳定性保障

| 机制 | 说明 |
|------|------|
| 单飞锁 | 条件变量实现，无死锁 |
| 并发信号量 | 限 4 路通达信并发，防线程耗尽 |
| 调用超时 | 8 秒强制超时，防挂起 |
| 优雅降级 | 通达信不可达时返回缓存 |
| 看门狗 | 崩溃 60 秒内自动重启 |
| 日志 | bridge.log + watchdog.log |

## 七、故障排查

| 现象 | 处理 |
|------|------|
| 桥 500 | 看 `data/logs/bridge.log` 找 traceback |
| 网页"检测中" | 确认桥进程在（任务管理器 python）+ 看门狗 |
| 通达信连不上 | 确认 keepalive 策略在跑 |
| token 失效 | 控制台 Token 管理重新生成 |
| 电脑卡顿 | 确认单飞锁修复版（v1.0）已部署 |

## 八、已知限制

1. **下单**：当前通达信量化模拟版 OMS 不支持真实下单，需券商开通 TQ 权限的账号
2. **订阅行情**：subscribe_hq 需常驻连接，HTTP 一次性请求不支持
3. **专业财务数据**：需通达信先下载专业财务数据包

## 十、打包为 EXE（可选，代码保护）

需要把桥打包成独立 exe（隐藏源码、免装 Python）：

### 步骤（Windows 上）
1. 双击 `build_exe.bat`
2. 自动安装 PyInstaller + 打包
3. 生成 `dist\TDXBridge.exe`

### 效果
- **代码不可见**：编译为二进制，普通人看不到源码
- **免装 Python**：双击即运行
- **自动开控制台**：启动后自动打开 `/ui` 网页

### 注意事项
- exe 是**单文件**，运行时会解压到临时目录，`data/` 会生成在 exe 同目录
- 看门狗需改为监控 exe（把 watchdog.ps1 里 Python 路径换成 exe 路径）
- 更新代码后需重新打包

> 如需更高等级保护（防专业反编译），可加 PyArmor 加密，需另行配置。

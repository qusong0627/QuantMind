## 六、边界（必须随名单一起读）

- 这是**样本内选特征**：用 2016–2024 的 IC/ICIR 与 LGB importance；2025 只做验证，2026 只做测试。
- 日频采样为每 20 个交易日一个截面；ICIR 的样本数约 104，不等同于逐日全样本 ICIR。
- T+1 门槛同时看「次日开盘买、次日收盘卖」与「次日收盘对当日收盘」两口径；满足其一且与 T+5 同号即通过，不是保证实盘可成交。
- 因子研究库自带的「近期失效/持续低效」是全窗口（到 2026）标签；本报告按截止 2024-12 重算，所以名单与 UI 上的 1500 个候选不是同一批。
- LGB gain 对高基数/连续特征有偏好，故叠加 null gain 比值与 cap 三档同号；最终模型仍要 2026 test + 扣费 + 分层回测验证。

1. `npm run typecheck` 通过；组件单测（vitest）或走查清单（视觉类）二者至少其一；
2. 新页面/组件与现有外观并排走查无违和；
3. 完成即勾选本文件 + 一行证据摘要；
4. 提交信息带任务 ID；`web/dist` 构建产物同步按现有部署流程。

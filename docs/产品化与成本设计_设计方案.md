# 产品化与成本设计_设计方案（消费者分层 · 合规 · 默认安全 · 运营）

> 版本：v1（2026-09-15）　配套：`docs/统一交易栈_设计方案.md`（v3）、`docs/设计复盘与优化报告.md`
> 背景：产品面向**普通消费者**（数千用户规模），但功能不缩水——机构级能力藏在后台，前台降维呈现。
> 核心命题：**成本与用户数脱钩**（铁律七），合规不留死角，消费者默认安全。

---

## 一、用户分层与功能矩阵

| 层级 | 典型用户 | 能用什么 | 成本归属 |
|---|---|---|---|
| **观察者** | 刚注册 | 看今日机会/系统信号、看演示账户、术语词典 | 纯共享层，≈0 |
| **订阅者** | 主流消费者 | 模拟盘跟投系统策略（一键订阅）、通知推送、简单模式全部 | 共享层 + 轻量用户层 |
| **进阶者** | 愿学愿调 | 改参数、看专业模式、写策略（模板/AI）、回测 | 共享层 + 用户层（回测配额） |
| **专业用户** | 少数 | 全功能（自有模型、L2 只读、API） | 配额+限流 |

## 二、共享层 / 用户层架构（铁律七的落地表）

| 资源 | 层 | 说明 |
|---|---|---|
| 全市场推理（日频） | **共享** | 1 次/日，所有用户同一份 Signal |
| 盘中热集实时推理 | **共享** | 1 份，系统级热集（持仓并集+候选并集，去重后通常 < 2000 只） |
| 行情扫描（七路 scanner） | **共享** | 批量 1 次 + 盘中 1 份 |
| 市场状态/情报总线 | **共享** | 1 份 |
| 策略参数应用（选哪只/仓位/风控） | 用户级 | 纯计算，毫秒级，不触发重推理 |
| 账户/持仓/订单 | 用户级 | 现有 Redis+PG 结构 |
| 通知/推送 | 用户级 | 限频 |
| 回测/参数扫描 | 用户级（配额） | 跑在 R1/R2 队列，按用户限并发 |
| LLM 对话 | 用户级（限流） | 分层模型 + 缓存 |

**上限保护**：共享层容量由"持仓并集+候选并集"决定；用户数增长只增加用户级轻量资源。系统健康卡监控共享层负载，超阈值自动降频（热集节拍 3s→10s）并告警。

## 三、成本模型（目标值）

| 项 | 摊到单用户 | 控制手段 |
|---|---|---|
| 共享计算（推理/扫描/实时） | ≈ 0（脱钩） | 共享层架构本身 |
| 存储（账户/快照/日志） | 忽略级 | 分层留存（L2 方案） |
| 通知推送 | 忽略级 | 合并推送/限频 |
| LLM | 关键成本项 | 分层模型（简单问答用小模型/缓存）、每用户每日 token 预算、超限降级 |
| 回测算力 | 中度 | 配额 + 队列 + R1 快扫优先 |

**验收**：单用户日边际成本 < 目标值（上线前实测一次，写入运维基线）。

## 四、合规设计（面向消费者的硬约束）

| 项 | 具体做法 |
|---|---|
| **资质边界** | 定位为"量化研究工具"：展示研究结果与信号，**不构成投资建议/不代客理财**；免责声明全流程可见（沿用现有 CLAUDE.md 的免责基调，产品化落地） |
| **收益展示规范** | 历史收益必须附：样本区间、口径说明、"过往不代表未来"；禁止暗示确定性措辞；榜单/排名注明计算口径与时间 |
| **适当性** | 首启风险问卷 → 风险等级；高风险功能（实盘、加大仓位）按等级解锁；风险揭示确认留痕 |
| **数据合规** | **L2/第三方数据的分发授权采购时确认**（原始数据不外露给用户，仅输出衍生指标）；用户数据（策略/持仓）隔离与导出/删除权 |
| **留痕** | 用户看到的每条信号/建议/通知落库（时间/内容/版本）——合规审计与纠纷举证 |
| **模拟先行** | 消费者默认只能模拟盘；实盘需完成教育流程（读风险页+确认）且门槛达标（评估体系） |

## 五、默认安全（消费者保护参数）

| 项 | 默认值 | 说明 |
|---|---|---|
| 止损 | 开（-5%） | 不可关（可调幅度）——消费者最容易犯的错是不止损 |
| 分散 | 强制（单票 ≤15%、最少 3 只） | 防单吊 |
| 仓位 | 按 regime 系数封顶 | 防熊市满仓 |
| 追高保护 | 开盘跳空 >4% 不追（买入前过滤默认开） | 移植 KHunter 规则 |
| 危险操作 | 二次确认（清仓/关风控/上实盘/大额调仓） | 文案说清后果 |
| 损失保护 | 账户日内亏损触及 X% → 当日自动停（可申诉恢复） | 防情绪化交易 |

## 六、运营与客服工具

- **客服视图**（只读）：用户账户/策略/最近订单/风控拦截，一键生成诊断报告（复用体检脚本）——客服不猜、不问开发。
- **运营看板**：用户数/活跃/订阅转化/模拟→实盘漏斗/系统健康。
- **通知体系**：分级（日常聚合推送 / 重要即时 / 风险必达），用户可配频率；文案走术语翻译层。

## 七、验收清单

- [ ] 共享层负载与用户数脱钩验证（压测：用户 ×10，共享层资源不变）
- [ ] 合规四件（免责/收益展示/适当性/留痕）全部上线并有测试
- [ ] 默认安全参数生效且不可绕过（除显式解锁）
- [ ] 客服视图 + 一键诊断可用
- [ ] 单用户边际成本实测达标

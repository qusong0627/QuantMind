# 多市场可插拔架构设计方案（复刻 · 好维护）

> 版本：v1（2026-09-15）　配套：`docs/统一交易栈_设计方案.md`（v3）
> 目标：**A 股先行，新市场按同一份清单即可"复刻"接入**；市场差异只允许存在于 Adapter 内，全系统零 `if market ==` 分支。

## 一、现状：五套市场资产已经存在，但接口没统一

| 资产 | 位置 | 现状 |
|---|---|---|
| 交易规则五套 | `simulation/services/market_rules.py`（CN/HK/US/FUTURES/CRYPTO：T+1、手数、费率、涨跌停开关） | 齐全但只有模拟盘用 |
| 数据目录解析 | `shared/quantdb_paths.py`（唯一事实源，禁硬编码） | 齐全 |
| 行情五市场 hub | `simulation/services/local_market_data.py` + `data_platform/*_hub.py` | 齐全（CN 不复权、其余 forward） |
| 市场适配器 | `engine/rd_agent/market_adapters/`（a_share/crypto/hong_kong/us_stock） | 因子挖掘用，未与交易层打通 |
| 前端市场分层 | `electron/src/features/dashboard-shared/marketContent.ts`（"差异只写在本文件"纪律） | ✅ 已是最佳实践，后端照抄该纪律 |
| 信号市场隔离 | `universe_tag` + `market_symbol_sql_regex` | 有历史事故（SHOP/SHW 被当成上交所），已修 |

**结论**：不是从零建，而是**把散落的五套东西收敛到一个 SPI 后面**，前端 `marketContent.ts` 的"差异唯一声明处"纪律推广到后端。

## 二、Market Adapter SPI（唯一市场差异出口）

```python
class MarketAdapter(Protocol):
    # 身份与符号
    market: str                          # CN | HK | US | FUTURES | CRYPTO | CUSTOM
    currency: str                        # CNY / HKD / USD
    normalize_symbol(raw: str) -> str    # 唯一归一处（后缀式/前缀式规则在此声明）
    parse_symbol(symbol: str) -> SymbolInfo

    # 交易规则（撮合/风控共用）
    trading_rules() -> TradingRules      # T+N、涨跌停、手数、最小变动、时段、集合竞价规则
    fee_model() -> FeeModel              # 佣金/印花/过户/最低佣金（fills 分项口径）
    calendar() -> TradingCalendar        # 交易日历、时区、夏令时

    # 数据
    data_hub() -> LocalMarketData        # 行情读取（复权口径在此声明）
    universe() -> UniverseProvider       # 股票池/成分/ST/退市标记

    # 执行
    matching_specifics() -> MatchingSpec # 涨跌停判定、ST 幅度、新股/复牌特殊行为
    corporate_actions() -> CorporateActionProvider  # 除权除息/送转

    # 风控
    risk_defaults() -> RiskDefaults      # 该市场默认风控参数（如港股无涨跌停 → 速度风控替代）
```

铁律：
1. **全系统只允许通过 Adapter 触碰市场差异**——下单、撮合、风控、信号、账本、前端注册表，一律 `get_adapter(market).xxx()`。CI 加规则：`grep -rn "if .*market\s*==\s*['\"]" backend/` 命中数必须为 0（白名单除外）。
2. Adapter **无状态、可单测**；每个市场一份**规则测试矩阵**（对同一构造场景断言行为差异）。
3. 市场能力差异用**能力声明**表达而不是分支：`supports_short_selling / has_price_limit / has_auction / t_plus` 等布尔+参数，消费方按能力降级（如港股无涨跌停 → 撮合走市价保护单逻辑）。

## 三、新市场复刻清单（"可插拔复刻"的定义：5 步 + 验收）

| 步 | 动作 | 产物 | 验收 |
|---|---|---|---|
| 1 | **数据接入**：落地 parquet（沿用 QuantDB 分区范式 `date/symbol`）+ qlib 缓存 + 数据质检 | `data/quant{X}/` + hub | 质检报告通过；样例查询正确 |
| 2 | **Adapter 实现**：按 SPI 全量实现（符号/规则/费率/日历/hub/universe/公司行为/风控默认） | `adapters/{market}.py` | 规则测试矩阵全绿 |
| 3 | **特征/训练默认**：默认特征集、默认窗口、模型 market 段 | 训练配置模板 | 训练一个基线模型并推理出信号 |
| 4 | **信号与交易打通**：universe_tag、模拟盘市场账户、撮合、风控 | 端到端 | 「推理→选股→模拟成交→账本」E2E 通过 |
| 5 | **前端注册**：dashboard marketContent、推理中心、个股终端（复用共享层，禁止复制目录） | 前端注册项 | 页面可用 + 空态文案正确 |

**度量**：完成一个市场的目标工作量 = 5 步 × N 天（历史经验：港股/US 已走通，可作为基准工时）；任何一步卡住 → 属于 SPI 缺项，**补 SPI 而不是打补丁**。

## 五、维护纪律（"好维护"的制度化）

1. **差异唯一声明处**：任何"某市场特殊"的规则，先加进 Adapter/能力声明，再写消费逻辑；禁止在业务代码里判断市场名。
2. **能力矩阵看板**：`docs/` 维护一张"市场 × 功能"矩阵（数据/训练/推理/模拟/实盘/风控/前端），每格标 ✅/🟡/❌ + 备注——上线前对照，防"半通"（港股托管静默 0 单类事故就是 🟡 被当成 ✅）。
3. **回归网**：每个市场一条 E2E（推理→模拟→账本）。新增市场只加测试文件，不改其他市场测试。
4. **SPI 版本化**：Adapter 接口变更需过"全部市场编译期检查"（Protocol 类型 + 每市场实现的契约测试）。
5. **文档同源**：每个市场的口径差异（复权/费率/时段）写入其 Adapter docstring，这份 docstring 是唯一权威，前端注册表的注释引用它。

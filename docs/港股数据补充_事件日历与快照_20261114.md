# 港股数据补充：PIT 事件日历与每日快照（2026-11-14）

> 目标：把“观测相关性”推进到“事件/自然实验”。不生成 alpha 公式；只做时间戳、
> 来源与可回滚的原始快照。

## 1. 已落地的数据

### 1.1 PIT 事件日历

脚本 `backend/scripts/hk_event_calendar.py`，输出：

`data/quanthk/2_base_sector/event_calendar/data.parquet`

列：`date, stock_code, event_type, source, value, meta, censored`

| event_type | 行数 | 可用（非左截断） | 说明 |
|---|---:|---:|---|
| `south_init_1pct` | 920 | **266** | 首次南向持股 ≥1%；左截断 654（样本起点已持有） |
| `dividend` | 203 | 203 | 除净日（Yahoo/akshare） |
| `split` | 202 | 202 | 拆合股（Yahoo） |

- `censored=True` 表示事件日等于样本首个南向分区（2024-11-27），不是真正“首次”，
  事件研究时必须剔除。
- `south_init_1pct` 是**首次持有代理**，不是官方港股通纳入日；只能做准自然实验。

### 1.2 每日快照采集

脚本 `backend/scripts/hkex_snapshot_sync.py`：

| 数据 | 来源 | 落盘 | 当前状态 |
|---|---|---|---|
| 北向合资格证券（SSE/SZSE） | HKEX 当前 CSV | `2_base_sector/stock_connect_eligible/dt=YYYYMMDD/{SSE,SZSE}.parquet` | 2026-11-14：SSE 1,906 行、SZSE 2,082 行 |
| HKEX 主板每日沽空 | ASHTMAIN 页面 | `2_base_sector/short_selling/dt=YYYYMMDD/data.parquet` | 周六/盘前占位页，无数据；交易盘后可用 |
| HSI/HSCEI/HSTECH factsheet | HSI 官网 | — | 公开 URL 已 404，**blocked** |

**注意**：HKEX 沽空 ASHTMAIN 只有最新交易日；历史段需付费 HKEX Data Marketplace
或第三方（etnet）逐日抓。当前脚本只能从今天起向前积累。

## 3. 数据缺口（必须付费/另找）

| 数据 | 免费可得性 | 影响 |
|---|---|---|
| 港股通官方历史纳入/剔除名单（PIT） | 当前名单免费；历史档 HKEX Data Products 付费（约 HK$1,000/月） | 没有官方生效日 → 只能做“首次持有”代理，不能做严格 inclusion DiD |
| HSI/HSCEI/HSTECH 历史成分与生效日 | HSI factsheet URL 404；历史需 HSI Services/AASTOCKS/Wind 或 Wayback | 指数再平衡 DiD 暂无数据 |
| HKEX 历史每日沽空 | 最新免费；历史付费/第三方 | squeeze 风险只能向前积累 |
| 配售/供股/质押公告日历 | HKEXnews 免费但需爬虫/解析 | 事件研究尚未接入 |
| 全量 CCASS 参与者（非 top50） | 历史只有 top50 | 结构性截断仍在 |

## 4. 运行方式

```bash
# 事件日历（本地 parquet → 事件表）
python backend/scripts/hk_event_calendar.py

# 每日快照（建议交易日 17:30 后；未接入生产调度）
python backend/scripts/hkex_snapshot_sync.py
```

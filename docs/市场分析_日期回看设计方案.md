# 市场分析「日期回看（复盘）」功能设计

> 目标：市场分析页右上角加日期选择器，切换后各面板显示**该交易日视角**的数据。
> 港股与美股**各自独立实现**（两个模块的数据源不同，可回看的范围也不同）。

---

## 一、先说结论：能做的比想象多，但有明确的边界

数据分三类，**决定哪些面板能做回看、哪些只能显示最新**：

| 类型 | 判据 | 例子 |
|------|------|------|
| **A 完全可回看** | 数据按日分区（`dt=`）或带明确日期字段 | 日线、指数、L1 因子、CCASS、南向、内部人交易、评级事件 |
| **B 部分可回看** | 事件流可截断，但"当前状态类"字段无历史 | 机构持仓（季度披露）、评级分布（月度滚动） |
| **C 不可回看** | 单点快照，只有最新值 | f10 估值快照、分析师目标价、财报日历、行业分类 |

C 类面板**不是不能加日期，而是加了也只会显示最新值**——必须在前端明确标注「最新快照，不支持回看」，否则用户会以为自己看到了历史。

## 二、逐面板可行性

### 美股（QuantUS）

| 面板 | 数据源 | 回看 | 说明 |
|------|--------|:----:|------|
| 指数卡 | `index_daily/dt=` | ✅ | 指数分区滞后个股，按各自日历回退 |
| 市场温度计 / 涨跌分布 | `daily_forward/dt=` | ✅ | |
| 今日热门（成交额/量比/异动） | `daily_forward/dt=` | ✅ | 量比基准取该日之前的 20 日 |
| 板块热力图 / 轮动 / 资金流 | `daily_forward/dt=` + sector 快照 | ✅ | 行业归属用**当前快照**（见 §五） |
| 市场宽度（MA50/200、52周、A-D） | `daily_forward/dt=` | ✅ | 窗口自然回退到该日 |
| 财报日历 | `calendar` 快照 | ❌ | 只反映最新排期 |
| 超预期榜 | `earnings_dates.Reported EPS` + 日期 | ✅ | 按 `report_date <= 选定日` 截断 |
| 盈利预期修正 | `earnings_estimate` 快照 | ❌ | |
| 分析师升降级流水 | `upgrades_downgrades.GradeDate` | ✅ | 按日期截断，天然适合复盘 |
| 目标价隐含空间 | `analyst_price_targets` 快照 | ❌ | |
| 评级分布 | `recommendations.period`（0m/1m/2m/3m） | ⚠️ | 只有 4 期、无精确日期，只能选「最近一期」 |
| 内部人交易榜 | `insider_transactions.Start Date` | ✅ | |
| 机构持仓 | `mutual_fund_holders.Date Reported` | ⚠️ | 季度披露，选任意日只能取 ≤ 该日的最近一期，需标注披露日 |
| 除息 / 拆股 | `calendar` / `splits` 事件 | ✅ | 拆股可回看；除息日历本身就是**未来**事件，回看意义弱 |
| 估值榜 / 市值分层 / 估值概览 | `f10` 单点快照 | ❌ | |

**美股可回看面板占比：约 9/16**，且覆盖了信息量最大的几个（热门、宽度、轮动、资金流、升降级、内部人）。

**港股可回看面板占比：约 6/9**，且**最有复盘价值的南向 + CCASS 恰好都是日频分区**——这是港股模块做回看的最大理由。

## 三、实现方案（两市场形态统一，各自独立落地）

### 后端

1. **端点加可选参数**：`?date=YYYY-MM-DD`（缺省=最新，与现在行为完全一致）
2. **feed 层归一为「最近可用交易日」**：`<= date` 的最后一个分区日；非交易日自动回退
   - 美股：`_trading_days(end, n)`（已收 end 参数）、`_index_trading_days(end, n)` —— **基座已就绪**
   - 港股：`_trading_days(end, n)` 同款
3. **快照类面板**：端点忽略 date，但响应体带 `"snapshot": true` + `"as_of"`，前端据此角标
4. **缓存键带日期**：`cached(f"us_market_breadth:{as_of}", ...)`，避免回看时串味
5. **越界保护**：date 早于最早分区 / 晚于最新分区 → 钳到最近可用日并在响应里回报实际使用的日期

### 前端

1. 页面顶栏加日期选择器（antd `DatePicker`，与页面已有 antd 依赖一致）
2. 选中日期进页面级 state，各面板请求透传
3. 视觉：回看模式下顶栏加醒目标识（如「回看 2026-08-15」+「回到最新」按钮）
4. 快照面板右上角显示 `最新快照` 角标，悬停说明原因

**两页共用同一个日期选择器组件**（放 `market-analysis-shared/`），避免各写一份漂移。

## 四、分阶段实施

| 阶段 | 内容 | 价值 |
|------|------|------|
| **P1** | 美股：指数 / 温度计 / 热力图 / 轮动 / 热门 / 宽度 加 date | 覆盖页面 ~60% 信息量 |
| **P2** | 美股：升降级流水 / 超预期 / 内部人（事件类，按日期截断） | 复盘「当时发生了什么」 |
| **P3** | 港股：全套（指数 / 温度计 / 热力图 / 轮动）+ **南向 + CCASS 历史** | 港股回看价值最高的两块 |
| **P4** | 快照面板统一角标 + 越界与空数据兜底 | 防误读 |

工作量估算：美股后端 0.5 天、港股后端 0.5 天、前端共用组件 0.5 天、测试 0.5 天 ≈ **2 天**。

## 五、两个必须向用户说明的偏差（否则复盘会得出错误结论）

1. **行业归属用当前快照**：回看某日时，板块热力图/轮动用的是**今天的 GICS 分类**，不是当时的。
   对绝大多数股票无影响，但改过行业的（如特斯拉从消费调到大盘科技类）会有偏差。
   严格还原需要行业历史表，**目前没有这个数据**。

2. **标的池是当前池（幸存者偏差）**：美股 517 只、港股池均是**今天的成分**。
   回看 2020 年时，看到的"标普500"其实是 2026 年的名单 —— 已经退市/被剔除的股票不在其中，
   会让历史宽度（如 % 站上 MA200）系统性偏乐观。**复盘时必须知道这一点**，建议在回看模式下页面顶部挂一行提示。

---

## 六、不做什么

- ❌ 不做「跨日对比」（两天并排）—— 先把单日回看做稳
- ❌ 不做「按日期重算 Qlib 缓存」—— 回看只读原始分区，不触发重建
- ❌ 不让快照类面板"假装"有历史（宁可不显示，也不给错数）

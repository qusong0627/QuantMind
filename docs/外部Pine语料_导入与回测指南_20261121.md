## 2. 导入命令

```bash
# 先克隆语料（只读研究；不要复制进仓库）
git clone --depth 1 https://github.com/theonetrade/pynecore-strategies.git /tmp/pynecore-strategies

# dry-run（不写盘）
python3 scripts/import_pynecore_corpus.py --corpus /tmp/pynecore-strategies

# 正式导入（幂等；已有条目跳过）
python3 scripts/import_pynecore_corpus.py --corpus /tmp/pynecore-strategies --apply
```

落盘位置（`data/` 是宿主机数据根，不在 git 内）：

```
data/pine_library/source/9xxx.pine          # 原始 Pine（byte copy）
data/pine_library/lib/                      # 语料 scripts/lib 副本（import lib.*）
data/pine_library/custom/index.json         # 列表条目（source_kind=imported）
data/pine_library/imported_deferred.json    # 未导入清单（审计）
data/pine_transpile/9xxx/candidate.py       # 原样编译产物
data/pine_transpile/9xxx/meta.json          # 来源/分类/许可/周期/校验
```

ID 使用 `9001` 起；`ID_RE` 允许四位数，`delete_item()` 只允许 `u###`，导入条目不会被误删。

## 3. 运行口径

### 成本/仓位（运行时覆盖，不改源码）

`backend/services/agent_arena/pyne_overrides.py` 在每次运行前把候选复制到临时目录，
重写 `@script.strategy(...)` 的仓位/成本/币种；原文件一个字节不动。

| 市场 | 单边成本 | 仓位 | 本金 | 滑点 |
|---|---:|---|---:|---:|
| A 股 | 0.05% | 95% equity | 100,000 | 1 tick |
| 美股 | 0.05% | 95% equity | 100,000 | 1 tick |
| 港股 | 0.15%（含印花税 0.1%） | 95% equity | 100,000 | 1 tick |

> 语料原始设置差异很大（commission 0–0.2%、171 条固定手数、本金 100–1,000,000），
> 不统一则「449 种下注口径」不可横比。原始 decorator 存档在 `meta.json`。

### 单条回测

- 界面：行情回测 → 左栏选策略 → 选标的/市场 → 「回测（预编译）」。
  worker 检测 `meta.imported=true` 会跳过 LLM 转写，直接静态闸 + bwrap 沙箱回测。
- CLI：

```bash
python3 scripts/pine_to_pyne.py --id 9402 --no-transpile --validate 600036.SH \
  --adj backward --market cn
```

### 批量（策略排行）

```bash
# A 股：只跑多头标签
python3 scripts/lab_batch_pyne.py --market cn --pool hs300 --limit 50 --workers 4

# 美股：跑多空标签
python3 scripts/lab_batch_pyne.py --market us --limit 100 --workers 4

# 港股：默认全量（卖空受限，结果只作展示）
python3 scripts/lab_batch_pyne.py --market hk --limit 100 --workers 4

# 指定策略 / 续跑
python3 scripts/lab_batch_pyne.py --market cn --ids 9008,9044 --limit 20
python3 scripts/lab_batch_pyne.py --market cn --resume <run_id>
```

产物：`data/lab_batch/<run_id>.json`，现有「策略排行/选股」页直接读取
（行 schema 与内置模板批量回测一致）。

> 成本参考：1 个标的 × 63 条 A 股策略约 4 分钟（8 workers）；`request.security`
> 子进程是主要开销。全池跑批请先用 `--limit 20~50` 试跑，再按夜盘节奏扩量。

## 5. `request.security` 支持范围

`backend/services/agent_arena/pyne_security.py` 解析脚本里的安全上下文，
按同标的聚合出 `.ohlcv` + `.toml`（security 子进程必须读 sidecar）：

| 周期 | A 股 | 港股/美股 | 加密 |
|---|---|---|---|
| `1D/1W/1M/3M/12M` | ✅ | ✅ | ✅ |
| `1/5/15/30/60` 分钟 | ✅（5m/1m 聚合） | ❌ 无分钟数据 | ✅ |
| `240/360/480/720` | ❌（交易日无法映射） | ❌ | ✅ |

解析支持：字面量（`'D'`/`'1D'`/`'W'`）、`timeframe.period`、`input.timeframe` 默认值
（含 `defval=`）、函数参数实参、`syminfo.tickerid` 别名、`ticker.heikinashi(...)`。

不猜的：跨标的请求（`'AAPL'`、`'AUDUSD'`）和无法静态解析的动态变量 → 留在
`imported_deferred.json`，导入器不会把另一条周期静默当成当前周期。

## 6. 已知坑（已处理）

- **PyneCore 版本**：平台钉 `6.9.2`，语料编译/测试为 `6.12.1`。已冒烟 A 股/美股/港股；
  若后续新增条目报 `AttributeError`，先怀疑版本差，升级 `requirements/pine_lab.txt`
  需按该文件注释在非交易时段回归。
- **Python 3.14 默认 forkserver**：security 子进程会嵌套 spawn，forkserver 直接
  `RuntimeError: ... bootstrapping phase`。`pine_to_pyne.py` / `lab_batch_pyne.py`
  在 Linux 上显式 `set_start_method("fork")`。
- **security_data 键必须用原始周期写法**：源码写 `'D'` 就要给 `"D"`，只给 `"1D"` 不命中。
- **`.toml` sidecar 缺失**：security 子进程 `SymInfo.load_toml` 直接报错；构建器已写。
- **批量 security 的 resource_tracker 警告**：进程池退出时偶发共享内存清理告警；
  当前不影响结果，若长期跑大批量需在 worker 退出前显式 join/清理。

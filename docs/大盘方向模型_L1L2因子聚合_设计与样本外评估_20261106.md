- 日期：2026-11-06
- 状态：研究交付（**未接入生产/未接交易**）
- 目标：用 L1-L2 因子库的**市场级聚合特征**预测沪深300 / 上证综指 / 中证1000 的
  T+1 / T+3 / T+5 方向，输出 P(上涨)
- 切分（用户指定）：train 2018-01-02~2024-05-31 / valid 2024-06-03~2025-06-30 /

## 0. 结论（先看这段）

1. **L1-L2 截面聚合因子在样本内有信号、样本外没有增量。**
   训练窗内单因子最高 AUC：h=5 时 `fa_micro_amihud_illiquidity_mean_pct` 0.607、
   `fa_vol_realized_rrv_mean_pct` 0.598、`fa_mom_ret_1d_std_pct` 0.587；
   但**只有 46.5% 的因子在 train→valid 保持同向**，最强的几个（Amihud、已实现波动）
   在 valid 直接反号。只用因子聚合建模：valid 平均 AUC **0.475**、test **0.452**。
   消融结论：**因子聚合没有给 base 特征带来任何样本外增益**。

2. **T+1 / T+3 方向不可预测（样本外）。**
   全部设计 × 3 指数 × 3 周期共 99 个模型/切分单元，test 窗 AUC>0.55 的只有 **1 个**；
   T+1/T+3 的 test AUC 集中在 0.41~0.51。

3. **T+5 有一个弱而连贯的「趋势+广度」排序信号，但不在 L1-L2 里。**
   base 特征（指数技术 + 全A/大盘股广度 + 两融 + 宏观 + 基差）经训练窗内稳定性筛选后
   训练 LightGBM：

   | 指数 | valid AUC | test AUC | oos AUC |
   |---|---:|---:|---:|
   | 沪深300 | 0.544 | 0.579 | 0.730 |
   | 上证综指 | 0.543 | 0.514 | 0.565 |
   | 中证1000 | 0.527 | 0.445 | 0.562 |

   三个指数在 valid 上一致 >0.5；test 上 2/3 >0.5；oos 上 3/3 >0.5。
   选中特征几乎全是：`mkt_pct_ma60`、`idx_dist_high_20`、`idx_dd_252`、`idx_ma_gap_*`、
   `idx_rsi_*`、`mkt_nh_nl_pct`、`mkt_n_limit_down`、`us_10y_chg_5` —— 即**趋势跟随 + 广度极值**。

4. **概率不可直接当「上涨概率」用。**
   校准后 ECE 在 valid 只有 0.021，但 test 是 0.117（test 是 +26% 单边牛市，基础上涨率
   0.596，模型系统性低估）；加 PIT 滚动基础率先验平移后 test ECE 降到 0.042、准确率从
   0.455 回到 0.549，但 oos（-17% 单边熊市）反而变差（ECE 0.042→0.216）。
   **先验漂移无法用滞后基础率预测** —— 与 2026-10-24 那份评估的结论一致。

5. **经济价值：它是「跌势里的减震器」，不是收益放大器。**
   T+5 沪深300 模型，P≥0.55 才持有（5bp/次切换、非重叠采样）：

   | 切分 | 策略收益 | 策略MaxDD | 买入持有收益 | 买入持有MaxDD |
   |---|---:|---:|---:|---:|
   | valid | 0.00%（全程空仓） | 0.00% | +7.50% | -11.94% |
   | test | +19.74% | -7.16% | +28.33% | -7.16% |
   | oos | **-6.43%** | **-3.90%** | -17.05% | -15.68% |

   即：牛市跑输、震荡市不进场、熊市明显少亏。**不构成「预测涨跌」的生产模型**，
   只能作为「趋势/风险仪表」。

## 1. 数据与特征

### 1.1 标签

- 主口径：`fwd_ret_h = close[T+h]/close[T] - 1`，`y_h = 1 if >0`；
- 稳健口径：`fwd_ret_open_h = close[T+h]/open[T+1] - 1`（次日开盘进场，存于特征表）；
- 标签已逐日复核：与原始 `index_daily` 重算完全一致（max abs diff = 0）。

### 1.2 特征（157 个，全部 PIT）

**A. 指数技术面（26，逐指数现算）**
`idx_ret_1/3/5/10/20/60/120`、`idx_ma_gap_5/10/20/60/120`、`idx_rsi_6/14`、
`idx_macd_hist_norm`（除以收盘价，避免随点位漂移）、`idx_boll_pctb`、
`idx_vol_10/20/60`、`idx_vol_ratio_10_60`、`idx_atr_pct_14`、`idx_dd_252`、
`idx_dist_high_20`、`idx_dist_low_20`、`idx_vol_z_20`、`idx_amt_z_20`。

**B. 市场广度（21）**
全 A（`by_universe` universe=all）：涨跌家数比、等权收益、截面分化、站上 MA20/MA60 占比、
TRIN(EMA10)、McClellan、ADL 斜率、新高新低占比、涨跌停净额、成交额冲击、stress；
大盘股广度（universe=hs300，**逐日流通市值前 300 的 PIT 代理**）：MA20/MA60 占比、
等权收益、分化、TRIN、ADL、新高新低、涨停家数。
慢漂移水平量（McClellan/ADL/stress）做 252 日滚动 z。

**C. 两融（8）**：`fin_chg5/20`、`fin_net5/20_ratio`、`slo_chg5/20`、余额/变化分位，全部用
`_lag1`（两融 T+1 披露）。

**D. 宏观（9）**：SHIBOR 隔夜/3M 变化、中债 10Y 变化与 60 日 z、美债 10Y 变化、
USD/CNY 变化与 60 日 z、期限利差、中美利差。只做 ≤5 日 ffill 补周末。

**E. 股指期货基差（4）**：IF/IH/IC 基差 60 日 z、IF-IC 价差。
**剔除 IM（2022-07 才有），否则「有没有数据」会变成年份哑变量。**

**F. L1-L2 因子截面聚合（88）**
从「因子研究 → 筛选」保留集里的 L1/L2 因子（共 89 个）取 36 个：

- 8 个核心因子做 4 种聚合：`turn_20`、`amt_ratio_5_20`、`vol_std_20`、`mom_ret_1d`、
  `micro_vpin_20`、`micro_liquidity_amihud_5`、`flow_net_ratio`、`style_idio_vol_20`；
- 28 个次级因子做 2 种聚合（估值 `fun_pe/fun_pb`、筹码、概念热度、微观流动性、
  VPIN 家族、资金流、特质波动等）。

四种聚合 = **等权均值（mean）/ 市值加权均值（capw）/ 大盘组−小盘组（ls）/ 截面离散度（std）**；
大盘组 = 当日流通市值前 300（`fun_mv_rank`，逐日 PIT），小盘组 = 分位 <0.5。
所有聚合再做 **252 日滚动分位（min_periods=120）**，保证跨年份可比。

> 「大盘股特征」在特征里有两层落点：① `capw` 用 `exp(对数市值)` 加权；
> ② `ls` = 大盘组均值 − 小盘组均值，直接刻画「大盘 vs 小盘」的风格差。

### 1.3 防泄漏

- 截面聚合只读当日 `dt=YYYYMMDD` 分区，不做跨日合并；
- 滚动分位只用尾随窗口；单测锁定「改未来值不影响历史分位」；
- 切分尾部按 `horizon + 2` 剔除标签窗口伸进下一段的样本；
- 特征筛选只在 **train 窗内**做（4 分块符号一致性），valid/test/oos 不参与；
- `fwd_*` / `y_*` 永远不进特征清单（单测 + 元数据锁定）。

## 2. 模型与训练协议

| 组 | 特征 | 说明 |
|---|---|---|
| `base` | A~E（71 个） | 不含任何 L1-L2 聚合 |
| `factor` | F（88 个） | 只用 L1-L2 截面聚合 |
| `full` | 全部（157 个） | base + factor |
| `compact` | 19 个理论驱动特征 | 趋势/反转/波动/广度/估值/换手/FX |

- **特征筛选（可选）**：`stable_features` —— 训练窗等分 4 段，要求 ≥3 段与全窗同向、
  且各段 |AUC−0.5| 最小值 ≥0.0075，按「最差段 edge」取前 20；
- **模型**：LightGBM（depth 3 / leaves 7 / lr 0.03 / ff 0.35 / L2 10）、
  `lightgbm_tiny`（depth 2 / leaves 3 / min_data 100）、CatBoost（depth 3 / rsm 0.35）、
  L2 逻辑回归（C 由内层 CV 选）、等权符号合成（零参数）、趋势投票基线；
- **内层 CV**：训练窗内 4 折扩窗（每折 252 天，embargo = h+2），只用于早停/轮数；
- **概率校准**：Platt 只在 valid 拟合（斜率上限 1.0，只允许收缩）；
- **先验平移**：`p' = σ(logit(p) + logit(π_t) − logit(π_valid))`，`π_t` = 过去 252 个
  **已实现**标签的上涨率（t−h 及以前），逐日 PIT；
- **评估**：AUC（块自助 95%CI）、准确率、平衡准确率、Brier skill、ECE、
  高置信子集命中率（Wilson CI）、非重叠 long/flat 策略（5bp/次切换）。

### 3.2 消融（LightGBM，三指数 × 三周期均值）

| 特征集 | valid AUC | test AUC | oos AUC |
|---|---:|---:|---:|
| base（指数技术+广度+两融+宏观+基差） | **0.524** | **0.493** | **0.559** |
| factor（仅 L1-L2 截面聚合） | 0.475 | 0.452 | 0.535 |

**因子聚合单独用比 base 差，且没有增量。** 全量模型（159 维，含当时未剔除的 IM 基差；
`smoke` 组）在 valid AUC 0.427 —— 特征越多越差，典型的小样本过拟合。

### 3.3 过拟合的直接证据

| 指标 | 值 |
|---|---|
| 全量特征 LGB 训练窗内 AUC | 0.894 ~ 0.943 |
| 稳定性筛选后（~20 特征）训练窗内 AUC | 0.791 ~ 0.845 |
| 同期 valid AUC | 0.42 ~ 0.57 |
| 训练/验证单因子同向比例 | **46.5%** |

### 3.4 概率校准

沪深300 T+5 base 模型：

| 切分 | 基础上涨率 | 校准后 ECE | 先验平移后 ECE | 准确率(校准) | 准确率(先验平移) |
|---|---:|---:|---:|---:|---:|
| valid | 0.488 | 0.021 | 0.042 | 0.543 | 0.535 |
| test | 0.596 | 0.117 | **0.042** | 0.455 | **0.549** |
| oos | 0.333 | 0.168 | 0.216 | 0.630 | 0.395 |

结论：**校准器无法预测基础率本身的漂移**。牛市里模型系统性低估上涨概率（准确率跌到
0.455，低于「永远猜涨」的 0.596）；熊市里先验平移又把概率压低得过头。

### 3.5 策略与高置信子集（沪深300 T+5）

P≥0.55 才持有：

| 切分 | 策略收益 | 策略MaxDD | 买入持有收益 | 买入持有MaxDD |
|---|---:|---:|---:|---:|
| valid | 0.00%（空仓） | 0.00% | +7.50% | -11.94% |
| test | +19.74% | -7.16% | +28.33% | -7.16% |
| oos | **-6.43%** | **-3.90%** | -17.05% | -15.68% |

test 窗高置信子集：P≥0.60（占 49% 的交易日）命中率 **0.609**（95%CI 0.517~0.693），
同期基础上涨率 0.596 —— **只比「永远猜涨」高 1.3 个百分点**。

## 4. 判读

1. **短周期（T+1/T+3）日频方向在 A 股基本不可预测**，与 2026-10-24 的
   `docs/大盘指数预测模型_CatBoost_LightGBM_XGBoost_训练规划_20261024.md`
   （T+1/T+5 0/13 通过）结论一致。本次用了更丰富的微观结构/资金流聚合，仍然没有改变结论。
2. **L1-L2 因子的价值在截面选股，不在择时**。这与
   `scripts/L2_阶段3_VPIN择时_冲击过滤报告.md` 的结论一致（VPIN 是选股正 alpha，
   不是风险信号）。它们的截面**均值**被 base 里的广度/波动特征覆盖，
   截面**离散度**在样本外不稳定。
3. **T+5 的弱信号是「趋势跟随 + 广度极值」**，不是「预测」。它擅长单边行情
   （test 牛市 AUC 0.579、oos 熊市 0.730），震荡市失效（valid AUC 0.544 但策略全程空仓）。
4. **多重检验校正后，T+5 的证据也只是「值得继续观察」，不是「可以下单」。**
   本轮一共评估了 99 个模型/切分单元；沪深300 T+5 的 test AUC 0.579（n=235，z≈2.4）
   单独看显著，但它是 9 个 base 单元里的 1 个，且有 3 个指数 × 3 个周期的选择空间。

## 5. 建议（按优先级）

1. **不要把任何一版接成交易信号。** 若要上线，只能作为「大盘分析」页的
   **趋势/风险仪表**（T+5、沪深300/上证），并明确标注「非概率预测」。
2. **若继续做方向模型**，优先方向不是换模型，而是换数据：
   - 指数期权隐含波动率/偏斜（50ETF、300ETF 期权）——A 股最可能有效的前瞻变量；
   - 融资融券的**逐日**行业结构（当前只有滞后 1 日总量）；
   - 股指期货持仓量/会员多空（当前只有基差）；
   - 盘中高频资金流（TDX L2 仅 2 个月，历史不足）。
3. **若目标是「概率最大」的短期胜率**，更现实的产品形态是
   **条件胜率表**（例如「MA60>MA120 且广度<30% 分位时，未来 5 日上涨概率 X%，样本 n，CI」），
   而不是一个黑箱概率。本轮已产出可直接查询的日频面板。
4. **若要复用本管线**，推荐命令见下节；`base + stable` 的 T+5 模型是当前最好的候选。

## 6. 复现

```bash
# 1) 构建特征（容器内，约 2 分钟）
docker exec -w /app quantmind python3 -m backend.scripts.market_direction.build_features

# 2) 训练 + 评估（三指数 × T+1/3/5）
docker exec -w /app quantmind python3 -m backend.scripts.market_direction.train \
  --feature-set base --selection stable --models lightgbm --tag base

# 3) 消融（L1-L2 聚合单独用）
docker exec -w /app quantmind python3 -m backend.scripts.market_direction.train \
  --feature-set factor --selection stable --models lightgbm --tag factor

# 4) 单测
python3 -m pytest backend/tests/test_market_direction_features.py -q
```

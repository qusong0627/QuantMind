# 板块量价加速度 · 统计核算（2026-10-29）

## 问题

「大盘全景 → 板块热力图」原来的「加速度」= 当前 N 日主力净额日均 − 前一 N 日日均，只反映资金流快慢，不包含价格与成交量的关系。用户提出：能否换成「量价加速度」，即资金流出/价格下跌、资金流入/价格上涨的同向关系，并重新核算。

## 口径

- 样本：申万二级 80 板块，2018-01-02 至 2026-10-28，171,021 个板块-日。
- 价格：板块成分等权日收益（`panel_sector.ret`）。
- 资金：板块主力净额/成交额（`panel_sector.net_ratio`）。
- 量：板块成分成交额/成交量之和（QuantDB `daily_unadjusted`，当前成分回溯聚合）。
- 前向收益：**可执行口径** t 日收盘信号 → t+1 收盘建仓 → t+1+h 收盘；板块等权收益减当日全板块均值（行业中性超额）。
- 指标均为逐日截面，IC 为 Spearman RankIC（每天 ≥20 个板块才计入），Q5−Q1 为按指标分五档的日期级平均超额差。

## 指标定义

| 指标 | 定义 |
|---|---|
| `flow_accel(old)` | 当前 3 日均净额比 − 前 3 日均净额比 |
| `price_accel` | 当前 3 日均日收益 − 前 3 日均日收益 |
| `amount_accel` / `volume_accel` | 当前 3 日均成交额/成交量强度 − 前 3 日 |
| `vp_amount_accel` | `ret × log1p(成交额强度)` 的 3 日加速度 |
| `flow_price_coupling3` | `sign(净额比) × 日收益` 的 3 日均值（同向为正） |
| `coupling_accel` | 上述耦合的 3 日加速度 |
| `agreement3` | 资金方向与价格方向一致的 3 日均值（0~1） |
| `rank(...)` | 上述分量的截面分位平均（量价加速度合成） |

## 结论

1. **量价加速度没有稳定正向 alpha**：3/5 日方向显著为负（价格/成交量加速越快，之后越容易反转，t≈−2.3~−2.9），10/20 日回到零附近。
2. **资金-价格同向关系（coupling/agreement）也接近零**：IC +0.003~+0.005，t<1.5，Q5−Q1 仅 0.06~0.09%，不能当方向预测。
3. **旧「资金流加速度」本身也很弱**：h5/h10/h20 IC +0.005~+0.006（t 1.4~1.8），只能作描述性温度计。
4. 因此**不建议**把热力图「加速度」替换成「量价加速度」并当作预测信号；会引入短期反转的负向暴露。
5. 产品处理：热力图新增**描述性**「量价共振」模式——资金加速与价格加速同向为红/绿（↑共振/↓共振），反向为琥珀（背离）；tooltip 明确写「描述性状态，历史统计不支持把它当方向预测」。原「加速度」从按钮中移出（仍保留在资金流速率卡与 block board 侧栏）。

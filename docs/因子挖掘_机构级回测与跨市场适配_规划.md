## 0. 目标（用户诉求逐条驱动）

用户原话：「因子挖掘的回测页面太简陋了，一点都不专业、需要像机构级别的回测、挖掘是沪深300，但是在样本外的市场回测、没有数据，或者不能批量回测？报告也没有？我挖掘到那么多因子，都不清楚适合哪些市场。需要您重新规划和设计这个回测部分、专业的量化机构级别。」

1. **回测页机构级重设计**——现状 = 一张永不渲染的死图 + 指标卡（见 §1.1），重做为「回测中心」。
2. **跨市场样本外回测**——CN（沪深300）挖出的因子，在 **US / HK / BC（加密）/ FUTURES（期货）** 上重算求值；数据契约适配是本规划的核心工程。
3. **批量回测**——因子 × 市场的组合批量派发、排队、续跑、熔断（服务端引擎，非前端队列）。
4. **机构级报告**——单因子 × 市场报告（概览/IC/分组/超额/稳健性）+ 矩阵导出（CSV/PDF）。
5. **核心产出 = 因子 × 市场适配矩阵**——回答「我挖的因子适合哪些市场」，含每因子最佳市场标注。

**已确认决策（2026-10-09，用户答复）**：
- ① 跨市场试点顺序 **US + HK 先行**，BC/FUTURES 实验性紧随；
- ② UI **沿因子挖掘栏目现风格升级**（alpha-research 玻璃拟态/深色语言 + ECharts 机构级图表 + 数据密集布局），不做另起炉灶的换肤；
- ③ **CN 必须与其它市场并排出现在对比矩阵中**（用户原话「A股也要别的市场也要对比的」）——CN 列 = 样本内基准（挖掘原始市场，沪深300），非 CN 列 = 样本外；
- ④ **排名、列表、回测数据呈现必须清晰**（用户原话「回测的排名、列表，都要清晰，回测数据这些」）——矩阵按所选指标全表排序（因子排名）+ 每市场列排名，run 级台账明细可筛可排，缺失一律「—」。

### 1.4 因子可移植性实测（本规划基石）

- 291 条因子（290 completed + 1 failed）**全部带 `factor_code`**（Python 源码）+ 文字公式 `factor_formulation`（自由文本，非可执行 DSL）。挖掘时全部 `market=a_share, universe=csi300`。
- 因子代码契约：自读 `daily_pv.h5`（MultiIndex[datetime, instrument]，`$` 前缀列）→ 写 `result.h5`（116 条显式 `read_hdf`；其余同契约变体）。
- **CN 富化 h5 = 39 列**（实测列头）：基础 7 列 `$open/$high/$low/$close/$volume/$amount/$factor` + 富化 32 列（`$turn_5/$turn_20/$idio_vol_20/$netflow_5/$netflow_20/$concept_hot/$float_mv/$total_mv/$beta_20/$bb_width/$mfi_14/$rsi_14/$macd_hist/$bp/$ep/$pe_ttm/...`）。
- **代码列 token 静态分级（290 完成因子全量精确统计）**：
  - **严格 6 列可移植**（`$open/$high/$low/$close/$volume/$factor`）：**175 条（60%）**；
  - **含 `$amount` 七列可移植：192 条（66%）**——五市场 bin 统一带 amount（§1.5 实测），此档全市场可跑；
  - **无显式 `$` 列引用：45 条（16%）**——动态/通用写法，静态判不穿，照跑裁决（失败记 error）；
  - **依赖富化列：53 条（18%）**——13 个列（`$turn_5`16 / `$turn_20`15 / `$idio_vol_20`12 / `$netflow_5`9 / `$concept_hot`8 / `$netflow_20`4 / `$float_mv`2 / `$bb_width`2 / `$beta_20`2 / `$turn_z_20`·`$bp`·`$ep`·`$mfi_14` 各 1），全为非 CN 不存在的 A 股微结构数据（换手/资金流/概念热度/筹码/特质波动）。
- **结论：静态可确认的跨市场候选 ≈ 192 条（66%），另 45 条待实跑裁决；53 条富化因子在非 CN = `data_unsupported`（诚实降级，不做近似替代）**——`$netflow_5` 这类市场结构数据在美股/港股本就不存在。
- 静态判据（列 token ⊆ 市场列集）可在**跑之前**给出 `data_unsupported`，免浪费算力（见 T-FB-02）。

## 2. 机构级设计要点（生产标准）

### 2.1 求值模型：一次「因子 × 市场」单元 = 契约装配 → 沙箱执行 → 指标/序列

```
[factor_code] × [market] × [window] × [cost_bps]
  → ① 市场档案（provider/universe/复权/基准/费率）        market_profiles.py
  → ② 兼容性分类（列 token ⊆ 市场列集；不兼容=免跑登记）    compat.py
  → ③ 数据装配：D.features（复权价+$factor）按窗口×universe 切片
        · CN：优先挖掘同源 39 列富化 h5（现状保留）
        · 非 CN：装配该市场可提供的同契约 h5（基础列、$ 前缀、同层序）
  → ④ 沙箱执行：subprocess 隔离（复用 alpha_agent 现成执行器：自执行式优先、零参函数式兜底）
  → ⑤ 指标：factor_report.metrics 纯函数层（IC/ICIR/NW t/PFS/成本网格/DSR…）
  → ⑥ 序列：净值/多空/分位/IC/换手/回撤 → 落库（图表与报告渲染源）
  → ⑦ 终态落账：ok / data_unsupported / insufficient / unavailable / failed（均带 reason）
```

### 2.2 诚实降级矩阵（状态机，绝不静默）

| 状态 | 触发 | 呈现 |
|---|---|---|
| `ok` | 求值完成 | 全指标 + 系列 |
| `data_unsupported` | 静态列依赖 ⊄ 市场列集 | 灰格 + 缺列清单（免跑） |
| `insufficient` | 有效日 < 阈值（默认 120）或截面覆盖不足 | 空值「—」沉底（沿工作台口径） |
| `unavailable` | 市场档案未就绪（provider/窗口空） | 灰格 + reason |
| `failed` | 执行异常 | 红格 + error 原文（可重试） |

**铁律**：缺失一律「—」，绝不显示成 0；不跨市场做「近似替代」（如拿成交量冒充资金流）。

### 2.3 市场档案注册表（单源 `market_profiles.py`）

每市场声明：qlib provider、universe 解析（默认值见 §1.5；非 CN 动态池=**按过去 60 日日均成交额 top-N** 逐日计算，避开前视/生存者偏差）、复权来源（$factor 或复权价列）、基准（缺失→等权全池基准兜底并在 UI 标注）、研究费率 bps（默认 20，可调）、数据窗口、最小历史天数。

### 2.4 批量引擎（服务端，样板 = 补码评估批）

- 派发：因子集（筛选/手选/全量）× 市场多选 × 参数 → `POST /batch`；**去重键 = (factor_id, market, window, cost)**，已有 running 背压。
- 排水：进程内串行（并发 env 可调，默认 1）；单元内核执行已在子进程 + `to_thread`（看门狗安全，沿 cf0e85e3 教训）；单元间让渡。
- 可靠性：**行终态回读定成败**（不按异常判）；连败 N 熔断保已完成；取消走标记不拆身份守卫；重启按行终态天然可重入（沿 9fb7dbc4 纪律：`run_id` 精确收口）。
- 可观测：进度端点（done/total/failed/当前单元）、矩阵页内嵌进度条、失败清单可导出重跑。

### 2.5 报告面（复用 metrics 纯函数层，不动 WIP）

单因子 × 市场报告 = 后端出标量与块（`brain_headline`、NW t、BHY q、DSR、成本网格、容量、半衰期、月度矩阵、滚动 IR）+ 前端从序列渲染五页签（概览/IC/分组/超额/稳健性）。超额块：有市场基准用基准，无则等权兜底 + `bench=equal_weight(fallback)` 标注。风格归因（CNE5）仅 CN，非 CN 显示不可用原因。

### 2.6 UI：回测页重做为「回测中心」（三区 + 钻取）

- **A 派发台**：因子多选（按库/筛选条件/手选）× 市场多选 × 窗口 × 成本 → 发起批量；实时进度 + 熔断提示。
- **B 适配矩阵（核心画面）**：行=因子、列=**CN + US/HK（+BC/FUT 实验性）并排**（CN 列=样本内基准，非 CN=样本外）、格=所选指标（RankIC / 扣费夏普 / 扣费年化 / 换手，切换器）；状态色 + 灰格降级；行内 **Best Market 徽标**；**排名视图**——全表按所选指标排序（因子排名）+ 每市场列内排名（市场适配排名）一键切换；筛选（库/状态/阈值）+ CSV 导出。
- **C 运行台账**：批次历史 + run 级明细（升级现有 BacktestHistoryPanel：补 market 展示与筛选、批次聚合）。
- **钻取**：点格 → 单因子×市场报告（五页签）；同因子跨市场叠加对比（净值/IC 多线）。
- 图表体系统一到 ECharts（`components/common/EChartsChart` + chartKit 模式），弃 recharts 死图；时间轴/缩放/导出对齐因子报告体验。

### 2.7 口径纪律（沿用全仓铁律）

- IC 口径与挖掘/现行回测**逐字一致**（`_vectorized_daily_spearman_ic` / `compute_factor_ic`）→ 矩阵与因子库指标可比。
- 窗口一致性两铁律（按天均值走请求窗口、累计型走全窗口；两轴各自配线）→ 报告块。
- 复权：收益一律用复权价（$factor 语义逐市场审计，见 T-FB-05）——**不做复权审计的跨市场 IC 是假数**。
- 时间列 TIMESTAMPTZ + `utc_now()`；前端展示按既有约定。

## 3. 数据模型

```sql
-- 台账扩展（启动 ensure 补列，照 rd_agent_persistence.ensure_tables 模式）
ALTER TABLE rd_agent_factor_backtests ADD COLUMN IF NOT EXISTS kind TEXT;         -- auto_mining | manual | cross_market | batch
ALTER TABLE rd_agent_factor_backtests ADD COLUMN IF NOT EXISTS params_json JSONB; -- {cost_bps, universe, universe_n, window, code_fp}

-- 序列表（图表/报告渲染源；run 级 1:1）
CREATE TABLE IF NOT EXISTS rd_agent_factor_backtest_series (
  run_id      TEXT PRIMARY KEY,
  factor_id   TEXT NOT NULL,
  market      TEXT NOT NULL,
  series      JSONB NOT NULL,   -- {dates[], ic[], ic_cum[], nav[], ls_curve[], q_curves{q1,q5,q10}, turnover[], drawdown[], coverage[]}
  created_at  TIMESTAMPTZ NOT NULL
);
```

  ±50% 未误杀；CN 零回归（新旧链同窗同池 ic/rank_ic/sharpe 逐位一致）。
- **T-FB-08/09 批量引擎实装语义**：
  - 去重键 `(factor, market, window, cost)` 的落法：窗口/费率是批次级常量，
    批内按 (factor, market) 先例去重；跨批次按**活跃 running 行**背压，且判据
    收敛到**因子粒度**（子进程登记以 factor_id 为键，同因子不得跨市场并发——
    比 (factor, market) 更强，宁严勿乱）。
  - 单元执行直接复用 `router._run_single`（取消/身份守卫/序列落盘与单发逐字
    一致）；成败一律**行终态回读**（`get_run`），内存不自造结论。
  - 熔断：连续 failed ≥ `QM_BACKTEST_MAX_CONSEC_FAILS`(默认 5) → aborted；
    data_unsupported/insufficient/unavailable 是适配结论，**重置**连败计数。
  - 重启可重入：启动 `resume_interrupted()` 扫 running 批次 + 状态轮询兜底
    重建；孤儿 running 行收口 `engine_restarted_mid_run` 且该单元**重试恰一次**
    （第二次再中断不再重试，防重启-重试死循环）。
  - 取消：杀当前单元（单发取消同一路径）+ 批次行收口；未启动单元不落行
    （诚实：它们从未运行）。批次收口幂等（端点与 drain 双路径先到先赢）。
  - 并发：`QM_BACKTEST_MAX_CONCURRENCY`(默认 1)；worker 以
    `_running_backtests` 占位表做同因子互斥（check→add 无 await）。
- **降级语义**：批级终态 `completed` 不等于全成功（失败计数与 failures 清单
  单列）；批次 `aborted` ≠ 用户取消 `cancelled`。

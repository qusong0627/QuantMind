# 市场分析 × 因子 × 预测 —— 因子概率板细案（v2 原型已验证）

> 日期：2026-10-11 · 状态：**已批准执行（机构级生产方案见 §六）** · 原型脚本：`probe_factor_board_v2.py`（仓根，商品化落点 P0）
> 本文所有数字均由原型在 2026-10-09 截面上实测，口径全部可复现（附录 A）。
> **2026-10-11 口径修正**：生产价格侧一律 `daily_forward`（qfq），见 §2.6。

## 一、问题定义（用户提出）

1. 市场分析现有看板 = **状态快照**（单日资金流、N 日累计），今天流入明天流出，**没有因子有效性、没有预测力**。
2. 要求从因子研究里挑「好的」因子（近效好、成功率高），做 **板块 / 个股 / 日期周期 × 分类** 的概率视图。
3. **反向因子也要用**——低分本身就是「大概率跌」的证据，双向都要能出名单。
4. **板块一致性规则**：若某板块的个股数据（因子 + 模型预测）普遍指向跌，则该板块不能选——大概率后面跌。反之个股层面普遍指向涨，才是可选的板块。
5. 让市场分析（含未来预测）与因子**紧密关联、更精准**。

- **共振看多** = 均分≥q67 ∧ 广度≥0.5 ∧ 模型广度≥0.55

### 2.6 复权口径复核（2026-10-11，生产切换 qfq）

原型最初用 `l1_factors` 自带 close 算前向收益，而该 close 由 `backfill_l1_ohlcv.py` 自 **`daily_backward`（hfq）** 回填——仓内已有铁证（`logs/` 2026-09-23 复核）：daily_backward 是逐分区拼接的不自洽序列，**跨分区比值（正是 T+5 前向收益）被污染**（600000.SH 跨缝日真实 −0.66% 算成 +3.09%）。生产价格侧切换到 `daily_forward`（qfq）后同窗全链重跑对照：

| 指标 | hfq（旧口径） | **qfq（生产口径）** |
|---|---|---|
| 过闸因子 | 306/349 | 314/349 |
| 入选 | 27（11正/16反） | 27（12正/15反，2 席互换：+`micro_liquidity_volatility`/`a101_088`，−`vol_persistence`/`a101_073`） |
| 个股 RankIC（近60评估日 fwd5） | +0.2318（ICIR 1.53，胜率 93%） | **+0.2381（ICIR 1.80，胜率 100%）** |
| 板块（行业二级）RankIC | +0.3126（1.23，88%） | +0.3139（1.26，92%） |
| 因子↔模型 Spearman ρ | +0.726 | **+0.748**（HH 365 / LL 449，交叉 19） |
| 行业二级判定 | 17多/14空/7+7背离 | 17多/14空/7+7背离（板块名单几乎一致） |
| 概念判定 | 56多/75空 | 57多/79空（「近期强势」系三层全负复现） |

**结论**：两套独立复权口径下全部结构结论一致（反向因子族、追涨陷阱形态、板块名单、四象限几乎不变），这本身是一份稳健性证据；qfq 是正确口径，生产一律 qfq，且把「close 非正计数」写进产物 meta 质检。

## 三、设计：市场分析升级为三层结构

```
L2 预测共振层   因子合成 × 模型信号 × regime  →  双向名单（靠前/回避）+ 背离清单
L1 因子概率层   27+ 精选因子（携 IC60/胜率/ICIR/持有期）→ 板块/个股/周期/分类概率板
L0 状态层       现有看板（资金流/情绪/热力）保留，标注「状态≠信号」+ 证据入口
```

### L1 因子概率板（新 Tab，只读）

- **板块视图**：行业（二级 73 / 一级 44）+ 概念（400）热力；每个板块给 均分 / 中位 / 个股广度 / 模型广度 / 判定 五元组。
- **个股视图**：全市场评分榜 + 共振四象限散点（因子分 vs 模型分位），默认剔 ST，标注所属行业。
- **周期视图**：全局与分族持有期条（1/2/5/10/20 日），回答"这个位置大概能走多久"。
- **分类下钻**：9 族（jq110 情绪 / gtja191 / alpha158 / alpha101 / alpha360 / tdxgs / L2 微观 / L1 生产 / rd 挖掘），每族给族内合成与代表因子。
- **体量限制**：每个数字带证据元数据（IC60、方向胜率、覆盖权重、样本内注记），**缺失一律 `—`，绝不显示成 0**。

### L2 预测共振层（核心 = 三层一致性）

- 同一评分两端：**靠前名单（大概率涨）** 与 **回避名单（大概率跌）**，不写买卖动词（展示面用位置词 + 共振/背离标签；执行词汇仅保留在交易执行面）。
- 个股：因子分位 × 模型分位四象限；HH/LL = 高置信，交叉象限 = 观察。
- 板块三层闸见 §2.5；**板块均分高但个股广度 <0.5（少数股拉分）→ 不入选**（用户规则 1）。
- regime 上下文：生产信号已带 `regime` 列，且 `backend/shared/market_regime.py` 是状态口径单源——P2 按 regime 分桶统计因子族 IC，做**状态化权重**（当前制度 = 反转/防守，追涨族权重天然为负）。

### 10.10 算法口径审计与图表化 v3（2026-10-29）

用户反馈「因子概率板多用图表，计算和算法口径对一下别出错」。本轮先审计后改图：

**已修的口径缺陷**
1. **ICIR 与 t 混用**：`selection.summarize_ic` 原把 `IC60/σ×√n` 写进 `icir60`，前端「ICIR」列实际显示的是 t（约放大 √60≈7.75 倍）。现改为 `icir60=IC60/σ`、新增 `t60=ICIR×√n`；净 IC 轨同改（`net_icir60`/`net_t60`）。与 `builder._validate`、`rolling._ic_agg` 的 ICIR/t 口径一致。
2. **板块广度分母含缺失**：`sector_table.fbreadth` 原用 `(s>0).mean()`，composite 为 NaN 时 `(NaN>0)=False` 被算进分母，系统性低估广度。现改为 `s.dropna()>0`。
3. **板块最小样本按总数而非有评分样本**：原 `n=size` 会把「8 只成分只有 2 只有分」的板块也送进三层判定。现新增 `n_scored=composite.count`，`n≥min_n ∧ n_scored≥min_n` 才判定；前端 `n` 悬停显示总成分/有评分成分。
4. **Top/Bottom 名单误删无模型覆盖标的**：`stock_lists` 原接收 `quadrant_frame` 的 `q`（已按双轴非空过滤），导致「合成分位 Top50」实际只含模型覆盖票。现改传全量 `stock`，Top/Bottom 按 composite 排序、无模型票保留（模型/象限显示「—」）；HH/LL 仍要求双轴。
5. **各库分区不同步时用残缺截面选因子**：各库落盘有先后（实测 2026-10-29 l1/l2 已到 10-28，其余五库仍 10-27）；原按 l1 最新日选因子，其余库整库剔除，入选骤降到 6（<硬门 10）。现 `common_factor_dates` 取候选库共同分区；10-28 只有 l1 时整体退到 10-27，并在 warnings 显形。
6. **重复 symbol/候选致 duplicate labels**：日线/因子分区内重复 symbol、`kept` 与 `rd_mined` 报告重复 `(lib,name)`，会让 `d[name]` 返回 DataFrame 并在 IC 对齐时抛 `cannot reindex on an axis with duplicate labels`。现装载时按 symbol/`(lib,name)` 去重（候选保留首行，优先联合筛选清单）。
7. **全部不过闸时 `pd.concat([])` 抛 ValueError**：现返回空表 + 由 `MIN_SELECTED` 硬门报 `BuildError`，错误可读。

**界面（图表优先，明细可切）**
- 板块共振：新增 **x=板块合成分 / y=个股广度 / 气泡=成分数 / 颜色=三层判定** 散点；q67/q33 与 50% 广度线直接画在图上，点击点位钻取成分股；原列表切「明细」。

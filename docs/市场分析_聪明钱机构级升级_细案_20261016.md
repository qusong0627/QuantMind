## 1. 目标与总设计

**一句话**：把「聪明钱」从**统计面板**升级为**机构级资金行为研究工作台**——
数据到席位级、分析到事件研究与战绩回溯、展示面图表化，全部过验证闸门。

四个正交能力（对应四条需求）：

| 需求 | 落点 |
|---|---|
| 机构级设计 | 席位级数据（D1/D2）+ 席位画像与胜率 + 行业聚合 |
| 带预测性 | 战绩追踪（历史选股已实现表现）+ 事件研究 CAR + IC 衰减/滚动 IC |
| 「历史那些聪明钱比较聪明，包括最近」 | 战绩追踪区三个视角：全窗累计超额曲线 / 近 10 日逐日案例（含进行中）/ 评分桶单调性；席位胜率榜标「最近窗口」 |
| 界面丰富·图表多·读得更简单 | ECharts 图表层（趋势/CAR/累计超额/分布）+ 服务端筛选分页 + 个股档案抽屉 |

**纪律不变（v1 继承，硬）**：
- `fwd_ret_*`（东财上榜后表现）封存——只展示、绝不可入信号（现有单测继续钉死）。
- 所有柱子（含新增候选）必须过双过闸（pass1 → build → pass2 三步），未过进否决清单公开展示。
- 缺失一律 null → 「—」，绝不补 0。
- 展示面/执行面用词纪律、「历史回溯统计（非预测）」标注照旧。
- 只动 CN 域 + `shared/smart_money/` + smart_money 脚本（美股分析文件禁区避让并行会话）。

## 3. 分析引擎 v2（`backend/shared/smart_money/analytics.py`，纯函数 + 金样）

统一口径：收益一律 `fwd(t,h) = close[t+h]/close[t+1] − 1`（T 盘后信号 → T+1 收盘
入场，与验证协议一字不差）；clip(-0.5, +1.0)；close 用 qfq `daily_forward`。
基准 = **全市场等权**（当日 daily_forward 全体标的等权收益，同窗口），
另有池内等权并列披露。所有输出只含「已实现」数据，未到期窗口标记 `in_progress`。

### 3.1 战绩追踪 `track_record(scores_hist, close, cal)` → `track_record.json`

「历史那些聪明钱比较聪明，包括最近」的核心面。逐评分日取 **top-10（score 降序）**：

1. **daily 序列**：每日 top10 等权 fwd h∈{1,3,5,10} 平均收益、全市场等权基准、
   超额（bp）、胜率（超额>0 占比）→ 累计超额曲线（逐日超额累加，h5 主口径）。
2. **区间统计**：全窗 / 近 60 交易日 / 近 20 交易日 / 近 5 交易日 四档：
   平均超额 bp、胜率、样本日数（诚实披露：近窗样本小）。
3. **最近案例**（含进行中）：近 10 交易日的每日 top-5 → `{date, symbol, name,
   score, entry_close, latest_close, ret_since_entry, status: 持有中|h10已实现, fwd: {h1,h3,h5,h10|null}}`。
4. **评分桶单调性**（机构级校验）：桶 [0,50) [50,70) [70,85) [85,100] × h5/h10
   平均超额与胜率 + 桶序 Spearman（单调=分有效，不单调如实披露）。

### 3.2 事件研究 `event_study(raw, close, cal)` → `event_study.json`

对四族事件按信号强/弱两组（族内当日截面分位 q5 vs q1），曲线 T+1..T+20：

| 族 | 强组 | 弱组 |
|---|---|---|
| 机构席位 | `inst_net_ratio` 日截面 q5 | q1 |
| 龙虎榜 | `net_ratio` q5 | q1 |
| 大宗 | `premium > 0`（溢价成交） | `premium < -5%`（深折价） |
| 调研 | `inst_count` q5 | q1 |

输出每族每组：`curve[{h, car_bp, n}]`（CAR=超额累计，相对全市场等权）+
n_days/avg_names。页面标注「历史回溯统计（非预测）」。

### 3.3 IC 衰减与滚动 IC（并入验证证据台）

- **衰减**：每个入柱 + 复合分在 h∈{1,2,3,5,10,20} 的 rank IC（全窗）→
  `evidence.decay = {name: {h: ic}}`；复合分同列。
- **滚动 IC**：复合分 h5 的 60 交易日滚动 IC 序列（200+ 点）→
  `track_record.rolling_ic[{date, ic}]`（展示分年稳定性/近月衰减）。

### 3.4 席位画像 `seat_stats(lhb_seat, close, cal)` → `seats.json`

逐席位（窗口 20/60/全窗三档）：
- 净买额合计、买入股数（净买>0 的 stock-day 数）、上榜天数；
- **胜率**：其净买个股 fwd h5 超额>0 占比 + 平均超额（bp）——「历史那些聪明钱
  比较聪明」的席位视角，最近窗口并列；
- 类型标签（§2.2 classify_seat）；代表性买入股（近窗净买最大 3 只）。

排序：默认近 60 日净买降序；前端可切 20 日/胜率排序。**披露**：胜率按席位
净买口径回算 ≠ 席位真实收益（不知其卖出时点），页面脚注注明。

### 3.5 行业聚合 `industry_flow(raw, margins+, cal, window=20)` → 并入 `latest.overview.industry`

20 日（机构净买 + 龙虎榜净买 + 机构专用大宗买入额）按行业求和
（industry 来自 instrument_detail.rs_hyname），Top±10 供横向柱状图。

### 3.6 新增柱候选（2 个，走同一闸门）

| 候选 | 定义 | 理由 |
|---|---|---|
| `dzjy_inst_amount_ratio_5d` | 机构专用买方大宗金额/流通市值（amount_ratio）5 日累计 | 机构借大宗接盘（明细层，v1 只有全口径） |
| `dzjy_inst_premium_5d` | 机构专用买方加权折溢率 5 日 | 机构接盘价格姿态 |

- 加入 `PILLAR_CANDIDATES` + 验证脚本 FAMILY（「大宗」族）；pass1 全窗 h10
  双过闸 + 相关塌缩（|ρ|>0.8 留强者）；过闸才入分，未过进否决清单。
- 复合分变化（若入柱增减）→ evidence.json 完整留痕 + §10 实施记录披露差值。

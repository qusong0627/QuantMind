## 5. 收益拆解与审计（摘要）

| 项 | 结果 |
|---|---|
| 14:50 → 当日收盘（尾盘+竞价） | **+0.054%**（胜率 32.7%） |

| 特征消融 | 仅分钟 +1.23%/日；仅日频上下文 +0.45%/日 |
| 规模/价格中性化 IC | 0.060 → 0.054（不是 beta） |

## 6. 风险与上线条件

1. **当前失效**：2026-10 月度 IC −0.066、20 日 IC 0.008、Top20 −1.44%（胜率 33%）。
2. **regime 阈值事后挑选**：20 日收益 > 0、回撤 > −3% 是在 2026 上选的，须前向验证。
3. **容量**：Top20 中小盘为主，百万级资金可行，千万级有冲击。
4. **执行**：14:51 出信号、14:51-14:52 下单；尾盘段收益≈0，延迟代价小。
5. **上线条件**：20 日 IC 回到 0.03+ → 影子跑 ≥2 周 → 5-10 万小资金验证滑点（目标 <0.2%）。

## 7. 复测方法（完整命令）

### 7.1 数据（已完成，若需重建）

```bash
# 2024-2026 分钟表（parquet 源）
bash scripts/build_l2_min1.sh 20240101 20251231
bash scripts/build_l2_min1.sh 20260101 20261231
# 2017-2022（7z 源，按需）
MIN1_BUILDER=7z MIN1_WORKERS=1 bash scripts/build_l2_min1.sh 20170101 20221231
# 质检
.venv/bin/python -m backend.scripts.minute_model.qc_min1_l2 --all
```

### 7.2 特征与面板

```bash
.venv/bin/python -m backend.scripts.minute_model.build_intraday_features --all --start 20240101 --end 20261231
.venv/bin/python -m backend.scripts.minute_model.build_panel --all --start 20240101 --end 20261231
```

### 7.3 训练（容器内，cat/xgb/lgb 都有）

```bash
DROP="order_n,big_order_n,cancel_n,order_trade_ratio,cancel_rate,order_rate_5m,cancel_rate_5m,big_order_ratio_5m,bid6,bid7,bid8,bid9,bid10,ask6,ask7,ask8,ask9,ask10,bidv6,bidv7,bidv8,bidv9,bidv10,askv6,askv7,askv8,askv9,askv10,bid_depth_10,ask_depth_10,book_ratio,wavg_bid_gap,wavg_ask_gap"
docker exec -i -w / -e PYTHONPATH=/app quantmind python -m backend.scripts.minute_model.train_intraday_model \
  --algo catboost --sample-frac 0.5 --label ret_4h --tag 4h_cat_live5 --drop "$DROP"
```

### 7.4 回测（容器内）

```bash
docker exec -i -w / -e PYTHONPATH=/app quantmind python -m backend.scripts.minute_model.backtest_intraday \
  --model lgb_4h_cat_live5.pkl --tag cat_live5 --cost 0.0015 --filter trend_dd
# 集成（可选）
docker exec -i -w / -e PYTHONPATH=/app quantmind python -m backend.scripts.minute_model.backtest_intraday \
  --models lgb_4h_live5.pkl,lgb_4h_xgb_live5.pkl,lgb_4h_cat_live5.pkl --tag ens_live5
```

### 7.5 衰减分析

```bash
docker exec -i -w / -e PYTHONPATH=/app quantmind python - < backend/scripts/minute_model/analyze_decay.py
# 输出：data/minute_model/model/decay_monthly.csv、decay_daily.csv
```

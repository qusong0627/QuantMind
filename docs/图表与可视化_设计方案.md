> 版本：v1（2026-09-15）　配套：`docs/前端界面设计_设计方案.md`、`docs/评估与打分体系_设计方案.md`
> 要求（用户明确）：**图表要专业，普通股民一看就觉得很专业**。
> 定位：图表是产品信任感的第一来源——K 线乱、曲线假、标注缺失，机构级后台也白搭。

## 二、"专业感"的十条具体标准（可走查）

1. **蜡烛图规范**：OHLC 正确、影线/实体比例标准、**涨红跌绿**（A 股口径，红=涨、绿=跌——全站唯一色规，与现有偏好一致）。
2. **成交量联动**：主图下方量柱，缩放/十字光标与主图同步。
3. **均线组默认**：MA5/10/20/60 四色，可增删；BOLL/MACD/KDJ 一键叠加（副图切换）。
4. **买卖点标注**：系统实际买卖点画在图上（B/S 标记 + 价格），**点击 marker 弹出"为什么"**（信号分数/触发规则/执行价）——这是"专业感 + 可信感"的核心，技术选型必须支持。
5. **十字光标信息条**：悬停显示 OHLC/涨跌幅/成交量/指标值，随区间统计。
6. **区间缩放与拖拽**：滚轮缩放、拖拽平移、区间选择（框选统计涨跌幅）。
7. **口径标注**：**复权口径必须标在图角落**（前复权/不复权/后复权），均价线口径注明——防"复权陷阱"衍生的用户误读（也是我们的历史事故类别）。
8. **数值格式统一**：价格两位小数；金额自动万/亿；百分比一位小数；涨跌颜色跟随红涨绿跌；大数不裸奔（1,234,567 → 123.46 万）。
9. **空态诚实**：无数据画空态说明（不画假线、不用平滑插值掩盖缺失）——对齐既有事故教训（前端 `null.toFixed` 白屏、假数据曲线）。
10. **密度与留白**：图表背景网格淡、数据流是主角；暗色/亮色双主题各自调校（不简单反色）。

## 三、技术选型

| 用途 | 推荐 | 理由 |
|---|---|---|
| K 线/分时 | **klinecharts**（或 TradingView lightweight-charts） | 金融图形原语齐全（蜡烛/指标/买卖点 marker/十字光标）、性能好、专业外观开箱即用；比通用图表库手搓 K 线专业得多 |
| 资金曲线/雷达/IC/分布 | 现有 ECharts（复用） | 通用图表现有生态，样式与全站统一 |
| 微型 sparkline | 轻量 canvas 或 ECharts 极简配置 | 列表性能优先 |

约定：**不手搓金融图**（用金融图形库）；通用图沿用 ECharts 并套统一主题 token（与现有外观统一）。

## 四、数据正确性（图表可信的前提）

| 规则 | 说明 |
|---|---|
| 后端给什么画什么 | 图表层不做业务换算（复权/单位换算在后端完成并入 payload 标注） |
| 缺失显式化 | 停牌/缺口 → 图上有断点/标记，不插值 |
| 实时更新策略 | 分时/盘中图增量 append + 定期全量校准（防漂移）；节流刷新（≤1 次/秒） |
| 快照一致性 | 图上任意点 ↔ 数据行可下钻（接交易台下钻链路） |
| 性能预算 | 单图 1 万根 K 线流畅缩放；页面首屏图表 < 1.5s |

---

## 五、图表与"翻译层"的配合

- 简单模式：K 线只留价格+成交量+买卖点；专业模式：叠加指标、回撤水下、IC/分层。
- tooltip 文案走术语翻译层（"热度排名 前 2%" 而不是裸 `rank 0.98`）。
- 评分雷达：每维悬停给"人话解释 + 本项得分依据"。

# 风险控制体系设计方案（生产级）

> 版本：v1（2026-09-15）　配套：`docs/统一交易栈_设计方案.md`（v3）、`docs/模型量化细则_设计方案.md`
> 定位：量化交易栈的"生存系统"。目标——**任何单点故障、任何极端行情、任何人为误操作，都不能造成不可接受的损失**。
> 设计立场：风控不是"功能"，是"基础设施"。宁可误杀（拒绝一笔正常单），不可放行（漏过一笔致命单）。

---

## 一、设计原则（生产级风控六条）

1. **Fail-Closed（拒绝优先）**：风控服务不可用、超时、状态未知 → **一律拒绝**，绝不"降级放行"。现有 mirror 的 kill switch 已按此语义设计，全体系推广。
2. **分层防御（Defense in Depth）**：七级防线独立生效，任一级可单独拦停（不依赖上游做对）。
3. **配置即代码、变更即审计**：所有规则参数在 PG 有版本、在 Redis 有热副本；每次变更记录"谁/何时/改了什么/为什么"，关键项双人复核。
4. **可观测、可演练**：风控自身的指标（拦截率/误杀率/延迟）与业务同等监控；一键停机/恢复每季度演练。
5. **先影子后生效**：新规则先在影子模式运行 N 个交易日（只记录拦截不执行），误杀率达标才转正式。
6. **规则可解释**：每笔拦截必须给出：规则 ID、计算依据、快照值。拦截记录全量落库，可回放复盘。

## 二、七级防线总览

```
订单流 →
 ┌ L0 系统级：kill switch（急停）· 全局熔断 · 交易日/时段校验
 ├ L1 账户级：资金/保证金 · 仓位上限 · 集中度 · 日内亏损限额 · 杠杆
 ├ L2 策略级：策略限额 · 回撤闸 · 连亏熔断 · 白/黑名单 · 生效状态
 ├ L3 订单级：单笔限额 · 价格偏离 · 频率/撤单率 · 自成交 · 整手校验
 ├ L4 标的级：涨跌停 · 停牌/ST/退市 · 流动性 · 黑名单
 ├ L5 市场级：大盘熔断 · 极端行情 regime · 流动性枯竭 · 板块异常
 └ L6 数据/模型级：行情陈旧 · tick 跳变 · 信号异常 · 契约不符
 → 通过 → OrderRouter → 撮合/券商
```

任一级判 **REJECT** 即终止（fail-closed）；判 **WARN** 记录并继续；判 **HALT** 触发全局状态机迁移。
风控状态机四级：`NORMAL → CAUTION（降仓）→ RESTRICT（只卖不买/限频）→ HALT（全停+撤单）`，迁移规则见 §四。

## 三、规则库（按级展开，含 A 股生产参数示例）

### L0 系统级

| 规则 | 触发 | 动作 | 参数示例 |
|---|---|---|---|
| 急停开关（kill switch） | 人工/监控触发 | 全部撤单 + 禁止新单 | Redis 热键 + 环境变量双通道，fail-closed |
| 全局熔断 | HALT 状态持续 / 连续异常 | 同上 + 告警升级 | — |
| 交易日/时段校验 | 非交易日、集合竞价禁时段、收盘后 | 拒单 | 集合竞价时段按交易所规则配置（09:20–09:25 不可撤单等） |
| 时钟漂移 | 与交易所时间偏差 > 500ms | 拒单 + 告警 | 实时轨必需 |

### L1 账户级

| 规则 | 说明 | 参数示例 |
|---|---|---|
| 可用资金校验 | 买入金额 ≤ 可用资金（含费用冻结） | 硬校验 |
| T+1 可卖量校验 | 卖出 ≤ available_volume | 硬校验（已有） |
| 总仓位上限 | 市值/总资产 ≤ X%（随市场状态动态） | NORMAL 95% / CAUTION 60% / RESTRICT 40% |
| 单票市值上限 | 单票 ≤ 总资产 15% | 可随流动性档调整 |
| 行业集中度 | 单行业 ≤ 30% | 申万一级 |
| 日内亏损限额 | 当日亏损 ≥ X% → 当日停止交易 | -3%（可配）；-5% → HALT |
| 回撤限额 | 账户/策略回撤 ≥ X% → 降仓；≥ Y% → 停 | -10% 降半仓 / -15% 停 |
| 杠杆/保证金 | 融资账户维持担保比例 | 已有 margin_monitor_service |
| 净敞口 | 多空净敞口限额（未来多空策略） | — |

### L2 策略级

| 规则 | 说明 |
|---|---|
| 策略状态校验 | 仅 `SIM/LIVE` 状态策略可下单；DRAFT/VERIFIED 拒（修"未验证策略可上线"） |
| 策略白名单/黑名单 | 哪些策略可上模拟/实盘（沿用 mirror 白名单机制，空=全否） |
| 策略级连亏熔断 | 连续 N 笔亏损 → 暂停策略 + 告警（默认 N=5，可配） |
| 策略级限额 | 单策略下单笔数/金额/标的数（已有 mirror 限额：单笔 1 万/日 5 万/日 5 标的/日 20 单） |
| 策略-模型契约 | Model Contract 校验（lag/horizon/池/特征）不符 → 拒（见模型细则 §二） |
| 上线冷静期 | 新策略/新参数上线前 N 日仅小仓（观察仓） | 

### L3 订单级（高频校验，目标 < 1ms/单）

| 规则 | 说明 | 参数示例 |
|---|---|---|
| 价格偏离闸门 | 委托价 vs 最新价偏离 | ±2%（强平单除外但保 sanity 上界，mirror 已有） |
| 陈旧价拒单 | 取价时间戳早于 N 秒 | 市价单 >5s 拒绝（已有即时路径，托管路径补上） |
| 单笔金额上限 | — | 单笔 ≤ X 万 |
| 下单频率 | 单账户 N 单/秒、M 单/日 | 20/日（mirror 口径） |
| **撤单率** | 当日撤单/委托比 | ≤ 40%（触发后限频；交易所监管口径参考 WonderTrader 通道流量风控） |
| 自成交防范 | 同账户同标的买卖方向冲突检测 | 拒后单 |
| 整手/零股 | 买入整手（科创板 200 股）、卖出允许零股清仓 | 硬校验 |
| 涨跌停价委托 | 涨停价买入/跌停价卖出 = 按盘口排队，需显式允许 | 策略级开关 |
| 重复单 | client_order_id 幂等 + 指纹去重（N 秒内同参数单） | 硬校验 |

### L4 标的级

| 规则 | 说明 |
|---|---|
| 停牌/复牌首日 | 拒单（复牌首日波动异常，默认黑名单可配） |
| ST/风险警示/退市整理 | 默认拒；ST 涨跌幅口径（2026-07-06 起 10%，见数据字典） |
| 次新股 | 上市 N 日内（默认 60）拒 |
| 流动性闸门 | 下单量 ≤ 近 N 分钟成交量的 X%（默认 10%）；日均成交额 < Y 拒 |
| 标的黑名单 | 人工维护 + 事件驱动自动加入（立案调查/严重负面新闻 → 见 L6 新闻 veto） |
| 北交所/特定板块 | 按策略 universe 白名单硬隔离 |

### L5 市场级（regime 联动）

| 规则 | 触发 | 动作 |
|---|---|---|
| 大盘熔断 | 指数日内跌幅 ≥ X%（如 -3%/-5%/-7%，参考交易所熔断规则 + 自定义更严档） | HALT + 全撤 |
| 跌停家数异常 | 全市场跌停家数 ≥ N（如 300） | RESTRICT（只卖不买） |
| 涨停家数异常繁荣 | 触发追高风险降档（防 2024-02 式顶部满仓） | CAUTION |
| 大盘均线规则 | 上证 < MA20 | 只卖不买（已有 TDX 滚动口径，推广为全局默认） |
| 流动性枯竭 | 全市场成交额较 20 日均值 < 60% | CAUTION |
| 波动率极端 | 指数波动率分位 > 95% | CAUTION/降仓 |
| 日内 regime | 盘中市场状态服务（§情报总线）输出 | 驱动仓位系数（1.0/0.5/0.3/0） |

### L6 数据/模型级

| 规则 | 触发 | 动作 |
|---|---|---|
| 行情陈旧 | tick/快照延迟 > N 秒（实时轨默认 10s） | 该标的拒单 + 告警 |
| tick 跳变 | 单 tick 价格变动 > X%（如 ±10%，相对前 tick） | 判为异常数据，拒单 + 标记数据质量 |
| 买卖盘口异常 | 盘口倒挂/空盘口 | 拒单 |
| 信号异常 | 当日信号分布坍缩（BUY 或 SELL 占比 > 95%）、全 HOLD（2026-08 事故模式） | 告警 + CAUTION（不自动交易异常信号） |
| 模型异常 | 滚动 IC 触发 / PSI 越限（见模型细则 §六） | 降仓/停用建议 |
| 契约不符 | 特征 hash/池/lag 不匹配 | 拒运行（训练/推理/回测三入口） |
| 新闻风险事件 | FinBERT 风险事件分级 ≥ critical 且标的命中 | veto 买入（策略开关 `risk.veto.news_event`）+ 告警 |

## 四、风控状态机与自动动作

```
NORMAL ──(CAUTION 条件)──→ CAUTION ──(恶化)──→ RESTRICT ─(HALT 条件)──→ HALT
   ↑                          │                    │                     │
   └────── 人工恢复 / 条件解除（需确认）────────────┴─────────────────────┘
```

| 状态 | 允许 | 自动动作 | 恢复条件 |
|---|---|---|---|
| NORMAL | 全部 | — | — |
| CAUTION | 降仓至 60%，新开仓减半 | 告警 + 交易台黄灯 | 条件解除且人工确认 |
| RESTRICT | 只卖不买、限频 | 告警升级 + 禁买锁置位 | 同上 |
| HALT | 全停 | **全撤未成交单** + 禁新单 + 升级告警（钉钉/短信） | 人工确认 + 双人复核 |

**"全撤"的实现**：OrderRouter 提供 `cancel_all(account, scope)`，模拟/影子/实盘三环境同接口（实盘走 QMT 撤单通道，需压测验证撤单时延）。
**状态持久化**：Redis 热状态 + PG 审计表（状态迁移全历史）；进程重启后从 PG 恢复（防"重启即遗忘风控状态"）。

## 五、执行架构（怎么落到系统里）

```
所有下单路径（托管/手动/沙箱/镜像/实时事件）
        ↓
  ┌────────────────────────────────────────────┐
  │ RiskGate（唯一入口，fail-closed）            │
  │  1. L0→L6 逐级检查（规则引擎，配置驱动）      │
  │  2. 输出：PASS / REJECT(规则ID+依据) / WARN  │
  │  3. 拦截落 risk_events 表（审计+可回放）     │
  └────────────────────────────────────────────┘
        ↓ PASS
   OrderRouter → 撮合/券商
```

- **前置机语义**：RiskGate 是进程内同步调用（<1ms）；跨进程场景（沙箱/镜像）通过内部 API，**超时即拒**。
- **规则引擎**：规则 = {id, level, condition(DSL/表达式), action, params, market, enabled, shadow}；DSL 用现有个股终端的表达式引擎（`tag_rules`）复用，禁止写死在代码里。
- **配置存储**：PG（版本 + 审计）+ Redis（热读）；生效有"配置版本号"，风控决策记录当时版本。
- **市场差异**：规则带 `market` 维度（涨跌停/整手/费用/时段按市场适配器取，避免 A 股规则误套港股）。
- **性能预算**：订单级检查 P99 < 1ms；快照级全市场扫描（L5/L6）< 100ms/轮（3s 节拍内富余）。

## 六、生产级运维要求

| 维度 | 要求 |
|---|---|
| 高可用 | RiskGate 无状态（状态在 Redis/PG）；服务不可用=拒单（fail-closed），恢复后自动续 |
| 变更管理 | 风控参数变更：单人在测试环境验证 → 影子模式 N 日 → 双人复核 → 生效；紧急放宽需留痕 |
| 审计 | 每次拦截/放行/状态迁移/配置变更全量落库，保留 ≥ 3 年 |
| 监控（风控自身） | 拦截率/误杀率/检查延迟/规则命中分布/状态机迁移次数；误杀率 > X% 告警（防规则过敏） |
| 告警分级 | info（入交易台）→ warn（钉钉）→ critical（钉钉+短信+电话升级路径） |
| 演练 | 每季度：一键停机、全撤、状态恢复、fail-closed（杀 RiskGate 进程验证拒单）；演练报告归档 |
| 测试 | 规则单测（每条规则正反用例）；故障注入（数据乱序/延迟/缺失）；压测（10x 峰值订单）；影子回归（新规则历史回放对比） |

## 七、与模拟盘/实盘的关系

- **同一套规则，三种环境同语义**：模拟盘拦截原因必须与实盘一致（模拟盘是风控的"免费演练场"）。
- **模拟→实盘梯度**：实盘上线前，风控影子模式跑满 N 日且拦截分布与模拟一致。
- **镜像链路**：模拟成交 → 真单镜像的既有闸门链（白名单/2% 偏离/限额/熔断）并入本体系，不另起一套（消除"两套风控口径"）。
- **QMT/通达信桥**：通道侧限频/撤单率控制（借鉴 WonderTrader 通道流量风控）为 L3 增补项。

## 八、验收清单（生产级判据）

- [ ] RiskGate 覆盖全部 5 条下单路径（托管/手动/沙箱/镜像/实时事件），无旁路
- [ ] fail-closed 实测：杀风控进程 → 订单被拒（不是放行）
- [ ] 规则库 L0–L6 每条有：配置、单测、拦截落库、交易台可见
- [ ] 状态机四级迁移 + 自动动作 + 人工恢复全链路实测
- [ ] 全撤（三环境）实测：下单压测中触发 HALT，未成交单 100% 撤销
- [ ] 影子模式机制可用（新规则先影子 N 日，误杀率报表）
- [ ] 一键停机/恢复演练通过并归档报告
- [ ] 风控决策记录含配置版本号，可回放复盘
- [ ] 误杀率/拦截率监控接入交易台；告警分级链路实测

# 筹码结构 · 主力/散户成本与 14% 低分位（2026-10-29）

## 回答的问题

1. 主力、散户的成交加权平均成本在哪；
2. 成交量最大的价格带（POC）、70% 价值区（VAL~VAH）；
3. 14% 低分位成交价（潜在低吸位）与 −14% 回撤位；
4. 日内成交最集中的时段（仅当本地分钟数据跟得上日线）。

## 口径

- **主力** = 超大单 + 大单；**散户** = 中单 + 小单。
- 个股：日 VWAP = 成交额 / 成交量；指数：无逐笔席位，用指数日典型价（高+低+收）/3，资金流取**全市场**同口径，明确标注 `cost_scope=全市场`。
- **成本 = 窗口内逐日净额累计的「净头寸成本」**（不是「净流入日加权」）：
  - 净额 > 0 视为买入、< 0 视为卖出；
  - 同向加仓按金额加权；卖出只减少头寸，不改变剩余头寸成本；翻仓时剩余部分按当日 VWAP 重新开仓；
  - 窗口起点按零仓，期末净额 > 0 为多头、< 0 为空头（散户在 A 股不能裸卖空，负值按「净卖出/卖出均价」解读，不当作真实空头持仓）。
- **双边成本带**（只作对照，不参与主成本）：净买日 VWAP 加权、净卖日 VWAP 加权、全活动（|净额|）加权。
- **两组净额不互补**：主力（超大+大单）与散户（中+小单）都是「主动成交金额」分桶，不是同一笔交易的多空两边；同一天两组可以同时净买入或同时净卖出，因此不能把散户净额简单当成主力净额的反数。
- **关键局限**：L2 日频只有按单笔金额分桶后的**净额**（`flow_super/large/medium/small_net`），没有分桶的买入额/卖出额；同日双边买卖会相抵，无法还原真实双边成交。精确成本需逐笔委托/成交（tick/order）按主动方向与订单大小重算。
- **成交价格分布**：每个交易日的成交额在 [low, high] 区间内均匀摊到 24 个价格箱；POC=成交额最大箱；价值区=围绕 POC 累计 70% 成交额；14%=从最低价向上累计成交额 14% 的分位价。
- **−14% 回撤位** = 窗口最高价 × 0.86（另给，不与 14% 分位混淆）。
- **日内时段**：本地 `min5_kline` 若最新日期落后日线超过 7 天，则明确不可用，不用旧数据冒充当前；当前实测本地分钟数据停留在 2026-07-24，故时段字段为不可用。
- 回看：`/volume-profile?symbol=...&window=...&date=YYYY-MM-DD` 只用该日及以前数据。

## 接口

`GET /api/v1/market-analysis/volume-profile?symbol=000300.SH&window=60[&date=YYYY-MM-DD]`

返回：`last/high/low`、`vwap`、`market_vwap`、`main_cost/retail_cost`（净头寸成本）及 `main_cost_kind/retail_cost_kind`（long/short/flat）、`main_net_yi/retail_net_yi`、`main_premium_pct/retail_premium_pct`、`main_buy_cost/main_sell_cost/main_activity_cost` 与散户同名字段、`poc/vah/val`、`p14_price`、`drawdown14`、`high_nodes`、`profile[24]`、`time_windows`、`method`、`position_note`。

## 价值区（黄色柱）怎么读

- **黄 = 70% 价值区**：窗口内 70% 的成交额落在 VAL~VAH 这个价格带；红 = POC（成交额最大的单一价格箱）；灰 = 其余成交价。
- **带宽** = VAH/VAL − 1。越窄 = 筹码越集中；越宽 = 筹码越分散。
- 现价在带**下方**：带内筹码整体浮亏，下沿是上方第一道套牢/反弹压力；现价在带**内**：多空共识区；现价在带**上方**：带内筹码获利，上沿转支撑。
- 边界是**价格带**，不是精确点位；日 OHLC 在 [low, high] 内均匀摊布是近似，不能当逐笔成本。

## 准确度边界（HS300 2016-2026 快速检验）

用 60/120 日滚动价值区、非重叠采样，统计“现价在带下方/带内/带上方”的后续收益：

| 窗口 | 位置 | T+5 均值 / 上涨占比 | T+20 均值 / 中位 / 上涨占比 |
|---|---|---|---|
| 60日 | 带下方 | +0.33% / 56.5% (n=124) | +0.59% / **−1.03%** / 44.7% (n=38) |
| 60日 | 带内 | +0.01% / 53.1% (n=286) | +0.44% / +0.17% / 53.0% (n=66) |
| 60日 | 带上方 | +0.03% / 44.0% (n=100) | −0.38% / −0.94% / 45.8% (n=24) |
| 120日 | 带下方 | +0.16% / 54.0% (n=126) | +0.25% / **−1.48%** / 38.7% (n=31) |
| 120日 | 带内 | +0.03% / 52.8% (n=271) | +0.70% / +0.49% / 55.2% (n=67) |
| 120日 | 带上方 | +0.21% / 47.5% (n=101) | −0.40% / +0.82% / 51.9% (n=27) |

结论：**没有稳定的单调优势**。带下方 T+5 上涨占比略高（56.5%），但 T+20 中位仍为负（−1.03%），说明“跌破价值区就买”不是可靠信号；它更适合做**位置/成本结构**描述，不是独立方向预测器。

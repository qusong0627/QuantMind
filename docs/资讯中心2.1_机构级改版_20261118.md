# 资讯中心 2.1 — 机构级改版（2026-11-18）

> 目标：把 2.0 从「能看」推到「像机构资讯台」：多市场、模型可选、标签可解释、
> 新闻可读、事件后走势可证、订阅可自动化。  
> 依据：`PRIOR_CONCLUSIONS_DETAILED_20261118.md` / `REPORT.md` / `NEXT_RESEARCH_SECTION.md`

## 4. 标签与决策（研究口径，必须在界面里讲清楚）

### 4.1 匹配层级

| 层级 | 判据 | 用途 |
|---|---|---|
| L1 代码 | 标题/摘要出现代码 | 最高置信，个股事件 |
| L2 标题主体 | 公司名在标题且非作者/媒体 | 高置信，个股新闻强度 |
| L3 正文提及 | 只在正文出现 | 只做热度，不做个股判决 |
| L4 实体情绪 | 仅 enrichment 命中 | 背景 |

### 4.2 事件分类

- 硬利空：财务造假、立案调查、退市风险、债务风险、事故停产、制裁关税、监管处罚
- 软利空：业绩风险、减持解禁、质押、诉讼、舆情
- 硬利好：中标、订单、业绩预增、净利润增长、扭亏、回购、增持、分红、并购、重组
- 治理利好：股权激励、战略合作
- 泛利好/泛利空：只有情绪，没有硬事件

### 4.3 决策卡（研究回测唯一通过的口径）

| 条件 | 等级 | 界面用语 | 证据 |
|---|---|---|---|
| 硬利空 & pre5>5% | P0 | 硬利空 · 高位 | T+1 回避 +186.8bp/事件，t=2.81 |
| 硬利空 & 2~5% | P1 | 硬利空 · 中位 | -82bp，p=0.106，只观察 |
| 利好 & pre5>5% | P2 | 利好 · 高位（不追） | 5 日 -103bp |
| 软利空 & -2~5% | WATCH | 软利空 · 反弹区间 | +78~+133bp，不追空 |
| L1 & 利好 | WATCH | L1 利好 · 观察 | 一分钟 +8.6bp，只观察 |
| 其他 | INFO | 信息 / 利好·不追 / 软利空·观察 | 无动作 |

### 4.4 降权因子（界面「依据」里显示）

- 转载层 ≥3 → 更差（泛利好 3+ 层 -107bp，t=-4.14）
- 同题 6h 重复 → 折叠
- 聚合页/热榜 → 降权
- 来源质量：财联社电报 -262bp、东财快讯 -298bp；新浪 +172bp、人民日报 +171bp
- 投机稿 → 降权；`n_speculative` 高位 → 风险 overlay（不做方向）

### 4.5 Do-Not-Redo（方法论页固定展示）

看到利好就买 / 板块利好追涨 / L2 当 L1 / 主题生命周期 / 跨市场映射 / 评级当买点 /
快讯热榜当 alpha / 情绪当大盘方向。

## 5. 事件后走势（Event Study）

- 入口：新闻行「走势」按钮 / 阅读抽屉。
- 计算：以新闻发布日 `D` 为 T0，取 `D-1..D+5` 日线收盘；
  `ret_k = close(D+k)/close(D-1)-1`；同时给每日涨跌幅柱。
- 数据：`GET /api/v1/market/kline`（A/HK/US 已支持）。
- 视觉：红涨绿跌；T0 竖线；柱 = 每日涨跌，线 = 累计；下方标注 T+1/T+3/T+5 累计。
- 边界：不是回测，未扣费、未排涨跌停；只用于「这条新闻后来发生了什么」的证据展示。

## 8. 视觉方向（机构资讯台）

- **不是卡片瀑布**：左市场轨 + 顶部 KPI 带 + 中间时间轴 + 右侧证据栏。
- **颜色语义**：市场色（A 靛蓝 / HK 青 / US 琥珀 / 期货 石板灰）；
  涨跌仍红涨绿跌；决策等级用红/琥珀/板岩灰。
- **数字醒目**：KPI 用 32–40px 大数；表格数字等宽。
- **图表**：30 日热度柱、方向条、决策分布、价格 sparkline、事件路径。
- **阅读**：正文抽屉宽 520px，标题 18px，来源/时间/标签一行；正文可滚动。
- **解释**：每个标签 hover 有 tooltip；方法论页给出定义+研究数字+用法。
- **响应式**：1440 三栏；<1180 收右栏；<900 单栏。

## 12. 2.2 追加（2026-11-18 晚，按用户实测反馈）

### 12.1 准确性：三个「看起来像新闻、其实不是」的源

| 类型 | 例子 | 旧计数（30 日） | 修正后 | 处置 |
|---|---|---:|---:|---|
| 出版方自己的域名 | 同花顺 300033 / 10jqka | ~3,861 | 5 | `publisher_conflict` 只剔 L3/L4；L1/L2 公司自身新闻保留 |
| 采购/招标平台 | 中国电建 601669 / 电建采购网 | ~5,600（90 日 16,796） | 11 | `article_is_noise`（域名 + 公告体标题） |
| 高歧义名称 | 线上线下 300959 / 农产品 / 老百姓… | 157 条提及 | 157 条提及，但 `ambiguous=true`，风险/决策 0 | `AMBIGUOUS_TICKERS` 强制「提及」，不进股票榜 |

结论：之前那屏「3861 条 / 立案调查 145」不是这家公司的新闻，是**媒体域名 + 多票稿件 + 高歧义名**的叠加；现在风险/决策计数按主体口径收敛。

### 12.2 右侧统计可点击筛选

- 方向（利好/利空/中性）、决策等级（P0/P1/P2/WATCH/INFO）、风险类型（立案调查/业绩风险/…）、主体（L1/L2）、投机稿：点击即筛，再点取消；顶部显示筛选 chip + 清除全部。
- 后端 `GET /stocks/{code}/news` 支持 `direction / decision / risk_type / subject_only / spec_only`，不是在 200 条前端切片里过滤。

### 12.3 阅读抽屉：K 线 + 成交量

- T-5..T-1（新闻前）+ T0..T+5 蜡烛图（OHLC，红涨绿跌）+ 成交量柱。
- 关键节点表：节点 / 涨跌 / 收盘 / 成交量 / 量比。
- 新闻日量比 = 当日量 / 新闻前 5 日均量；后 5 日均量比 = 后 5 日均量 / 前 5 日均量。
- pre5 读数与「利好落地 / 已跌透」提示（研究口径）。
- 仅 L1/L2 展示；L3 明确不挂个股走势。

### 12.4 版面

- KPI 读数移到顶栏、市场轨之后、模型选择之前。
- 板块雷达行：排名 + 新闻数 + 风险 + 方向条 + 偏多/偏空占比 + 投机占比。
- 研究口径不再单独占一个视图：改为右侧抽屉，并在每日推理/个股档案右栏固定「研究口径 · 重点」卡（P0/P2/WATCH 三条 + 完整口径链接）。

### 12.5 市场区分

- 个股档案左侧股票列表按市场拉取（A/港/美各自），港股/美股不再显示 A 股。
- 每日推理对模型批次做市场过滤；批次不是该市场标的时明确提示换模型。
- 我的订阅按市场过滤；实盘自动订阅仅 A 股。
- 主题雷达的 top tickers 只保留当前市场代码。

## 13. 2.3 追加（2026-11-19 凌晨，按用户实测反馈）

### 13.1 单位与口径
- 资金流接口单位是 `yuan`（`meta.unit`），前端统一换算成「亿」显示：板块雷达 `主力 +30.58亿`、个股头部 `主力5日 +2.32亿 / 1日 +0.61亿`、右栏「主力5日」同步。
- 板块雷达 `top_sectors` 曾被传成 300，超过路由上限 `le=30` 直接 422 → 板块流全空。改传 30；`sectors[]` 仍是全集，足够给整张榜配资金流。

### 13.2 个股档案：关键词检索
- 新增 `GET /api/v1/news-intel/stocks/search?q=&market=&days=`：三路合并 ①代码直配 ②股票名/别名模糊匹配（`stocks.name` / `stock_aliases.alias`）③新闻标题命中该词的标的按命中篇数聚合。
- 返回 `is_code / is_name` 标记；唯一命中或唯一名称命中（如「茅台」→ 贵州茅台）直接开档案，否则左栏列候选，点选进入。
- 代码形态（6 位/`600519.SH`/`0700.HK`）仍直达档案，不走检索。

### 13.3 我的订阅：实盘 + 模拟盘
- `POST /subscriptions/sync-positions` 同时读：
  - 实盘：`real_account_snapshots.payload_json.positions`（近 3 日，`volume>0`）→ `source=live`
  - 模拟盘：`simulation_position_lots`（`quantity_remaining>0 AND status='open'`）→ `source=sim`
- 同一标的两个来源都持有时按实盘记；返回 `{synced, live, sim, symbols}`。
- UI：按钮改「同步持仓」，提示 `已同步持仓 80 只（实盘 14 · 模拟盘 66）`；订阅分「实盘自动 / 模拟盘自动 / 手动置顶」三段，模拟盘徽标 `is-sim`。

### 13.4 非 A 股每日推理：不再留白
- 模型批次不覆盖当前市场（或该模型暂无已完成批次）时，每日推理直接落「新闻优先」的个股档案板，顶部琥珀提示原因；新闻、结构、资金流、订阅照常可用。
- 港股推理表里是裸 4 位码（`2380`），统一经 `toMarketSymbol` 规范成 `2380.HK` 再进新闻接口（旧版会 400）。
- `marketSymbol.marketOf` 补规则：裸 4–5 位码与 `HK00700` 形态都判 HK，避免切港股时模型榜被过滤空。

### 13.5 切模型 → 截面重排
- 根因是后端 `GET /models/inference/latest` 忽略 `model_id`，所有模型都返回 Redis 里全局「当前生效」的那一个 run，导致切模型后榜单/截面不动。
- 新增 `per_model=true`：按 `model_id` 取该模型最近一个 `completed` 批次；**默认 false 保持交易侧「当前生效批次 + matched_model」语义不变**。资讯中心的每日推理与个股档案用 `per_model=true`。
- 个股档案左栏新增「新闻优先 / 模型排名」切换；模型排名直接展示该模型最近批次的 `#名次 + 分数`，切模型即重载。

# 盘中强势 → 隔夜持有：策略说明与验证记录

> 日期：2026-11-25 · 数据：`l2_min1` 全市场分钟表 2017-01-03 ~ 2026-11-17 · 脚本与产物在 `data/tmp/strict_t20/`
>
> **一句话**：14:30 找出「温和上涨 + 全天站上均价线 + 此刻创全天新高 + 已连续多日创新高」的股票，14:31 买入、**次日开盘卖出**。全部收益在隔夜段，当天卖必亏。

---

## 一、结论摘要

| 口径 | 日均只数 | 隔夜超额 | t | 超额胜率 |
|---|---|---|---|---|
| 追最强 30 只（按 09:30→14:30 涨幅） | 30 | **-0.589%** | -25.0 | 22.5% |
| 涨幅 ≥5% | 129 | **-0.489%** | -31.3 | 18.1% |
| 涨幅 3~5% + ≥80% 时间在均价线上 | 153 | -0.143% | -16.6 | 33.3% |
| **+ 14:30 创全天新高（V6）** | 11.9 | **+0.393%** | 9.89 | 64.3% |
| V10：再 + 连续 2 日上涨 | 4.2 | +0.631% | 8.52 | 60.8% |
| V11：再 + 连续 3 日上涨 | 3.2 | +0.736% | 7.29 | 60.8% |
| V12：再 + 连续 2 日创 20 日新高 | 2.0 | +0.958% | 7.00 | 62.0% |
| **V13：再 + 连续 3 日创 20 日新高** | **1.5** | **+1.107%** | 6.06 | 64.2% |

- **市场隔夜腿（全市场等权 收 T → 开 T+1）平均 -0.18%/天**，是负漂移；上面是逆着它赚到的超额。
- **「14:30 创新高」是唯一的开关**：同一涨幅带、同一均线条件，去掉它超额 -0.143%，加上它 +0.393%。
- 每个交易日是一次**独立观测**（持仓只过一夜、不跨日叠加），所以 t 值有效，不是重叠 cohort 撑出来的。

## 二、数据与口径

### 2.1 输入

| 用途 | 路径 | 说明 |
|---|---|---|
| 分钟行情 | `/data/quantdb/1_kline_data/l2_min1/dt=YYYYMMDD/data.parquet` | 全市场约 5200 只 × 241 根（09:25 竞价 + 09:31~15:00）；列 `symbol/time/high/low/close/volume/amount` |

### 2.2 单位

- `volume` 单位为**股**，`amount` 单位为**万元** → `vwap = amount × 1e4 / volume`
- 成交额下限 `cum_amt ≥ 3000`（万元）= 3000 万

### 2.3 数据缺口（必须记账）

`l2_min1` 有 **1802 个分区目录，但其中 208 个是空目录**（L2 落库当年没跑完，只剩 `.data.parquet.tmp` / `.duckdb_tmp`）。真实可用 **1594 天**：

2021: 141   2022: 0     2023: 0
2024: 242   2025: 243   2026: 210

即：**8 个年份、1594 个交易日**，不是连续十年，也不是 1802 天。2019 缺 134 天、2020 缺 72 天（集中在 2019-06 之后）。

## 三、规则（逐条可复现）

所有判定都只用 **≤14:30** 的信息，无一例外。

### 3.1 股票池与硬排除

1. 代码以 `.SH` / `.SZ` 结尾（剔除北交所）
2. 当日累计成交额 ≥ 3000 万元（14:30 前的累计值）
3. 当日 ST 名单剔除
4. **14:30 时已封涨停的剔除**：`close(14:30) < round(prev_close × (1 + 板块涨跌幅), 2)`
   - 主板 10%、创业板/科创板 20%、北交所 30%（ST 已整只剔除，不需 5% 分支）

### 3.2 五个信号条件

| # | 条件 | 公式 |
|---|---|---|
| ① | 涨幅 3%~5% | `ret_intra = close(14:30) / close(首根bar) - 1` ∈ [0.03, 0.05] |
| ② | 全天站上分时均价线 | `above_ratio = mean(close_t ≥ vwap_t × 0.999)` ≥ 0.80，t ∈ [09:25, 14:30] |
| ③ | 14:30 创全天新高 | `high(14:30) ≥ max(high[09:25..14:29])` **且** `close(14:30) ≥ 0.995 × high(14:30)` |
| ④ | 连续强势（截至 T-1） | V10/V11：连续 N 日 `close > prev_close`；V12/V13：连续 N 日 `close ≥ 20 日新高` |
| ⑤ | 变体选择 | V6 无 ④；V10/V12 用 N=2；V11/V13 用 N=3 |

> ④ 用 `.shift(1)`，即**只用到 T-1 收盘**；当天收盘在 14:30 时不可知。

### 3.3 交易

| 项 | 规则 |
|---|---|
| 入场 | **14:31 那根分钟 bar 的收盘价**（14:30 之后第一根） |
| 出场 | **T+1 开盘价**，全部卖出 |
| 持有 | 一夜（14:31 → 次日 09:30），**不跨第二个交易日** |
| 空仓 | 无信号日空仓 |
| 仓位 | 信号日**等权满仓**于当日入选股票（V13 日均 1.5 只 → 实际是 1~2 只） |
| 成本 | 往返 15bp / 25bp 两档 |

### 3.4 三段收益定义（用于归因）

```
尾盘腿  r_tail  = close(T,15:00) / entry(14:31) - 1
隔夜腿  r_on    = open(T+1)      / close(T,15:00) - 1
合计    r_total = open(T+1)      / entry(14:31) - 1
超额          = 组合该腿 - 全市场等权同腿
```

### 4.4 三种出场规则的对照（这是最重要的一格）

同一批 V13 信号，只改出场方式，用**逐日盯市的真实净值**（现金 + 持仓市值）计算：

| 出场方案 | 每轮均值 | **真实总收益** | **最大回撤** | 在场 |
|---|---|---|---|---|
| **A 次日开盘卖（本策略）** | +0.695%/天 | **+497%** | **-21%** | 11.7% |
| B 持有到底（每日 14:30 复核） | +0.66%/轮 | **-58.9%** | -75.1% | 12.1% |
| C 开盘裁决（低开砍）+ 14:30 复核 | +0.84%/轮 | **-21.7%** | -56.1% | 12.1% |

**两条变体都是亏钱的**，尽管每轮均值都是正的。原因：单票、±10~20% 涨跌停、每轮标准差约 14%，几何收益 ≈ 均值 − σ²/2 ≈ 0.66% − 1.0% < 0。最差单日 2025-02-05 **-19.2%**（持有的创业板票吃跌停）。

**结论：alpha 只存在于隔夜那一段（约 19 小时）。** 把持有期拉长到「一整日以上」，收益来源没变但风险敞口翻倍，净值直接转负。

> ⚠️ 计算方法陷阱：一天可能同时持有 2 只甚至 23 只票，它们**平分同一笔资金**，组合收益是**加权平均**；用 `∏(1+r_i)` 逐笔连乘会把同一笔钱按每只票各复利一遍，虚增几十倍（曾算出 +782%，实为 -58.9%）。**必须用现金+市值逐日盯市。**

## 五、必须知道的风险与约束

1. **不能当天卖**：V13 的尾盘腿是 **-0.081%**，全部收益在隔夜。当天卖 = 稳定亏。
2. **单票风险**：V13 日均 1.5 只，等于 1~2 只票满仓过夜，最差单笔 **-10.05%**，没有分散度。
3. **胜率只有 51.6%**（V13 25bp），靠盈亏比不靠胜率。
4. **一年只有 29 笔、在场 11.7%**——大多数时间空仓等待。
5. **2019 是异常年**（+64.3%），剔除后仍约 22%/年，但方差更大。
6. **容量未测**：14:31 市价买入 + 次日集合竞价卖出，参与率与冲击成本没有建模。
7. **2022–2023 无数据**，该区间表现完全未知。

## 六、如何在盘中实施

### 6.1 每日流程

```
14:25  预扫描：拉全市场分钟线，算 above_ratio / ret_intra（不含③的高点判定）
14:30  +30s：计算第 ③ 条（14:30 这根 bar 是否创新高），叠加 ④ 连续新高天数
14:31  市价买入入选股票
次日 09:25-09:30  集合竞价卖出全部
```

### 6.2 数据来源（平台内已有）

- 分钟线：`market:series` / `l2_min1` 当日分区（收盘后落盘）；盘中用 TDX 桥 `get_market_snapshot` 或 TdxAiData 订阅推送
- ST 名单：`st_history`（注意只更新到 2026-11-17，新 ST 需当日公告补充）
- 涨停价：`round(prev_close × (1+板块幅度), 2)`

### 6.3 最小实现

```python
# 伪代码
t1430 = last bar with time <= 14:30
vwap  = cumsum(amount)*1e4 / cumsum(volume)
ret   = close(t1430) / close(first_bar) - 1
above = (close >= vwap*0.999).mean()             # ≤14:30
newhi = high(t1430) >= max(high[:t1430]) and close(t1430) >= 0.995*high(t1430)
streak= 连续 N 日 close >= 20日新高（截至 T-1）

sel = pool[
    (ret>=0.03)&(ret<=0.05) & (above>=0.80) & newhi & (streak>=3)
    & (cum_amt>=3000) & (~is_st) & (close(t1430) < limit_up)
]
buy at close(14:31 那根 bar)；次日 open 全卖
```

## 七、复现脚本

**推荐路径：先物化面板，之后任何变体 30 秒**

| 文件（`data/tmp/strict_t20/`） | 作用 |
|---|---|
| `build_1430_panel.py` | **一次性**物化 14:30 截面（8 进程，259 秒）→ `panel_1430.parquet`（676 万行 / 114MB） |
| `fast_sim.py variants` | 各信号口径的隔夜超额（**30 秒**） |
| `fast_sim.py exits` | 三种出场规则对照（**30 秒**） |
| `intraday_strength_overnight.py` | 原始逐日扫描（13 分钟，仅用于校验面板口径） |
| `overnight_nav.py` | 原版净值曲线（含成本） |

```bash
# 一次性
docker exec quantmind bash -lc 'cd /data/tmp/strict_t20 && \
  python build_1430_panel.py --start 20170103 --end 20261117 --workers 8'

# 之后随便跑
docker exec quantmind bash -lc 'cd /data/tmp/strict_t20 && python fast_sim.py variants'
docker exec quantmind bash -lc 'cd /data/tmp/strict_t20 && python fast_sim.py exits'
```

面板口径已与原逐日扫描对拍：V6 +0.391% vs +0.393%、V8 +0.228% vs +0.228%（float32 舍入差）。

**面板的复用价值**：任何「盘中某时点截面」的策略（14:00 / 14:50 / 10:30）都可以照这个模式各建一份面板，之后全部秒级，不必每次重扫 220GB 分钟数据。

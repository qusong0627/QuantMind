# 大盘情绪 · 主力视角与成交量加权曲线（2026-10-29）

## 定位

把大盘情绪从「等权散户视角」扩一层「主力视角」：主力 = 超大单 + 大单（L2），
不是散户单（中单/小单）。展示层只描述当前资金结构，不构成方向预测。

## 新增指标

| 指标 | 定义 | 解读 |
|---|---|---|
| `main_net_yi` | Σ(超大单+大单)净额（亿元） | 主力净流入/流出金额 |
| `main_net_ratio` | 主力净额 / 全市场成交额 | 主力资金强度；>0 净流入 |
| `main_net_z20` | 主力净额比的 20 日 z 值 | 相对自身近 20 日的异常度 |
| `main_breadth` | 主力净流入为正的个股占比（等权） | 主力覆盖广度 |
| `main_breadth_amt` | 主力净流入为正的个股成交额占比 | 成交额加权广度，更接近主力视角 |
| `vw_breadth` | (上涨股成交额 − 下跌股成交额) / 全市场成交额，−1~1 | 成交量加权涨跌系数 |
| `vw_breadth_pct` | 上涨股成交额 / 全市场成交额，0~1 | 成交量加权上涨占比 |

## 单位与口径

- QuantDB `l2_factors` 的 flow 金额按分区混存（2023-01~2026-09-18 为元，
  2026-09-21 起为万元，早期亦可能万元）；`amount` 恒为万元。
- `backend/scripts/market_analysis/main_force.py` 按日比较
  `|flow_net_amount/amount − flow_net_ratio|` 与
  `|flow_net_amount/(amount×1e4) − flow_net_ratio|` 判定当日单位，再统一为元；
  不假定全历史单一单位。
- L2 资金流自 2022-06 起可用；主力分位用全量 L2，曲线只画最近 120 日。
- 日频快照由 `market_sentiment_snapshot.py` 生成；API 只读 JSON。

## 前端

- `VolumeForceChart.tsx`：上=全市场成交额柱（红=成交额加权偏涨、绿=偏跌），
  下=成交额加权涨跌系数实线（−1~1）+ 主力成交额加权广度虚线（0~1）。
  顶部 chips：成交额、成交额加权系数、主力净额/成交额、主力广度（等权/额加权）、主力净额。
- 大盘情绪左栏新增「主力视角 · 冷热」：主力强度、主力广度、主力额广度、成交额系数，
  与原有 8 个广度分项共用冷热条组件；分位为扩张窗口，不用未来数据。
- 旧快照没有 `volume/main_force` 字段时自动隐藏，不补 0。

## 算法改进建议（按证据优先级）

1. **等权 → 成交额加权**：同一广度指标用成交额加权后更接近主力视角；本次先把
   `main_breadth_amt` / `vw_breadth` 单独展示，不直接改压力分。
2. **主力资金强度** `main_net_ratio` 与价格加速度做状态表（类似板块方向表），
   先验证历史条件分布，再决定是否进入评分。
3. **压力分加权版本**：把 `pct_above_ma20/ma60` 从等权改为成交额加权，需重算
   PIT 面板并做金样；当前未改，避免无验证地动核心分数。
4. **模型特征**：现有资金流概率模型已使用订单流结构（一致性/VPIN/卖压/撤单/大单占比）
   与量价速度，主力视角可增加 `main_net_ratio`、`main_breadth_amt`、
   `vw_breadth` 的 3/5 日加速度；先做 OOS，不直接上线。

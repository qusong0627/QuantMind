# 股票研究档案库（stock_registry）

用途：把每次研究涉及的股票信息持久化，下次研究直接查，不用重跑。
数据源：TFT 273 模型 2025-01-02 ~ 2026-10-22 的逐日预测（`pred.parquet`）。

## 文件

| 文件 | 说明 |
|---|---|
| `stock_registry.parquet` | 每只股票一行：名称/行业/ST/HS300、首次与最近出现日、覆盖天数、被标最差/最好 10% 的天数与占比、均值/最近预测值、最近排名分位 |
| `stock_registry.csv` | 同上 CSV（UTF-8 BOM，Excel 可直接打开） |
| `stock_notes.json` | 研究备注，按代码累积，追加式 |

## 命令（容器内）

```bash
# 重建档案（新增预测后刷新）
docker exec -w /app quantmind python3 -m backend.scripts.stock_classifier.research_registry build

# 查单只股票
docker exec -w /app quantmind python3 -m backend.scripts.stock_classifier.research_registry show SZ000001

# 列「经常被标最差」的股票（bottom10 天数占比 ≥ 20%）
docker exec -w /app quantmind python3 -m backend.scripts.stock_classifier.research_registry list --flag bottom --min-share 0.2 --limit 30

# 记一条研究备注
docker exec -w /app quantmind python3 -m backend.scripts.stock_classifier.research_registry note SZ000001 "测试备注"
```

## 字段口径

- `bottom10_share` / `top10_share`：该股在 435 个交易日里，被模型排进**当日最差/最好 10%** 的天数占比；
- `last_rank_pct`：最近一个交易日按预测值升序的截面分位（0 = 最差，1 = 最好）；
- `mean_pred` / `last_pred`：模型的预测值（标签为约 5-10 日收益，非绝对涨幅）。

## 研究结论（2026-11-07）

- 最差 10% 名单：未来 10 日下跌比例 **63.9%**、平均 −2.38%、跌超 10% 概率 **21%**（市场 13%）；
- 该结论在 2025（样本内）与 2026（样本外）方向一致，是本轮唯一稳定的信号；
- 失效场景：急跌后的反弹月（2026-04：下跌比例仅 45.8%，平均 +2.65%）。

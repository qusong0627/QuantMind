# 盘中 4h 模型 · 实时落地路径

- 日期：2026-11-09
- 目标：把已验证的「14:50 买 Top20 → 次日开盘卖」做成盘中影子信号
- 模型：CatBoost 实时版（`lgb_4h_cat_live5.pkl`，112 特征；纯快照版见第 5 节）

---

## 1. 实时数据从哪来

| 层 | 来源 | 内容 | 覆盖/频率 |
|---|---|---|---|
| 盘中行情（主） | QMT 大端全市场快照（桥 → Redis `market:snapshot:{code}`） | 最新价、OHLC、累计量额、昨收、**5 档价量** | ~5,500 只，3-5 秒/轮 |
| 盘中行情（备） | TDX 桥热集（`market:snapshot/series`） | 同上 | 529 只 |
| 日频上下文 | 前一交易日 `l1_l2_factors` + 指数日线 | 58 因子 + 4 regime | 收盘后落库 |
| **缺** | 逐笔成交方向、大单分桶 | — | 桥的 `get_full_tick` 无逐笔 |

**结论**：实时链路只能拿到快照级数据 → 用**纯快照模型**；若未来接入逐笔源，可升级到 112 特征版。

## 2. 盘中五个组件

```
09:30 ──────────────────────────────────────────────
  [1] 分钟聚合器（常驻进程）
      每 3-5 秒读全市场快照 → 按分钟落 bar（5 档 44 列）
      → Redis qm:live:min1:{symbol}（当天 241 根）
      → 校验：新鲜度 / 覆盖率 >90% / 与 min1_kline 对账

14:51:00 ────────────────────────────────────────────
  [2] 打分器（精确分钟触发，常驻进程 sleep 到秒）
      当日 bars + 前一日因子 + regime → 快照特征 → CatBoost → Top20
      → 过滤：涨停封板（卖一无货）/ 停牌 / 次新
      → regime 闸：昨日前 20 日收益 >0 且回撤 >-3%，否则空仓

14:52 ──────────────────────────────────────────────
  [3] 信号落地
      PG 表 intraday_signals（date/cutoff/symbol/score/rank/regime_ok/tradable）
      → 前端卡片 / QQ 推送（可选）
      → 影子期：只记录，不生成委托

次日 09:31 ──────────────────────────────────────────
  [4] 对账
      拉开盘价 → 回填 open_ret → 写台账
      15:10 计算当日 IC / Top20 收益 → Redis qm:minute_model:ic_20d

每日 ────────────────────────────────────────────────
  [5] 衰减闸
      20 日 IC <0.02 或 Top20 日胜率 <50% → 信号标 halted
```

---

## 3. 存储与调度

| 项 | 方案 |
|---|---|
| 分钟 bar | Redis hash `qm:live:min1:{symbol}`（当天），收盘后落 parquet 归档 |
| 信号 | PG `intraday_signals`（新建，与现有信号台账隔离） |
| 调度 | **不用 celery beat 分钟轮询**（项目踩过「精确分钟门 + 隐形任务」坑），常驻进程 + 精确 sleep/门控 |
| 模型 | CatBoost 在容器内加载（宿主机 venv 缺 cat/xgb） |

## 4. 待验证（上影子前）

1. **快照覆盖率**：`market:snapshot` 当前多少只、更新频率是否 ≤5 秒；
2. **分钟 bar 对账**：用 QuantDB `min1_kline`（2026-01~08）逐分钟比对聚合器输出；
3. **纯快照模型损失**：见第 5 节回测结果；
4. **14:51 时延**：全市场特征计算 + CatBoost 打分是否 <30 秒。

## 5. 纯快照模型（实时唯一可行版）

- 丢弃：8 个委托特征 + 4 个 10 档/加权价特征 + 15 个成交/微观特征 = 27 个实际特征；
- 保留：OHLCV/累计量额/VWAP、5 档深度/失衡、5 分钟波动/振幅、盘口变化、日频 58 因子、4 regime；
- 训练：CatBoost，同切分同超参，tag `4h_snap`；
- 回测：`data/minute_model/backtest/snap/`（结果见报告）。

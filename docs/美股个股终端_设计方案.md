# 美股个股终端（Stock Terminal US）设计方案

> 目标：为美股做一套个股终端（搜索 + K 线 + 完整美股详情），并把**三个市场的个股终端统一到共享层**，
> 解决「每加一个市场就复制一份 6000 行」的维护问题。
> 对标：A 股 `stock-terminal/`、港股 `stock-terminal-hk/`；架构样板：`market-analysis-shared` 的
> 「独立市场目录 + 跨市场共享层 + 原路径 re-export」。

---

## 一、结论先行

1. **先抽共享层，再加市场**。港股终端当初是整目录复制 A 股终端（commit `ec2b2871`，6289 行），
   之后两边各自继续改，已经**双向漂移**（详见 §二）。再复制第三份，同一个 bug 要改三遍。
2. **共享层是机械提取，不是重写**：两份各约 300 行的服务文件，真实差异只有 **16 行赋值**；
   逐文件 diff 后，差异全部收敛成主题参数与一处配置。
3. **美股终端自包含**：后端 `stock_terminal_us/`（复用美股市场分析的现成数据基座，零重复），
   前端 `stock-terminal-us/`（只放美股特有：详情体 + 主题 + 服务配置）。
4. **口径与 A 股/港股不同，必须在界面上讲清楚**：日线是**未复权原始价**、`amount` 是**美元原始值**、
   标的池只有约 500 只（标普 500 + 纳指补充）且**非全市场**。
5. 验证期间发现并修掉一个**既有 500**：`/market/kline` 的 aggregator 兜底路径把 NaN 写进响应体
   （`float(x or 0)` 对 NaN 是放行的），港股终端冷启动时必现（详见 §六）。

---

## 二、为什么先抽共享层（实测证据）

逐文件 `diff` 两套副本：

| 差异行数 | 文件 | 性质 |
|---|---|---|
| **0**（13 个） | types.ts / engine/indicators.ts / OverviewTab / tabs{NewsTab,P2Tabs,SeriesChart} / MarketCalendarFilter / RankingPanel / Sparkline / TagStrip / KlineReplay / ChartBacktestPanel / L2FeatureCard | 逐字节相同，纯重复 |
| 2–8 | ScoreCalendar / StockSearchBar / KlineChart | 市场常量级 |
| 12–52 | IndexMaCard / StockFilterPanel / StockSidebar / InferenceScoreChart | 市场常量 + 少量分支 |
| 89 / 97 | pages/StockTerminalPage / kline/KlineWorkspace | 详情体不同 / 双向漂移 |
| **16**（300 行文件） | `services/stockTerminalService.ts` | 全是 `market:'A'\|'HK'`、指数代码，**外加港股副本没跟上 A 股的 `resolveWebSafeServiceBase` 修复** |

**双向漂移已发生**：A 版 `InferenceScoreChart` 有 `compact/endDate`（被 inference-center 复用），港股版没有；
港股版 `StockSidebar` 有信号列、`KlineWorkspace` 有策略提醒引擎，A 版没有。两边都在改，没有「哪边更新」的规律。

**另有大量死代码**：终端改「搜索驱动」布局后，`StockSidebar / StockFilterPanel / Sparkline /
MarketCalendarFilter / ScoreCalendar / RankingPanel / TagStrip / KlineWorkspace / KlineReplay /
ChartBacktestPanel / IndexMaCard` 在两套目录里都已无任何渲染点，只有 `toPrefix` 一个工具函数还被 import 拽着。
本次删掉了全仓库零引用的 12 份（6 个组件 × 2 套目录）。

## 三、目标架构

```
electron/src/features/
├── stock-terminal-shared/               ← 新增：唯一实现
│   ├── types.ts · utils.ts · engine/indicators.ts
│   ├── service.ts                       ← StockTerminalService：由市场配置驱动
│   ├── adapter.tsx                      ← StockTerminalProvider / useStockTerminal（主题 + 服务 + 自选格式）
│   ├── components/{KlineChart,StockSearchBar,InferenceScoreChart}.tsx
│   └── page/StockTerminalShell.tsx      ← 顶栏 + K 线卡 + 右侧详情卡（详情体由各市场注入）
├── stock-terminal/     (A股)   ← 页面薄封装 + CnDetailBody(9 Tab) + CN adapter
├── stock-terminal-hk/  (港股)  ← 页面薄封装 + HkDetailBody(7 Tab) + HK adapter
└── stock-terminal-us/  (美股)  ← 页面薄封装 + UsDetailBody(9 Tab) + US adapter

backend/services/api/
├── stock_terminal_us/                   ← 新增，自包含
│   ├── router.py                        ← /api/v1/stock-terminal-us，6 个端点，只做转发
│   ├── feed/{base,universe,kline,detail,news,research,labels}.py
│   └── README.md                        ← 口径表
└── market_analysis_us/feed/base.py      ← 被上面的 base.py 复用（US 数据访问基座，唯一实现）
```

**接线**：前端 `App.tsx` 的 `StockTerminalByMarket` 加 US 分支（菜单/权限/i18n 都不用动，
nav id `stock-terminal` 三市场共用）；后端 `api/main.py` 加 import + `include_router` 各 1 行。

### 市场差异的收敛方式

| 差异 | 承载方式 |
|---|---|
| 市场常量（kline/quotes 的 market、指数代码、端点前缀） | `TerminalMarketConfig` |
| 文案、主题色、K 线参考线标签、缩放条几何、复权选项 | `TerminalTheme` |
| 详情面板 | 各市场自己的 `XxDetailBody`，通过 `renderDetail` 注入 |
| 代码格式（自选表 prefix vs 裸 ticker） | `toWatchSymbol` |
| 端点返回结构不同（美股是扁平结构） | 在**服务子类**里映射成通用 `StockProfile` / `StockListItem`，共享组件不写市场分支 |

## 四、美股终端内容

### K 线

本地 parquet `1_kline_data/daily_forward`（6571 分区 / 2001-01-02 起 / 最新 2026-09-10），
**不走 `/market/kline?market=US` 的 yahoo 外网快路径**（终端应当本地优先、口径稳定）。

口径：yfinance `auto_adjust=False` 的**原始未复权价**，`amount` 为**美元原始成交额**。
→ 复权切换**只保留「不复权」**，并用 `3_financial_data/splits` 的事件在图上打**橙色竖线**
（拆股日未复权价会真实跳变，不标注会被误读成闪崩）。K 线卡头部常驻口径提示。

### 详情面板（9 个，全部实测有数据）

| Tab | 数据源 | 覆盖 / 备注 |
|---|---|---|
| 概览 | `security_master`(517) + `f10` + 日线 | 中文名（实测 AAPL→苹果）、GICS 板块、市值、距 52 周高点 |
| 估值 | `2_base_sector/f10/*.parquet` | 市值/PE/PB/股息率/52 周区间；约 420/484 有 PE；**库里没有 PS、EV、Forward PE** |
| 财务 | `3_financial_data/{income,balance,cashflow}/{SYM}.parquet` | **只有年报**（每标的 5 个财年）；后端把 yfinance 英文列名映射成中文标签子集 |
| 分析师 | `4_analyst/{analyst_price_targets,upgrades_downgrades,recommendations}` | 目标价 + 隐含空间、评级分布条形、升降级流水（含目标价前后值） |
| 财报 | `4_analyst/{earnings_history,earnings_dates,calendar}` | 未来财报日 + 历史超预期（EPS 实际/预期/超预期幅度） |
| 内部人 | `4_analyst/insider_transactions` | SEC Form 4；`Transaction` 列恒空，类型由 `Text` 前缀解析；净买卖汇总 |
| 机构 | `4_analyst/{major_holders,mutual_fund_holders}` | 13F 口径、**披露滞后约一季**（已在面板标注）；4 行无标签宽表按固定顺序解析 |
| 分红拆股 | `3_financial_data/{dividend,splits}` | 分红记录 + 拆股历史，与 K 线上的竖线呼应 |
| 资讯 | PG `news_article_enrichment.tickers` | 按 ticker 精确匹配（实测 NVDA 4655 / AAPL 3529 篇），带情绪标签；Huntly 标题匹配作兜底 |

**明确不做**：L2 微观因子（A 股独有）、CCASS 与南向（港股独有）、分钟线（QuantUS 无）、
期权与 VIX（单快照 + 只有 call，见 `docs/美股市场分析模块_设计方案.md` §3.2）、指数均线卡（该后端接口本就是 A 股专用）。

### 推理分副图

沿用共享层的 K 线卡（`/models/inference/stock/{symbol}/history`，主源是模型目录的 `pred.parquet`）。
美股模型训练刚打通，若该模型尚无历史分数，前端空态降级、不报错。

## 五、后端端点（前缀 `/api/v1/stock-terminal-us`）

```
GET  /list?q=&page=&page_size=     # 标的池搜索（代码/中文名/英文名），按市值降序
GET  /profile?symbol=AAPL          # 头部：名称/行业/最新价/涨跌幅/市值/52 周高低
GET  /kline?symbol=&days=&start=&end=  # 本地日线（未复权）+ 窗口内拆股事件
GET  /detail?symbol=AAPL           # 一次聚合 9 个面板（每段独立容错，某段失败返回空结构而非 500）
GET  /news?symbol=AAPL&limit=20    # 个股中文资讯（带情绪）
POST /refresh                      # 清缓存（数据同步后调用）
```

性能约束沿用美股市场分析模块的既定做法：按日期取数走**显式分区文件列表 + 列裁剪**
（`_read_partitioned`，禁止对 `dt=*/data.parquet` 全 glob —— 文件内的 `dt` 列会遮蔽 hive 分区列，
实测 250 日窗口从 1.73s 降到 0.05s）；`f10`/`4_analyst` 这类小文件集合一次读全市场再进 TTL 缓存。

## 六、验证期间发现并修复的问题

| 问题 | 根因 | 处置 |
|---|---|---|
| `/market/kline?market=HK` 冷启动 500 | HK/US 的 yahoo 快路径在适配器未注册时抛 KeyError，被 catch 后落到 `_aggregator_fetch`；该函数用 `float(x or 0)` 处理 `amount`，而 **NaN 是 truthy**，NaN 进了响应体 → FastAPI `Out of range float values are not JSON compliant` | 改用文件内已有的 NaN 安全函数 `_safe_float`（`default=None`）。修复后港股 K 线 200 |
| 美股搜索联想不出结果 | 后端条目用 `display_name/cn_name/market_cap_yi`，共享搜索框读 `name/total_mv` | 在美股服务子类里映射成通用 `StockListItem`（含 `cap_display`），共享组件保持零市场分支 |

**未修（既有、已知）**：`/stock-terminal/profile?symbol=0700.HK` 返回 404 —— 该端点是 A 股专用，
港股页 `getProfile` catch 后回落到列表项字段（页面表现正常，价格/行业仍显示）。美股走自己的 `/profile`，不受影响。

## 八、为什么这样设计（可维护性）

1. **一处改动三市场生效**：K 线卡、搜索框、指标引擎、服务实现都只有一份；
   市场差异一律进 `TerminalTheme` / `TerminalMarketConfig`，共享组件里**不允许**出现 `if (market === 'US')`。
2. **原路径 re-export 保兼容**：`stock-terminal/types.ts` 与 `components/InferenceScoreChart.tsx` 保留为转发文件
   （后者被 `inference-center/ModelScoreCurveGrid` 直接引用），抽取过程调用方零改动。
3. **市场差异在服务边界翻译**：美股后端返回扁平结构，映射放在美股服务子类，
   共享组件继续吃通用类型 —— 否则每加一个市场就要在共享层里加一层分支。
4. **加第 N 个市场的清单固定**：新建 feature 目录（页面 + 主题 + 服务配置 + 详情体）→ `App.tsx` 加一个分支
   → E2E 的 `MARKETS` 加一项。菜单、路由、权限、i18n 都不用动。
5. **口径显式化**：美股的数量单位、复权口径、标的池范围、13F 滞后都在面板与 README 里写明，
   防止后人用 A 股习惯误读（这是本项目反复踩过的坑）。

# 前端界面设计_设计方案（信息架构 · 新手引导 · 写策略 · 提要求）

> 版本：v1（2026-09-15）　配套：`docs/统一交易栈_设计方案.md`（v3）、`docs/设计复盘与优化报告.md`
> 约束（用户明确）：**外观与现有界面统一**（沿用现有设计系统，新页面"看不出是后加的"）；**新手也能好上手**；涵盖**写策略**与**自然语言提要求**。

---

## 一、设计原则

1. **外观统一优先**：完全沿用现有设计系统（组件库、色板、布局、间距、交互模式），新页面与现有页面并排无违和。不引入第二套视觉语言。
2. **渐进披露**：简单/专业双模式（全局一键切换，默认简单）；简单模式隐藏术语，专业模式展示全部机构级信息。
3. **术语翻译层**（唯一来源）：每个专业指标有"人话"标签，hover/问号即见（rank→"当前热度排名"、IC→"历史预测准确度"、滑点→"实际成交与预期的差距"、回撤→"从最高点最多跌过多少"）。翻译表集中维护，前端与推送文案共用。
4. **处处可下钻**：任何数字可点开看来源（曲线点→快照→订单→成交→信号→机会）。
5. **空态必引导**：每个空页面说清"为什么空 + 下一步做什么"（沿用现有 dashboard 空态纪律）。
6. **接线最小化**：新页面注册遵守现有约定（`App.tsx` + `api/main.py` 最小接线），构建走既有 `web/dist` 预编译流程。

## 三、新手路径（四级渐进，每级有"下一步"引导）

```
① 看（只读）      ② 跟（零配置）        ③ 改（调参）          ④ 写（创作）
系统信号/今日机会 → 一键订阅系统策略到 → 参数表单+diff+试算 → 模板库/AI对话写策略
                  模拟盘（默认安全参数）
```

- **首启向导**（3 步）：风险问卷（适当性）→ 开通模拟盘（默认保守参数）→ 选一个系统策略开始观察。
- **示例账户**：新用户首批看到"演示账户"的完整闭环（信号→成交→盈亏），再上自己的。
- **术语词典**：内置可搜索的词条页；UI 术语首次出现附解释。

## 四、写策略体验（策略中心）

| 模块 | 设计 |
|---|---|
| 模板库 | 现有 minibt 模板（11 个）→ "复制为我的策略"；每个模板配"它是什么/适合什么行情/风险点"三行说明 |
| **AI 写策略（对话式）** | 自然语言 → AI 引导澄清（一问一答补全 universe/holding/risk）→ 产出**结构化策略草稿**（params 或 minibt）→ 自动校验（schema+AST）→ 回测 |
| 参数编辑器 | 按策略 schema **自动生成表单**（不手写每策略 UI）；展示"当前生效值 + 来源"；保存前 diff 预览；线上策略改参需"升版本"确认 |
| 回测页 | 进度可见；结果含基准对比 + 分层/成本后 + 证据卡；失败给原因（不是白屏） |
| 晋级流 | VERIFIED→SIM→LIVE 三步按钮，每步显示门槛达成情况（模拟天数/跟踪误差）——达不到则按钮灰显 + 原因 |

## 五、"提要求"（自然语言统一入口）

- **入口**：全局 AI 助手（导航固定位），按意图路由四类：
  1. **写策略**：见 §四（产出结构化草稿）
  2. **选股筛选**："找主力连续流入的票" → 解析为筛选条件 → **显示解析结果（可编辑）** → 执行 → 结果进机会池
  3. **分析问答**："我持仓里哪只风险最高" → 工具调用取数回答（数值必须来自工具，见 LLM 方案）
  4. **操作帮助**："怎么把策略上实盘" → 引导到对应流程
- **安全铁律**：AI 的输出=建议与草稿；**一切写操作（下单/上线/改参）需用户确认卡片**（两步确认）；AI 永不直接执行。
- 结果可追溯：每条 AI 建议附"数据来源/时间"脚注。

## 六、专业模式（机构能力的前台呈现）

- 今日交易台专业视图：信号就绪详情、调仓计划全字段、执行质量（IS/滑点）、风控拦截流、情报总线（新闻/状态/异动）。
- **系统健康卡**：体检断言集可视化（12 项红黄绿），一键跳诊断报告。
- 下钻链路完整可用（原则 4 的落地验收）。

## 七、实现约束（与现状衔接）

- 复用现有组件与 tokens；新组件放对应 `features/*`；`dashboard-shared` 的"内容分层唯一声明处"纪律适用于所有市场差异化文案。
- 新页面接线只动 `App.tsx` + `api/main.py`（既有约定）；部署走 `web/dist` 预编译（不新增构建步骤）。
- 文案国际化预留（翻译表唯一来源，便于以后多语言）。

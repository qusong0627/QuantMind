# 盘中分钟特征与 T+1 模型 · 数据与训练规划

- 日期：2026-11-07
- 目标：用 L1/L2/V5 的**盘中分钟数据**训练一个 T+1（最多持有 3 天）选股模型
- 状态：规划（待确认范围后开工）

## 1. 数据实况（2026-11-07 实测）

| 数据 | 位置 | 覆盖 | 体积 | 形态 |
|---|---|---|---|---|

| **L2 已转 parquet（2024-2025）** | `/media/zbox/nas-wd/l2-warehouse/parquet` | 2024-04-01 ~ 2025-11-28 | — | 同上 |
| L2 已转 parquet（2024-2025 补） | `/media/zbox/sata/l2-warehouse/parquet` | 2024-11-01 ~ 2025-12-31 | — | 同上 |
| 分钟线（现有） | `data/quantdb/1_kline_data/min1_kline` | **2026-01-05 ~ 08-25** | — | 每只股票一个 parquet，1 分钟 OHLCV |
| L2 日频因子（V5） | `data/quantdb/6_ml_datasets/l1_l2_factors` | 2018-01 ~ 2026-11 | — | 329 列日频宽表 |

**parquet 表结构（每日）**：

- `snapshot`：1.85M 行 × 72 列 —— 10 档盘口（申买/申卖价量 1-10）、成交价/量/额、
  累计量额、加权平均叫买/叫卖价、买卖标志；约 3 秒一笔；
- `trades`：14.3M 行 —— 逐笔成交（价格、数量、方向、买卖单号）；
- `orders`：15.8M 行 —— 逐笔委托（价格、数量、方向、撤单标志）。

**成本估算**：

| 环节 | 单日成本 | 2017-2026 全量（约 2,400 天） |
|---|---|---|
| 7z 解压（14 GB） | 约 3-5 分钟（LZMA2 solid，20 线程） | — |
| 解析 4 个 CSV × 4,000 只 + 聚合分钟 | 约 15-25 分钟 | — |
| 合计 | **约 20-30 分钟/天** | **800-1,200 小时（连续 33-50 天）** |
| 磁盘峰值 | 解压需 ~20 GB 空闲/天 | 分钟面板（约 4,000 只 × 240 根 × 2,400 天）约 2-3 TB |

> 结论：**全量 2017-2026 从 7z 重建需要一台机器连续跑一个月以上**，不适合在现有生产机上直接开跑。
> 已转好的 parquet（2023-2025，约 650 天）可以先做，成本只有聚合，约 **2-3 天**。

## 2. 分钟特征规划（本文件的核心）

所有特征按**时点**计算（10:30 / 11:30 / 13:30 / 14:50），每个时点只用到该时刻为止的数据。

### 2.1 分钟量价（snapshot 聚合到 1 分钟）

| 特征 | 说明 |
|---|---|
| `m_open/high/low/close/volume/amount` | 分钟 OHLCV |
| `m_vwap` | 分钟成交额/成交量 |
| `m_ret_1/5/15/30` | 1/5/15/30 分钟收益 |
| `m_vol_5/15/30` | 分钟收益的已实现波动 |
| `m_vol_ratio_5` | 当前分钟成交量 / 过去 5 日同分钟均量 |
| `m_amt_ratio_5` | 同上（成交额） |
| `m_close_pos` | (close-low)/(high-low) |
| `m_dist_open` | 距当日开盘价 |
| `m_dist_prev_close` | 距昨收 |
| `m_trade_count` | 分钟成交笔数 |
| `m_avg_trade_size` | 分钟平均单笔金额 |

### 2.2 L2 盘口（snapshot 的 10 档）

| 特征 | 说明 |
|---|---|
| `b_spread_rel` | (卖1-买1)/中间价 |
| `b_depth_bid/ask_1/5/10` | 买/卖 1/5/10 档挂单量 |
| `b_imb_1/5/10` | 盘口不平衡 (bid-ask)/(bid+ask) |
| `b_depth_slope` | 档位越深挂单量的衰减斜率 |
| `b_big_bid_ratio` | 买 1-3 档大单占买盘比例 |
| `b_weighted_bid/ask` | 加权平均叫买/叫卖价（表内已有） |
| `b_spread_chg_5m` | 价差的 5 分钟变化 |
| `b_depth_chg_5m` | 深度的 5 分钟变化 |

### 2.3 逐笔成交（trades）

| 特征 | 说明 |
|---|---|
| `t_buy_vol_ratio` | 主动买量 / 总成交量 |
| `t_net_flow` | 主动买-主动卖金额 |
| `t_large_net` | 大单（>100 万）净流入 |
| `t_xlarge_net` | 超大单（>500 万）净流入 |
| `t_large_ratio` | 大单成交占比 |
| `t_vpin_1m` | 分钟 VPIN（成交量桶买卖不平衡） |
| `t_dir_autocorr` | 成交方向自相关（分钟级） |
| `t_avg_size` | 平均单笔成交量 |

### 2.4 逐笔委托（orders）

| 特征 | 说明 |
|---|---|
| `o_arrival_rate` | 分钟新增委托笔数 |
| `o_cancel_rate` | 分钟撤单率 |
| `o_cancel_imb` | 撤单不平衡（买撤-卖撤） |
| `o_big_order_ratio` | 大额委托（>50 万）占比 |
| `o_order_trade_ratio` | 委托笔数/成交笔数 |

### 2.5 L1 日频转分钟（用当日截至该时点的累计数据）

| 特征 | 说明 |
|---|---|
| `l1_cum_turnover` | 累计换手（累计成交量/流通股本） |
| `l1_cum_amt_z` | 累计成交额相对过去 5 日同期的 z 值 |
| `l1_ma_gap_5/20` | 分钟价相对 5/20 日均线 |
| `l1_rsi_6/14` | 用当日分钟序列算 RSI |
| `l1_intraday_pos` | 当日价格在已走区间的位置 |
| `l1_prev_day_ret_1/5/20` | 昨日及以前日线收益（慢变量） |

### 2.6 L2/V5 日频因子（慢变量，用前一日值）

从 `l1_l2_factors` 取前一日（PIT）的：`turn_20`、`vol_std_20`、`style_idio_vol_20`、
`micro_vpin_20`、`micro_liquidity_amihud_5`、`flow_net_ratio`、`chip_profit_ratio_20`、
`fun_pb`、`ind_dispersion_20` 等（约 15-20 个稳定因子），作为日频上下文。

### 2.7 截面特征（每个时点当天横截面）

每个特征在当天的**截面分位**（0-1），以及相对市场的分钟超额收益。

---

## 3. 标签与切分

- **标签**：截面 5 分位（次日/两日/三日收益）。
  - 主口径：**当日 14:50 买入 → 次日收盘卖出**（T+1）；
  - 备选：T+2 / T+3（最多持有 3 天）。
- **切分**（沿用项目惯例）：按日期切，禁止随机；训练/验证/测试之间按持有期 + 2 天做 embargo。

---

## 4. 训练方案

1. **按每个时点一个模型**（10:30/11:30/13:30/14:50），或一个模型带 `时点` 特征；
2. 模型族：LightGBM / CatBoost / XGBoost（与现有管线一致）；
3. 特征量：约 80-120 个分钟特征（含截面分位）；
4. 样本量：650 天 × 4,000 只 ≈ 260 万行/时点（若只用 2023-2025 parquet）；
5. 评估：截面 IC、分层收益、Top50/尾部分析、扣除成本后的多头收益。

## 5. 执行分期（建议）

| 阶段 | 内容 | 成本 | 产出 |
|---|---|---|---|
| **P0（可立即做）** | 用已转 parquet（2023-2025，650 天）聚合分钟 bar + 建特征 | 约 2-3 天机器时间 | 分钟面板 + 特征表 |
| **P1** | 训练 + 样本外评估（2023-2024 训练 / 2025 测试） | 数小时 | 首个盘中模型与报告 |
| **P2（可选）** | 7z 回补 2017-2022（约 1,450 天） | 约 500-800 小时 | 完整 2017-2026 分钟库 |
| **P3（可选）** | 抽样回补（每年 1-2 个月）验证早期数据可用性 | 约 100-150 小时 | 长历史稳健性 |

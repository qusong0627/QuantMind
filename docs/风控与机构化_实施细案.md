## 二、T-RC 风险控制体系（主体，今晚开工 RC-01）

### 架构裁定（落地口径）
- **唯一入口**：新包 `backend/shared/risk/`（唯一实现），`RiskGate.evaluate(ctx) -> Decision` 纯函数核心 + 薄 IO 壳。
- **规则 = 配置**：`backend/shared/risk/rules/*.py` 只放**判定函数注册表**（id/level/参数 schema/默认参数/单测）；
  参数值在 PG（版本+审计）→ Redis 热副本（同 P6 门控模式）。DSL 复用个股终端表达式引擎（`tag_rules`）作为 **L3 自定义规则**扩展位，内置规则不走 DSL（性能与可解释性）。
- **决策记录**：`risk_events`（新表，自愈迁移）字段 = rule_id/level/action/reason/evidence(json 快照值)/config_version/symbol/order_id/market/shadow/ts；
  **config_version 强制**（审计缺口的正面回答）。
- **状态机**：`NORMAL→CAUTION→RESTRICT→HALT`，状态在 Redis 热键 + PG `risk_state_history`（迁移全历史，重启恢复）；
  自动动作（降仓系数/禁买锁/全撤）由状态驱动，恢复必须人工确认（HALT 加双人复核字段）。
- **影子**：规则带 `shadow=true` → 判定照跑、落库照记、**动作不执行**；报表按 shadow×rule 分组出误杀率预览，达标后转正（转正 = 一次配置变更，全程留痕）。

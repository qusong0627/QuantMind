# 因子挖掘机构级 · 文档/图片输入链 + 挖掘任务中心 —— 规划与任务单（2026-10-09）

> 状态：**机构级规划稿（生效版）**，已按生产环境标准编入任务单（T-FM-01…20）。
> 基线事实：2026-10-09 三路实测侦察（前端 alpha-research / 后端挖掘链路 / MinerU API 契约 v4）。
> 上游约束：本仓既有纪律——TIMESTAMPTZ+aware UTC、启动期 ensure 建表 + 升级 SQL、双开关收敛（实盘同款）、多会话共享工作区、前端改动必须 typecheck+deploy_frontend。

## 0. 目标

1. **挖掘入口多模态化**：上传 **PDF / DOC(X) / PPT(X) / XLS(X) / 图片（png/jpg/jpeg/jp2/webp/gif/bmp）**——含**扫描件 OCR**——经 **MinerU 在线 API** 解析为 markdown，再由**版本化提示词模板**整理为受约束的「挖掘方向/研究假设」（自由挖掘 / **论文复现** 两口径），人工可编辑确认后交给现有 RD Agent 链路。
2. **挖掘任务中心**：每次挖掘的输入、状态、产出（因子数）、血缘（文档→任务→因子）全程可回看、可跳结果、可重跑；重启/升级不丢。
3. 既有链路契约不变：挖掘 → `rd_agent_factors` → 物化 → 池/训练。本计划为其**前置入口链**与**任务级记录层**。

**MinerU 链路（实现基准）**
```
POST /api/v4/file-urls/batch   {files:[{name,data_id,is_ocr,page_ranges}], model_version:"vlm",
                                enable_formula:true, enable_table:true, language:"ch"}
  → data.batch_id, data.file_urls[]
PUT file_urls[i]  (文件二进制；不要带 Content-Type / Authorization)   # 上传完成自动入队
GET /api/v4/extract-results/batch/{batch_id}  → extract_result[]{file_name,state,full_zip_url,err_msg,data_id,extract_progress}
GET full_zip_url → zipfile 取 full.md + images/ + *_content_list.json（**勿用 4.0 命名 markdown.md**）
错误码：A0202/A0211(token)；-60005 超大小；-60006 超页数；-60009 队列满；-60018 日上限；-60019 html 额度；
        -60007/-60008/-60010/-60001/-60011 暂态可重试；-60002/-60003/-60004/-60015/-60016 永久失败
```

## 2. 机构级设计要点（生产标准）

1. **多租户隔离**：文档/任务一律 `user_id` 归属校验（照 `_require_owned_task`）；管理员视图单独放行。
2. **双开关收敛（实盘同款）**：后端 `ENABLE_DOC_MINING`（默认 false；False 时 docs 相关端点 404/403，防未验收功能出网）+ 前端 `VITE_ENABLE_DOC_MINING`（构建期，未开整块不渲染）。**文档出网（MinerU 云端）是敏感行为，闸门默认关，验收后再开。**
3. **时间纪律**：所有新列 `TIMESTAMPTZ`，Python 侧 `utc_now()` 写入（`backend/shared/utc_datetime.py`），JSON 带 `Z`。
4. **建表与升级**：启动期 ensure（照 `rd_agent_persistence.ensure_tables`）+ 随版本发 `data/upgrade_vX.sql`（老库升级）。
5. **可靠性**：解析编排 **PG 为权威状态**，重启续轮询（优于挖掘链路的"重启即 failed"）；MinerU 暂态错误退避重试（指数，上限），永久错误立即失败并给可读文案；**done 立即下载落盘**（链接无 TTL）。
6. **安全**：上传 magic 校验 + 防穿越 + 大小闸；zip 解包**只白名单提取**（`full.md`/`images/*`/`*_content_list.json`），拒绝绝对路径与 `..`（Zip-Slip），解压总量与条目数上限（Zip-Bomb）；文件名清洗；文档内容视为**不可信输入**（提示词注入不落地执行，仅作 LLM 语料 + 用户确认后作 direction）；direction 提交前限长（8k 字符）。
7. **配额治理**：平台共享 1000 页/日（MinerU 账号级）。Redis 记账（当日页数）；每用户每日页数上限（env 可配，默认 200）；上传前 PDF 页数预检（>200 拒）；测到页数后记账；余量预警端点 + 管理员可见；`-60018` 为最终兜底。
8. **幂等与去重**：同用户同 sha256 文档命中已解析记录 → 直接复用解析产物（**省配额**），仅新建文档条目引用同一解析目录。
9. **可观测**：结构化日志带 `doc_id/task_id`；`GET /alpha-agent/docs/quota`（当日已用/上限/余量）；解析耗时与失败按错误码计数；配额 <10% 告警接入现有 QQ 通道（可选，P2）。
10. **留存治理**：`RD_AGENT_DOC_RETENTION_DAYS`（默认 90）到期 GC 原文件+zip（保留 full.md？——默认全清，行转 `expired`）；管理员手动删除；磁盘水位检查。
11. **模板版本化**：整理模板带 `organize_prompt_version`，落库并在历史页可见（哪个模板整理的，可追溯、可回归）。
12. **质量回归**：整理输出做**金样测试**（`tests/fixtures/` 固定输入 md → 断言 schema 与关键字段，照 researchScoreGolden 模式）。

## 3. 数据模型（DDL 草案）

```sql
-- 挖掘任务中心（T-FM-01）
CREATE TABLE IF NOT EXISTS rd_agent_mining_tasks (
  task_id       TEXT PRIMARY KEY,
  user_id       TEXT NOT NULL,
  market        TEXT NOT NULL DEFAULT 'a_share',
  universe      TEXT,
  data_source   TEXT,
  direction     TEXT NOT NULL DEFAULT '',      -- 挖了什么（全文）
  direction_mode TEXT,
  loop_n        INTEGER,
  source        TEXT NOT NULL DEFAULT 'text',  -- text | doc | legacy
  doc_id        TEXT,
  status        TEXT NOT NULL DEFAULT 'pending', -- pending|running|completed|failed|cancelled
  progress_pct  INTEGER NOT NULL DEFAULT 0,
  current_loop  INTEGER NOT NULL DEFAULT 0,
  error         TEXT,
  factor_count  INTEGER NOT NULL DEFAULT 0,
  created_at    TIMESTAMPTZ NOT NULL,
  updated_at    TIMESTAMPTZ NOT NULL,
  completed_at  TIMESTAMPTZ
);
CREATE INDEX IF NOT EXISTS idx_rd_mining_tasks_user ON rd_agent_mining_tasks (user_id, created_at DESC);
CREATE INDEX IF NOT EXISTS idx_rd_mining_tasks_status ON rd_agent_mining_tasks (status);

-- 文档中心（T-FM-07）
CREATE TABLE IF NOT EXISTS rd_agent_docs (
  doc_id        TEXT PRIMARY KEY,
  user_id       TEXT NOT NULL,
  filename      TEXT NOT NULL,
  ext           TEXT,
  size_bytes    BIGINT,
  sha256        TEXT,
  original_path TEXT,
  mineru_batch_id TEXT,
  parse_state   TEXT,                          -- MinerU state 镜像
  page_count    INTEGER,
  md_path       TEXT,
  content_list_path TEXT,
  status        TEXT NOT NULL,                 -- uploaded|parsing|parsed|parse_failed|organized|expired|deleted
  organized_text TEXT,
  organize_kind TEXT,                          -- free | paper
  organize_prompt_version TEXT,
  organized_at  TIMESTAMPTZ,
  task_id       TEXT,                          -- 最近一次由它发起的挖掘任务
  error         TEXT,
  created_at    TIMESTAMPTZ NOT NULL,
  updated_at    TIMESTAMPTZ NOT NULL
);
CREATE INDEX IF NOT EXISTS idx_rd_docs_user ON rd_agent_docs (user_id, created_at DESC);
CREATE INDEX IF NOT EXISTS idx_rd_docs_sha ON rd_agent_docs (user_id, sha256);
```
落盘根：`RD_AGENT_DOCS_DIR`（默认 `/data/rd_agent_docs/<doc_id>/`：`original.ext / mineru.zip / full.md / images/ / content_list.json`）。

## 9. 风险与对策
| 风险 | 对策 |
|---|---|
| 文档出网（MinerU 云端） | UI 明示披露；双开关默认关；需要时转自托管（GPU，P3+） |
| 1000 页/日共享配额被单用户吃光 | 每用户日限+记账+预警；`-60018` 兜底文案 |
| zip 恶意样本 | 白名单解包+Zip-Slip/Bomb 防线（T-FM-06 专测） |
| 长文 LLM 成本/漂移 | map-reduce+模板版本化+金样回归；用户 Key 自理成本 |
| 整理质量差致废因子 | 默认人工确认（直通开关默认关）；direction 进池后由现有门禁/复核继续兜底 |
| 挖掘链路 /tmp 丢失 | 任务表 PG 化后记录不丢；日志本体迁移为 P3 可选 |

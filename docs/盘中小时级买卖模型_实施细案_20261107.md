# 盘中小时级买卖模型 · 实施细案

- 日期：2026-11-07
- 目标：盘中按小时选股买入（T+1，跨日持有）、次日起按分钟决定卖出
- 数据底座：`l2_min1` 分钟表（2024-2025 共 485 天连续，2023 年 169 天有缺口）

---

## 0. 一句话口径

| 项 | 买入模型 | 卖出模型 |
|---|---|---|
| 决策频率 | 盘中 5 个时点：10:30 / 11:30 / 13:30 / 14:30 / 14:50 | 次日起每分钟 |
| 标签 | 未来 **240 交易分钟**收益（= 下一交易日同一时点，含隔夜跳空）；另训 300 分钟对照 | 现在卖 vs 持有到 4h 终点，二分类 |
| 用途 | 截面排序，选最优买入 | 持仓退出 |

**为什么是 240 交易分钟**：A 股 T+1，今天买最早明天卖。240 个交易分钟正好等于一个完整交易日的交易时长，标签 = 同时间点的下一交易日价格，天然包含隔夜跳空，与实际持有期对齐。

## 1. 数据层（P0，依赖分钟表落库）

### 1.1 分钟表
- 产物：`data/quantdb/1_kline_data/l2_min1/dt=YYYYMMDD/data.parquet`
- 每股每日 241 根：09:25 竞价 + 09:31~11:30 + 13:01~15:00
- 已验收：成交量/成交额/收盘价与日线误差 ~1e-7，盘口量纲自检通过

### 1.2 多时点特征表（新增 `build_intraday_features.py --cutoffs`）
- 每个 `(date, symbol, cutoff)` 一行，cutoff ∈ {1030, 1130, 1330, 1430, 1450}
- 特征只读 `time <= cutoff` 的 bar，约 45 列：
  - 价量：`px/ret_open/range_pos/cum_volume/cum_amount/vwap_gap/ret_5m/15m/30m/vol_15m/30m`
  - 盘口：`spread/bid_depth_1/5/10/ask_depth_1/5/10/imb_1/5/10/big_bid_ratio/book_ratio/wavg_bid_gap/wavg_ask_gap`
  - 成交：`buy_ratio/net_amt/trade_n/avg_trade_amt/large_net/large_ratio/xlarge_net/dir_autocorr`
  - 委托：`order_n/big_order_n/cancel_n/order_trade_ratio/cancel_rate`
- 输出：`data/minute_model/intraday/date=YYYYMMDD/data.parquet`（25,000 行/天）

### 1.3 标签
- 交易分钟序列：把每日 241 根按时间拼接，去掉 09:25 竞价 bar → 240 根/天
- `ret_4h(t) = close(t + 240 bars) / close(t) - 1`（跨日自动包含隔夜）
- `ret_5h(t) = close(t + 300 bars) / close(t) - 1`；数据末尾不足时截断并用次日收盘兜底，标记 `label_capped`
- 截面分位：每个 `(date, cutoff)` 内对 `ret_4h` 做 rank_pct
- 可交易性标记：`is_limit_up`（cutoff 时点涨停，买不进）、`is_suspended`、`is_new_listing`、`is_st`

### 1.4 日频上下文
- 从 `6_ml_datasets/l1_l2_factors` 取**前一日**（PIT）约 40-60 列：动量、波动、换手、流动性、资金流、微观结构（`micro_vpin_20` 等）
- 严禁取当日日频值（含收盘信息 = 前视）

### 1.5 面板
- `data/minute_model/panel/date=YYYYMMDD/data.parquet`
- 训练集：特征 + 上下文 + 标签 + 可交易性
- 约 25,000 行/天 × 485 天 ≈ **1,200 万行**，80-100 列

## 2. 买入模型（P1）

| 项 | 方案 |
|---|---|
| 样本 | 5 cutoffs × ~5,000 股 × 485 天 ≈ 1,200 万行 |
| 切分 | 2024 训练 / 2025 测试；测试段内再做季度 walk-forward（每季向前推） |
| Embargo | 训练/验证之间留 4 个交易日（覆盖 4h 标签跨日） |
| 模型 | LightGBM 回归（主）+ 5 分类（5 分位，对照）；CatBoost/XGBoost 对照 |
| 特征 | 45 分钟特征 + 40-60 日频上下文（前一交易日）+ 时点 one-hot（或分时点各训一版） |
| 过滤 | 剔除涨停（cutoff 时点封板）、停牌、次新（上市 < 60 日）；ST 用 PIT 来源，缺失则显式标注 |
| 评估 | 截面 IC（Spearman）、分层 5 档的 4h 收益、Top50 扣成本后的 4h 收益、按 cutoff 分拆、隔夜 vs 日内收益分解 |
| 产出 | 模型文件、评估报告、特征重要性、分时点 IC 表 |

**关键风险**：4h 收益里隔夜跳空占比可能很高，模型可能只是在学「隔夜 beta」。必须分解 `ret_overnight`（cutoff→次日开盘）与 `ret_intraday`（次日开盘→终点），分别看 IC。

## 3. 卖出模型（P2）

### 3.1 持仓样本构造
- 用 P1 模型在历史每一天每个 cutoff 产出 Top N（如 20/50）信号
- 买入价 = 信号时点下一分钟的 `open`（避免用收盘价成交的作弊）
- 持仓期：买入后至 4h 终点（下一交易日同一时点）
- 每条持仓在次日盘中每一分钟产生一个样本（状态）

### 3.2 特征
- 分钟级：近 5/15/30 分钟动量、量比、主动买卖差、盘口失衡、分钟波幅
- 持仓上下文：浮盈（现价/买入价−1）、已持有分钟数、距当日高水位回撤、距昨收、距 4h 终点剩余分钟
- 市场上下文：指数同期涨跌、全市场涨跌家数

### 3.3 标签（二分类，主）
- `sell_now_ret = P_t / E - 1`
- `hold_ret = P_{endpoint} / E - 1`
- `label = 1 { hold_ret > sell_now_ret + cost }`（持有更优）；`cost` = 双边手续费+印花税+滑点
- 对照：回归标签 `P_{endpoint}/P_t - 1`

### 3.4 评估（端到端，唯一算数的）
同一批买入信号，对比四条退出策略：

| 策略 | 说明 |
|---|---|
| A 卖出模型 | 模型每分钟判断 |
| B 次日开盘卖 | 无脑基线 |
| C 次日收盘卖 | 无脑基线 |
| D 固定回撤止损 | 如 −5% 触发，否则收盘卖 |

指标：扣成本净收益、最大回撤、胜率、单笔平均持有分钟、换手。
**A 打不过 B/C 就没有上线价值**，如实报告。

## 4. 实时推理（P3）

### 4.1 同口径保证
- 抽 `backend/shared/intraday_features.py::compute_features(bars_df, cutoff)` 纯函数
- 批量侧（DuckDB）与实时侧（pandas）各一份实现，**金样对账**：同一日同一时点逐列 diff = 0（容差 1e-9）
- 参照 `research_score.py` ↔ `researchScore.ts` 的金样文件模式

### 4.2 买侧（每小时）
- 时点：10:30 / 11:30 / 13:30 / 14:30 / 14:50（调度用精确分钟门）
- 取数：当日分钟序列（Redis `market:series` / `market:snapshot`；先热集 529 只，再扩候选池）
- 流程：拼当日 bar → 共享特征函数 → 模型 → 写 `engine_signal_scores` + 实时卡片
- 先**影子模式**：只记录信号与后续走势，不产生委托

### 4.3 卖侧（每分钟）
- 范围：当前持仓（含模拟盘/实盘，按账户隔离）
- 流程：每分钟取持仓最新价+近 30 分钟序列 → 特征 → 卖出模型 → 「建议卖/持有」
- 先影子：只写建议与台账，不自动下单；达标后再讨论接执行（风控默认 fail-closed）

## 6. 验收与红线

1. **前视零容忍**：特征只用 `time <= cutoff`；日频上下文只用前一交易日；标签用未来数据但只出现在标签列。
2. **切分按日**，禁止随机切；embargo ≥ 4 个交易日。
3. **可交易性**：涨停封板买不进的样本必须剔除或加权，不能用「买到涨停价」的假收益。
4. **成本**：双边手续费 + 印花税 + 滑点，默认按现有撮合口径（万 3）+ 0.1% 滑点，报告里写清。
5. **负结果照报**：模型无预测力就降级为描述性，不进执行链。
6. **影子先行**：任何自动执行前，先跑 ≥ 2 周影子，记录信号与真实走势。

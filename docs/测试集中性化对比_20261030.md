# 测试集对比：原始 vs 中性化（统一 3 日收益）

- 日期：2026-10-30
- 样本：8 个模型（6 个 T+3 + T+5 + T+10），测试集
- 口径：所有模型统一用 **T+3 模型的 3 日收益标签**评估；中性化用生产核心
  `backend.shared.neutralization`（市值 + 60 日 Beta + 20 日动量，秩回归、二遍收敛）
- 多空 = 每日前 20% 减后 20%；夏普按 √242 年化；回撤 = 累计多空曲线最大回撤；
  换手 = 前 20% 名单日度 Jaccard 距离；净收益按单边 10bp 扣减

## 结论

1. **中性化在 8 个模型上一致成立**：多空日均基本不变（±0.03pp），最大回撤从
   -78%~-90% 收敛到 -12%~-18%，夏普从 2.4~3.2 提升到 5.0~6.1。IC 从 ~0.095 降到
   ~0.078，但 ICIR 从 0.52~0.55 升到 0.79~0.81——被剥掉的是不稳定的风格暴露。

2. **3 日持有口径下，CAT2016 T+3 是净收益最高的组合**：0.395%/日（扣 10bp），
   高于 T+5 的 0.372% 和 T+10 的 0.357%。T+5/T+10 的原始多空更高（0.48%/0.51%），
   但原始回撤 -88.7%/-90.1%，中性化后收益反而落到 T+3 以下。

3. **2026 年 IC 普遍低于 2025**：T+3 原始 0.087~0.088（2025 为 0.099~0.101），
   所有模型同向衰减；中性化后 2026 为 0.075~0.076。T+10 在 2026 的中性化 IC 最低
   （0.0683），长周期模型对近期结构变化更敏感。

4. **口径边界**：这批模型的 200 个候选因子是用 2023–2025 IC 选出的，2025 年对
   “选因子”是样本内；因此绝对 IC 偏乐观，**模型间比较与原始/中性化比较仍然有效**，
   但不能把 0.095 当成严格样本外水平。2026 年是最干净的窗口。

5. **成本边界**：换手 27%~35%，按单边 10bp 扣减后净收益见表；未含冲击成本，
   实盘还需按成交额与流动性再折。

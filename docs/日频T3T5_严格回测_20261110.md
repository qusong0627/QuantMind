# 日频 T+3 / T+5 严格回测报告（2026 测试窗）

> 结论先说：**两个模型的横截面排序能力是真的，但按 Top20 等权长多、扣费后不成立**。
> 沪深300 MA20/MA60 过滤不但没救，反而把仅有的正收益也滤掉——该模型不是趋势跟随，过滤方向有害。

## 一、口径

- 信号日：2026-01-01 ~ 2026-11-05（`pred.parquet` 的 `split=test`）。
- 执行：t 日收盘出信号 → **t+1 开盘买** → t+1+h 收盘卖（T+3 h=3，T+5 h=5）。
- 剔除：ST（PIT）、停牌、次新 <60 交易日、开盘涨停买不进；卖出遇跌停/停牌顺延，最多 10 日。
- 组合：TopN 等权；成本为往返 0.15% / 0.25% / 0.40%（佣金+印花+滑点）。
- 统计：全部每日 cohort + 非重叠周期路径；NW t 值（lag=h）；年化/回撤/夏普按非重叠周期。
- 回测器：`backend/scripts/model_eval/strict_backtest.py`（新增 `--benchmark-ma` / `--index-dir`）。

## 五、结论与边界

1. **模型 IC 是真的**：test rankIC 0.081/0.095，单因子 OOS 同号率 95–97%，但 IC 没有转化成可交易的长多 Top20 净值。
2. **长多 TopN 不成立**：0.15% 成本已经年化负；0.25%/0.40% 更差；Top50/Top100 没有改善。
3. **MA 过滤有害**：MA20/MA60 都显著恶化；不要用。
4. **收益集中在少数月份**：5/6 月双位数亏损，最大回撤 −30%；不满足「按月分段存续」。
5. **不能进影子盘/实盘**：当前形态只能作为研究信号，不能当独立长多策略。

## 六、下一步（一次只动一轴）

- **P1 避免底部（avoid-bottom overlay）**：不买 Top20，而是在宽基/现有持仓里剔除模型 bottom decile；换手低，可能捕捉「避雷」alpha。
- **P2 缓冲持有**：TopN 进、跌出 Top2N 才卖，或按月调仓；把 121x/81x 换手降到 20–40x。
- **P3 对冲结构**：TopN 多 + IC/IM 股指期货空，检验长腿 alpha 是否能覆盖对冲成本；需要期货账户。
- **P4 换标签/换周期**：T+5 比 T+3 略好但不够；先试 T+10/T+20 低换手，再谈特征。
- 所有实验继续走同一台账：strict 结果已挂进 `registry`，经验/坑已自动记为 `strict_long_only:*` 与 `strict_filter:*`。

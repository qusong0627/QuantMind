# 散户情绪 · 反向指标设计与验证（2026-10-29）

## 结论先行

**散户净流入/散户广度本身不是反向指标**：2022-2026 全史里它们更像同步动量（散户买、指数短期也偏强）。
真正稳定可反向的是：

> **散户追涨相关 `retail_chase_corr`（10 日均）** = 当日个股「散户净额/成交额」与「过去 5 日涨跌幅」的截面相关。
> 高 = 散户在追近期赢家（情绪过热，之后偏弱）；低 = 散户不追/卖涨（情绪冷，之后偏强）。10 日均用于减少单日翻转。

## 口径

- 散户 = 中单 + 小单（L2 `flow_medium_net + flow_small_net`），主力 = 超大单 + 大单。
- 数据：2022-01-04 至 2026-10-28，A 股全市场；L2 金额按分区元/万元逐日归一。
- 前向：t 日收盘信号 → t+1 收盘建仓 → t+1+h 收盘；指数用沪深300/中证1000。
- 截面相关按当日所有有 L2 的个股计算，剔除缺失。

|---|---:|---:|---:|---|

## 产品化

- 后端 `backend/scripts/market_analysis/retail_force.py`：日频计算 `retail_ratio`、`retail_breadth`、`retail_breadth_amt`、`retail_chase_corr`、`retail_chase`、`retail_panic`、`retail_net_yi`、`divergence`。
- 快照新增 `retail` 块：
  - `retail_score = clip((chase_corr − 0.05) / 0.25 × 100, 0, 100)`（0=不追，100=追涨过热）。
  - 分数：`clip((10日均 chase_corr − 0.10) / 0.10 × 60 + 20, 0, 100)`。
- 阈值（10 日均）：`≥0.20` 过热 → 反向警惕；`≤0.10` 冷/不追 → 反向关注；中间中性。
  - 指标：散户追涨相关、散户净额/成交额、散户成交额加权广度、主力−散户背离。
- 前端大盘情绪左栏新增「散户视角 · 冷热」：分数条 + 反向结论 + 分项冷热 + 「指标说明 ?」弹窗。
- 成交量副图新增「散户柱」：全市场散户净额（中单+小单），红=净流入、绿=净流出；与「大盘柱/主力柱」并列。
- 成交量柱视觉：每根柱增加淡红/淡绿整列背景 + 加粗柱体/白描边，方向在最小净额下也能一眼看出。
- 回看日期：`build_payload(as_of=...)` 只使用当日及以前序列；L2 自 2022 起可用。

## 边界

- 追涨相关是**市场级**情绪，不是个股信号；不要直接拿来选股。
- 高/低阈值来自 2022-2026 全史，未来风格切换可能失效；应持续滚动复核。
- 散户=中单+小单是券商 L2 的机械分桶，不等于真实散户身份；只能作为行为代理。
- 所有结论为历史统计，不构成投资建议。

## 2026-10-29 追加：主力/散户分数并入广度压力主图

- 主力分数：
  - `main_buy_score = mean(expanding_pct_rank(main_net_ratio), pct(main_breadth), pct(main_breadth_amt)) × 100`（越高=主力越偏买）。
  - `main_pressure = 100 − main_buy_score`（越高=主力越偏派发/卖）。
  - 2026-10-28 实测：主力买入 92.3 / 100，派发分 7.7。
- 散户分数：沿用 `retail_score = clip((chase_corr−0.05)/0.25×100,0,100)`（越高=散户越追涨，反向风险）。
- 主图压力带内画三条线：
  - 紫色虚线：广度压力分（0~100，越高越冷）
  - 蓝色虚线：主力派发分（100−主力买入，越高越偏卖）
  - 橙色点线：散户追涨分（越高越追涨，反向风险）
  - 三线共用 0~100 右轴；鼠标悬浮读数框同时给出三个分数。
- 主力/散户分数在 L2 起点（2022-06）之前不可用：前端显示“该日期早于 L2 资金流起点”的明确提示，不再用 `—` 冒充。
- 主力视角区显示「主力买入 X/100 · 派发分 Y/100」；散户视角区显示分数条与反向结论。

## 2026-10-29 追加：10 日均与主图三分数

- 散户追涨相关改为 **10 日均**：单日版本会一会追涨一会追跌；10 日均仍保留反向力（h5 IC −0.066、h10 −0.100、h20 −0.087），且状态更稳定。
- 10 日均阈值：>0.20 过热、<0.10 冷/不追；分数映射 `(ma10−0.10)/0.10×60+20`。
- 主力买入分同样对三个分项先做 5 日均，再取扩张分位平均；主力派发分=100−买入分。
- 主图压力带三条线：广度压力（紫）、主力派发（蓝）、散户追涨（橙，10日均）；悬浮读数同时给三值。
- 成交额/主力/散户柱全部加淡色方向背景列，红色/绿色方向比细柱明显。

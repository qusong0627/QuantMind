# 期货数据面扩容：期权 EOD 数据集（2026-10-28）

## 目标

把 A 股 ETF 期权 EOD 数据落到 QuantFutures 数据根，纳入后台「数据管理 → QuantFutures」目录，
每日随期货同步自动更新；支持 2016 年以来回填。

**范围**：上交所/深交所 ETF 期权，交易所官方口径；不含 CFFEX 股指期权、不含美股期权、不含逐合约 OHLC。

## 数据源与覆盖

| 数据 | akshare 接口 | 覆盖 | 落盘 |
|---|---|---|---|
| SSE 逐合约风险指标 | `option_risk_indicator_sse(date=YYYYMMDD)` | 至少 2016-01 起；50ETF 最早，300ETF/500ETF/科创50 随上市日 | `2_base_sector/options_risk/dt=YYYYMMDD/data.parquet` |
| SSE 每日统计 | `option_daily_stats_sse(date=YYYYMMDD)` | 2016-01 起；5 个标的（510050/510300/510500/588000/588080） | `2_base_sector/options_stats/dt=YYYYMMDD/data.parquet` |
| SZSE 每日统计 | `option_daily_stats_szse(date=YYYYMMDD)` | 2019-12-23 起（159919）；2022-09-19 起 159915/159922；2023-01 起 159901 | 同上 |

**为什么不用 CFFEX**：akshare 1.18.88 的 `option_cffex_hs300_daily_sina` 报 `SyntaxError`；
`option_cffex_hs300_spot_sina` 只有当日快照，无法回填 10 年。CFFEX 股指期权需另找官方日档。

## 表结构

### `options_risk`（SSE 逐合约）

| 列 | 含义 |
|---|---|
| `trade_date` | 交易日 |
| `underlying` / `underlying_name` | 标的代码/名称（510050 等） |
| `contract_id` / `security_id` / `contract_name` | 合约代码/交易所内部码/简称 |
| `option_type` | `call` / `put` |
| `strike` | 行权价（元） |
| `expiry_month` | 到期年月（`YYYY-MM`；合约代码只给年月，精确到期日由交易所日历另算） |
| `delta/gamma/theta/vega/rho` | Greeks |
| `implied_vol` | 隐含波动率（小数）；源端 0 已置 NaN，避免污染 ATM/skew |
| `source/release_id/published_at` | 来源与落盘时间 |

### `options_stats`（SSE + SZSE 按标的）

| 列 | 含义 |
|---|---|
| `trade_date` / `exchange` | 交易日/交易所 |
| `underlying` / `underlying_name` | 标的代码/名称 |
| `n_contracts` | 合约数（仅 SSE） |
| `amount_wan` | 总成交额（万元，仅 SSE；深交所汇总不提供） |
| `volume` / `call_volume` / `put_volume` | 总/认购/认沽成交量 |
| `pcr_volume` | 认沽/认购成交量比（小数；源端百分比已归一） |
| `open_interest` / `call_oi` / `put_oi` | 总/认购/认沽持仓量 |
| `pcr_oi` | 认沽/认购持仓比（小数） |
| `source/release_id/published_at` | 来源与落盘时间 |

## 同步集成

- 新增脚本：`backend/scripts/akshare_futures_options.py`
- 数据集注册：`quantfutures_daily_sync.EXTRA_DATASET_TASKS`
  - `options_risk` → `task_options_risk(days)`
  - `options_stats` → `task_options_stats(days)`
- 每日全量同步默认附带（`DEFAULT_EXTRA_DATASETS`），最近 5 个交易日重写，补齐延迟发布。
- 后台目录：`global_market_console._default_datasets("FUTURES")` 已加两项，路径/分区布局与其余期货数据集一致。

## 命令

```bash
# 每日增量（最近 5 个交易日）
python backend/scripts/akshare_futures_options.py --task all --days 5

# 10 年回填（默认跳过已有分区，可断点续跑）
python backend/scripts/akshare_futures_options.py --task all \
  --start 2016-01-01 --end 2026-10-27 --sleep 0.2

# 强制重写
python backend/scripts/akshare_futures_options.py --task all \
  --start 2016-01-01 --end 2026-10-27 --force
```

## 踩坑记录

- **深交所 HTTPS 被断连**：akshare 1.18.88 的 `option_daily_stats_szse` 走
  `https://investor.szse.cn/...`，在本环境返回 `Empty reply from server`；
  改用 **http** 同路径 + 浏览器 UA 可正常返回。脚本内 `_fetch_szse_stats_raw`
  是唯一深交所请求入口，不要再退回 akshare 的 HTTPS 实现。
- **深交所数值带千分位**（`2,762,319`）：落盘前统一去逗号转数值，否则
  `volume/pcr` 会静默变 NaN。
- **休市日**：SSE 风险指标/统计源端无列会抛 `KeyError`，脚本按空数据跳过，
  不记故障；A 股休市日在期货日历里仍可能有分区。

## 运维边界

- 期权 T 日数据一般 T 日盘后发布；每日同步重写最近 5 日，避免「当天没发出来就永久缺」。
- 单日失败隔离：某日/某交易所异常只记录 error，不中断整轮回填；缺失分区下次回填会自动补。
- 交易所接口有速率限制；回填默认 `--sleep 0.2`，失败重试 3 次（0.8/1.6/2.4s 退避）。
- 回填以期货日K分区为交易日历；A 股休市日（元旦/春节等）源端返回空，不落分区，属正常。
- 10 年回填约 2,600 个交易日 × 2 个数据集；风险指标每日约 100~700 行，统计每日 1~9 行，磁盘量级约 100~200MB。
- **不含**逐合约成交量/持仓明细/OHLC；可做 IV/PCR/skew/期限结构，但 **max pain 不可算**（缺逐档持仓），也不能直接回测期权买卖。若要做期权策略回测/max pain，需要另接逐合约行情源。

## 验收

- 单日：2026-10-27 → `options_risk` 664 行、`options_stats` 9 行（SSE 5 + SZSE 4）。
- 5 日增量：risk/stats 各写 5 个分区，`status=ok`。
- 单测：`backend/tests/data_platform/test_futures_options.py` + `test_quantfutures.py` 共 38 项通过；新模块覆盖率 94%。
- 历史抽测：2016-01-04（50ETF 100 行）、2020-01-02（+300ETF）、2024-01-02（5 个 SSE 标的 + 4 个 SZSE 标的）均能取到。
- 10 年回填以期货日K分区为日历，共 2,818 个交易日；休市日无期权数据，不落分区。
- 风险指标回填结果：`status=ok`，写 1,256 个分区、跳过 1,369 个已有分区、空 193 个休市日、错误 0。
- 每日统计回填/修复结果：2016-2019 补 7 个、2020-2021 补 342 个、2022-2026 补 1,089 个，错误 0；休市日空 193 个。
- 最终规模：两数据集各 **2,625 个交易日分区**（2016-01-04 ~ 2026-10-27），
  `options_risk` 706,466 行 / 77MB，`options_stats` 11,496 行 / 42MB。
- 完整性校验：逐分区可读、无重复键、风险表 `trade_date` 与分区键一致；
  统计表每个交易日有 SSE 行，2019-12-23 起每个交易日有 SZSE 行且成交量非空。

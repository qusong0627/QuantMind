# 通达信实盘桥 — 完整部署与使用指南

> QuantMind 每天 AI 推理选股 → 全自动推送到 Windows 通达信：选股板块、预警信号、消息提醒、策略源码、实盘下单。
> 反向拉取通达信账户盈亏、持仓、委托状态，形成决策闭环。

---

## 二、前置条件

| 条件 | 说明 |

## 三、Windows 侧部署（一次配齐）

### 3.1 准备
1. 启动通达信客户端 `TdxW.exe`
2. **登录交易账号**（模拟盘或实盘账号均可）

### 3.2 一键运行 setup.ps1（已配齐所有环境）

打开共享目录 `\\192.0.2.22\PYPlugins\bridge-windows\`，**右键 `setup.ps1` → 使用 PowerShell 运行**。

脚本自动完成 7 步：

| 步骤 | 内容 | 解决什么问题 |
|------|------|-------------|
| **1/7** | 检测 Python | 未装 Python 则提示安装 |
| **2/7** | 给系统 Python 装桥依赖 (aiohttp/pyyaml) | 桥程序运行 |
| **2.5/7** | **给通达信 TQ Python 装 numpy/pandas** | 修复 `ModuleNotFoundError: No module named 'numpy'` |
| **3/7** | 设置 BRIDGE_AUTH_TOKEN | 桥鉴权 |
| **4/7** | 防火墙放行 8550 端口 | Linux 能访问桥 |
| **5/7** | 检测通达信客户端 | 确认 TdxW.exe 在跑 |
| **6-7/7** | 启动桥 | HTTP 服务监听 |

> ⚠️ 如果 2.5/7 步提示"未找到通达信捆绑 Python，用系统 Python 安装"，说明通达信用系统 Python 或捆绑路径特殊。装完后**重启通达信客户端**让 TQ 环境重新加载 numpy。

### 3.3 验证桥启动

```powershell
curl.exe http://127.0.0.1:8550/api/v1/health
# 期望: {"status":"ok","tdx_connected":true}
```

- `tdx_connected:true` → 通达信已连接 ✅
- `tdx_connected:false` → 通达信未登录 或 TQ 环境问题（检查 numpy）

### 3.4 防火墙（脚本已自动配置）

脚本已自动添加入站规则放行 TCP 8550。若失败，手动：
- 控制面板 → 防火墙 → 高级设置 → 入站规则 → 新建 → 端口 8550

## 四、Linux/QuantMind 侧部署

### 4.1 挂载共享目录（已有）

```bash
sudo mount -t cifs //192.0.2.22/PYPlugins /mnt/tdx-shared \
  -o username=esxi,password=<SMB口令>,vers=3.0,uid=1000,gid=1000
```

### 4.2 配置 .env

在 `/home/zbox/projects/quantmind/.env` 追加（已配好）：

```bash
# ============ 通达信实盘桥配置 ============
ENABLE_TDX_PUSH=true                    # 开启全自动推送
TDX_BRIDGE_URL=http://192.0.2.22:8550
TDX_BRIDGE_TOKEN=b6334ff871a8f51c524ea08bba7c9cdd1e6cc1173791625e9ba4808dc5f0bfe9  # 与 Windows 侧一致!
ENABLE_REAL_TRADING=true                # 启用实盘
REAL_BROKER_TYPE=tdx                    # 通达信 broker
TDX_ACCOUNT=                            # 通达信资金账号(留空用默认)
TDX_ACCOUNT_TYPE=stock
```

> ⚠️ **BRIDGE_AUTH_TOKEN 必须与 Windows 侧完全一致**，否则桥返回 401。

### 4.3 重启后端容器

```bash
cd /home/zbox/projects/quantmind
docker compose restart quantmind
```

## 六、全自动推送流程

### 6.1 每日选股自动推送

推理完成后（`script_runner.py`），若 `ENABLE_TDX_PUSH=true`：

```
1. push_signals_to_block → 今日选股写入通达信"临时条件股"板块
2. push_message → 通达信界面显示 "QuantMind 今日选股 N 只|预测日期 X"
```

**通达信侧查看**：TQ 策略界面 → 自定义板块 → 临时条件股（自动跳转显示）。

### 6.2 实盘下单流程

```
QuantMind 信号 → trading_engine → TdxBroker.place_order()
  → Windows 桥 → 通达信下单
  → 通达信客户端弹出确认框 → 用户点"确认" → 成交
  → 桥回传 Wtbh 委托编号 → QuantMind 查状态
```

### 6.3 拉取通达信状态

| 操作 | 调用 | 返回 |
|------|------|------|
| 账户盈亏 | `pull_pnl()` | 总资产/现金/持仓市值/各股盈亏/总盈亏 |
| 持仓明细 | `pull_positions()` | 代码/成本价/总持仓/可用 |
| 当日委托 | `pull_orders()` | 委托号/代码/方向/状态/成交价/成交量 |
| 单笔状态 | `pull_order_status(wtbh)` | Status: 0无效/1未成交/2部分/3全成/4部分撤/5全撤 |
| 下单成败 | `check_order_success(wtbh)` | Status=3→全部成交✅; 2→部分⚠️; 1→未成交⏳ |

### 6.4 手动调用 TdxPushService

```python
from backend.services.trade.services.tdx_push_service import tdx_pusher

# 推送选股到板块
await tdx_pusher.push_signals_to_block(["600519.SH", "000001.SZ"], block_code="")

# 拉账户盈亏
pnl = await tdx_pusher.pull_pnl()

# 下单
result = await tdx_pusher.place_order("600519.SH", "buy", 100, price=1650.0)

# 查单笔状态
status = await tdx_pusher.check_order_success("W20260812001")
```

## 七、故障排查

| 现象 | 原因 | 解决 |
|------|------|------|
| 桥返回 401 | token 不一致 | 核对 Linux `.env` 与 Windows 输入 |
| `tdx_connected:false` | 通达信没登录 | 启动通达信并登录交易账号 |
| `No module named 'numpy'` | TQ 环境缺依赖 | 重跑 setup.ps1 (2.5/7步) + 重启通达信 |
| Linux 连不上 8550 | 桥没启动/防火墙 | Windows 运行 setup.ps1，确认 4/7 步 |
| 下单"待确认" | 实盘单需客户端确认 | 通达信客户端点确认 |
| 推送没触发 | `ENABLE_TDX_PUSH` 未开 | .env 设 `ENABLE_TDX_PUSH=true` + 重启后端 |

## 八、安全说明

1. **token 鉴权**：桥用 Bearer token，Linux/Windows 必须一致，不要泄露
2. **防火墙**：只放行 8550 到可信内网 IP
3. **实盘人工确认**：通达信实盘下单默认弹确认框，不自动下单（更安全）
4. **模拟/实盘隔离**：SIM 模式完全走本地撮合，零风险
5. **日志审计**：桥把每次操作写入 `execution_reports/trade_log.jsonl`

## 九、当前限制（重要）

### 9.1 下单功能受通达信环境限制

**实测结论（2026-08-12）**：当前通达信 `new_tdx_mock`（量化模拟版）**不支持 TQ 下单**。

- 账户查询 / 持仓 / 选股推送 / 消息 / 预警 / 源码推送 / 委托查询：✅ 全部正常
- **真实下单**：❌ 通达信 OMS 返回 `不支持的证券[1,600519]<==(7617)OMS.OrderInput`
- 在通达信客户端**手动下单同样失败** → 确认是模拟环境禁用了下单，非桥或代码问题

### 9.2 如何启用下单

要启用真实下单，需要以下任一条件：
1. **标准版通达信**（非 mock 测试版）+ 券商开通 TQ 权限的账号
2. **实盘券商账号**（skill 原文："自动下单需联系开户券商开通支持TQ的版本"）

# 策略教程示例

| 文件 | 用法 |
|---|---|
| qlib_topk_strategy.py | 回测中心「专家模式」/ 策略管理，需传 model_id |
| qlib_risk_guard.py | 带基本面过滤与账户风控的 STRATEGY_CONFIG |
| minibt_dual_ma.py | AI-IDE / 回测中心 minibt 运行时 |
| sandbox_on_tick.py | 模拟盘上传策略 |
| strategy_lab_dual_ma.py | 策略实验室 |
| ai_ide_script.py | AI-IDE 普通脚本 |
| live_trade_config.json | 模拟盘调度配置示例 |

使用前请替换 SYMBOL、日期、资金、model_id 等占位值；示例不构成投资建议。

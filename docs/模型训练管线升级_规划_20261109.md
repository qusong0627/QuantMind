# QuantMind 模型训练管线升级 · 规划（2026-11-09）

> 目标不是「回测/IC 好看」，是**实盘净 Top-N 好看**。所有升级围绕一条主线：
> 统一口径（时间切分/可成交价/成本/容量）→ 标签与损失对齐交易动作 → 严格评估 → 才谈模型结构。

## 0. 统一口径（先定死，不再改）

| 项 | 口径 |
|---|---|
| 信号时点 | t 日收盘后（PIT 因子/财务） |
| 买入 | **t+1 开盘可成交价**（集合竞价 / 09:30–09:35 VWAP；容量单独核） |
| 卖出 | t+1+N 收盘（N 由模型标签决定，日频默认 5） |
| 切分 | 时间切分；train 尾部按 horizon+lag 做 embargo/purge；验证/测试不参与任何拟合 |
| 拟合 | 标准化/填充/PCA 只在 train 拟合；财务按公告日；股票池用历史成分，含退市 |
| 成本 | 基础 0.15% 往返；压力 0.25% / 0.40%（华泰双边千四）；印花税 2023-08-28 后卖方 0.05% |
| 可交易 | ST、停牌、次新、涨停买不进、跌停卖不出（顺延）；容量 ≤10% 当日成交额 |
| 评估 | **净 Top-N（扣费）** + RankIC/ICIR（HAC）+ 换手 + MDD + 容量 + 月度稳定性 + 安慰剂/种子/成本敏感性 |
| 调参 | 只在验证集；测试集最后打开一次；3 折滚动 + 3 种子；不看测试选模型 |

## 1. 现状盘点

### 已落地（工作区，未提交；纯函数与冒烟已过）
- **标签截面变换**：`rank`（默认）/ `zscore` / `raw`；`label_drop_extreme_pct`（MASTER 式，只 train 段）。
- **特征稳健标准化**：`standardize="robust"`（median/IQR），保留 zscore/rank。
- **排序损失 + 按日分组**：CatBoost YetiRank、LightGBM lambdarank/rank_xendcg、XGBoost rank:pairwise/ndcg/map；
  `train.py` 按 `trade_date` 排序并传 groups；Optuna/分位数模式在排序损失下自动跳过。
- **三棵树机构级默认参数**：LGB lr0.03/depth6/min_data500/ff0.7/l2=5；XGB lr0.03/depth5/采样0.8/min_child100/lambda10；
  CAT depth5/lr0.03/l2=10/2000轮/od_wait100。
- **已有**：时间切分 + embargo、月度滚动重训、WFA、Optuna、rank IC/ICIR/分组/多空评估、模型注册。

### 缺口（按优先级）
1. **执行价**：平台标签是 t+1 **收盘**；目标是 t+1 **开盘**。标签/回测/评估都要切到开盘口径并做 close vs open A/B。
2. **严格评估器**：训练结果只出 IC/ICIR/分组；缺「净 Top-N、换手、容量、HAC 显著性、月度」的统一出口。
3. **成本感知标签**：常数成本对 rank 标签无效；需按股票差异化成本（tick/price、spread、参与率）或成本过滤。
4. **多种子集成**：seed 固定 42；需 3 种子平均与产物包装。
5. **数据审计**：PIT 财务、退市股、历史指数成分、幸存者偏差，逐项核。
6. **300 特征内存**：54GB 容器装不下 300×1,070 万行（两次 OOM）；需 池 / 200 列 / 站外精简三选一。
7. **DDG-DA / DoubleAdapt**：研究级，Phase 4 才评估，不阻塞主线。

## 2. 分期计划

### Phase 0 · 训练代码基础（已完成，待提交）
- 交付：上节「已落地」的代码 + `backend/tests/test_training_label_preprocessing.py` + rank-loss 冒烟脚本。
- 验收：纯函数测试通过；三棵树 rank loss 冒烟通过；默认参数与旧行为可回滚（payload 显式参数优先）。
- 收尾：提交（commit 自主）；文档记录开关与口径。

### Phase 1 · 评估口径先行（最高优先级，1–2 天）
- **1.1 次日开盘执行**：`execution_price: open|close` 配置；`loading.py` 用 t+1 open 建标签；回测同口径；
  做 close vs open A/B，记录差异。
- **1.2 严格回测器**：t+1 买入、t+1+N 卖出；0.15/0.25/0.40 成本；ST（2026-07-06 前 5% / 后 10%）、
  主板 10%/创业板科创板 20%、停牌、涨停不可买、跌停/停牌卖不出顺延、次新、容量 10%、退市/PIT。
- **1.3 评估出口**：一条命令输出净 Top-N（20/50/100/500）、RankIC/ICIR（HAC）、换手、MDD、月度、
  容量/参与率、成本敏感性、安慰剂/种子。
- 验收：147 基线在同一报告下重算；任何新模型用同一报告，禁止口头/截图对比。
- Kill：147 净 Top20 在 0.25% 成本下 <0 → 先解决信号，不进入 Phase 3。

### Phase 2 · 标签 / 损失 / 样本（2–3 天）
- 2.1 标签 A/B：next-open T+5 vs next-close T+5；top-tail（只学上半区）vs 全截面 rank；成本差异化标签（可选）。
- 2.2 损失 A/B：MSE/Huber vs rank loss（CAT YetiRank / LGB lambdarank / XGB rank:pairwise）；同切分同评估。
- 2.3 样本卫生：极端标签剔除 5%（train）、ST/次新/停牌过滤、禁止未来收益列。
- 2.4 多种子：3 seeds（42/7/2024），rank 平均；产物包装（多模型目录 + 推理聚合）。
- 验收：严格报告下，最佳变体相对 147 基线净 Top-N 提升且 t≥2、0.25% 成本为正。
- Kill：所有变体在 0.25% 成本下为负 → 停下，回到数据/标签，不调模型。

### Phase 3 · 规模与模型阶梯（3–5 天）
- 3.1 300 特征内存路径（三选一）：
  - A. 指数池（CSI1000，行数约 1/5，300 列可装）；
  - B. 砍到 200 列走平台；
  - C. 站外精简训练（全市场、跳平台整帧副本；300×1,070 万 float32 ≈13GB）。
- 3.2 模型阶梯（每级同切分/同特征/同评估）：
  Ridge → LightGBM → XGBoost → CatBoost → GRU → TCN；Transformer/TabNet/NativeTFT 最后。
  3 折滚动 + 3 种子；只在验证集调参；测试最后开一次。
- 3.3 集成：GBDT + 深度模型混合；必须验证样本外增益，不以「名字不同」假定有效。
- 验收：3 折 WFA 的净 Top-N、MDD、换手、容量；模型选择只看验证，测试只报一次。

### Phase 4 · 滚动 / 漂移 / 上线前（3–5 天）
- 4.1 月度滚动重训（已有）+ **衰减触发**（滚动 IC/胜率阈值），不只靠日历。
- 4.2 DDG-DA / DoubleAdapt 研究 spike：仅在 Phase 1–3 过关后评估；不阻塞。
- 4.3 数据审计：PIT 财务、退市股、历史指数成分、幸存者偏差；缺什么补什么。
- 4.4 影子盘：信号台账、次日开盘成交、真实滑点/容量；≥2 周再谈真钱。

## 3. 全局验收与 Kill Criteria

| 闸 | 标准 |
|---|---|
| 时间切分 | train/valid/test 无重叠，embargo≥horizon+lag |
| 可成交 | 涨停/跌停/停牌/ST 全部按规则处理；容量 ≤10% 成交额 |
| 净收益 | 测试段净 Top-N 在 0.25% 成本下 >0；0.40% 下不崩（≥−5%/年） |
| 显著性 | HAC t≥2（重叠标签校正后），不是朴素 t |
| 稳健性 | 3 种子方向一致；安慰剂≈0；月度不靠 1–2 个月 |
| 防泄漏 | PIT/退市/历史成分审计通过；测试集只开一次 |
| 结论 | 任一闸不过 → 判「描述性/不可实盘」，不上钱 |

## 5. 风险与阻塞

1. **300 特征 OOM**（两次 137）：必须选 池/200/站外；不解决就没有 300 版。
2. **数据 PIT/幸存者偏差未知**：这是最可能让所有回测作废的项，Phase 4.3 必须做，不能拖到上线前。
3. **执行价与容量**：开盘集合竞价对低价小盘容量有限；Phase 1.1 必须用可成交 VWAP/参与率，不用单一 open print。
4. **重叠标签显著性**：T+5 日频重叠，朴素 ICIR/t 偏高；统一用 HAC/非重叠/block bootstrap。
5. **多重检验**：多模型 × 多参数 × 多种子，验证集冠军偏乐观；最终用未碰测试 + DSR/PBO。
6. **回滚**：训练代码改动均为 opt-in/默认可回退；payload 显式参数优先，旧任务不受影响。

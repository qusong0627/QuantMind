# 市场分析模块 (Market Analysis)

## 模块说明
市场分析功能板块，提供全市场大盘全景、多周期资金流向、板块/个股资金链、申万一级行业热力矩形图谱等可视化与交互分析。

## 核心组件与页面
- `pages/MarketAnalysisPage.tsx`: 市场分析主页面组件，包含顶部 Banner 顶栏、核心指数快照、功能 Tab 导航以及资金流向下钻面板。
- `components/ShenwanHeatmapChart.tsx`: 申万一级分类矩形树图 (Treemap) 热力图组件。
- `components/MarketBreadthCard.tsx`: 市场情绪温度计与赚钱效应卡片。
- `components/MarketSentimentPanel.tsx`: 大盘情绪页签 —— 广度压力分（0–100）+ 各指数「未来 20 个交易日历史同状态路径分布」扇形图 + 8 个广度分项分位。
- `components/SentimentFanChart.tsx`: 扇形图（SVG）。左段真实收盘，右段 p10–p90 / p25–p75 两条带 + 中位虚线；中位以上红、以下绿，上下宽度一眼可见。回看模式叠加黑色实线＝之后实际走势（不足 20 天时画已走出的部分）。**单击历史某天＝回看当天预测**，拖动＝平移，双击复位。
- `components/BreadthFactorBars.tsx`: 广度分项冷热分位图。各指标方向先统一成「越靠右＝越冷」，再画 0–100 点位；名称与提示用大白话（不出现 TRIN/McClellan 术语）。含左栏浓缩版（`compact`）。
- `components/PredictionReview.tsx`: 预测复盘（T+5/10/20 当时预测 vs 之后实际、方向命中、样本外命中率/MAE/IC 与最近 12 次命中点）。
- `components/BreadthDistributionBar.tsx`: 七档涨跌分布（涨停/涨>5%/…/跌停，当日计数，互斥）。
- `components/FactorHeatmap.tsx`: 底部分项冷热热力图（8 指标 × 近 60 交易日，颜色=冷度）。
- `components/StockMoneyFlowTable.tsx`: 个股资金流向排行榜表格。
- `components/FlowPanoramaPanel.tsx`: 资金流全景面板（细案 v2 状态中枢）：工具栏 + 证据 meta 披露 + 标签融合条 + 桑基 v2 + 板块⇄个股双向工作台 + 延续证据台。
- `components/FlowSankeyV2.tsx`: 四层桑基（主体 → 单型 → 板块 → 个股），点节点联动下方工作台。
- `components/SectorFlowWorkbench.tsx`: 板块榜 ⇄ 板块内个股榜双向工作台。
- `components/StockFlowDetailCard.tsx`: 个股资金流详情卡（20 日五档序列 / 板块归因回跳 / 因子板共振态）。
- `components/FlowEvidencePanel.tsx`: 延续证据台（全史条件统计命中榜 + 信号档案）。
- `components/FlowProbabilityCard.tsx`: **未来强度概率（模型）**：LightGBM 排序分（订单流+量价速度+板块状态）、强弱/逆流候选、板块成分聚合、消息/龙虎榜/大宗徽章；OOS AUC 与十分位胜率固定披露。
- `components/FlowPredictiveCard.tsx`: **资金流预测力**（研究证据卡）：净流入金额分位对照、资金流质量分（订单流结构）分位→可执行超额、5×5「净流入×过去涨跌」热力图、高/低胜率形态与当日靠前/靠后个股。
- `components/TagBrowserStrip.tsx`: 板块标签融合条（统一搜索：板块 / 标签 / 股票代码；热门板块 chips）。
- `components/EvidenceBadge.tsx`: 延续证据徽章（连N + 条件超额悬停）。
- `components/FactorBoardPanel.tsx`: 因子概率板面板（合成分 × 模型分位象限）。

## 数据服务与词汇表
- `services/moneyFlowService.ts`: 资金流全景/板块/个股/标签/证据台 API 客户端与类型（`FlowPanoramaResponse`、`FlowStockFactor` 等契约字段）。
- `services/factorBoardService.ts`: 因子概率板 API 客户端（`REQUIRED_TOP_KEYS` 与后端金样共读）。
- `services/sentimentService.ts`: 大盘情绪 API 客户端（`/market-analysis/sentiment`，只读预计算快照；缺失一律 null，绝不回落成 0）。
- `factorBoardVocabulary.ts`: 判定词/衰减/制度注记/个股象限（`quadChipCls` / `quadrantMeta`）唯一展示映射，禁用买卖指令词。

## 最近优化
- **资金流概率模型**（2026-10-29）：①新增 `build_flow_probability.py`（31 特征、LightGBM、2025-2026 OOS、isotonic 校准），弱侧（bottom 十分位）显著强于强侧；②资金流全景新增「未来强度概率」卡：强势/弱势 Top、**逆流候选（当前流出·概率高）**、**流入但弱（派发警惕）**、板块成分聚合；③桑基新增**着色切换**（净额/概率）——节点按模型分着色、边宽仍按当前净额；④概率卡叠加消息情绪/龙虎榜/大宗徽章（覆盖期 2026 / 2023-10 起，明确披露）；⑤板块不做独立模型（实测 AUC≈0.51），只做成分聚合。
- **资金流预测力**（2026-10-28）：实测「主力净流入金额」本身几乎没有方向性（分位→之后收益平坦；高净流入+已大涨在 10~20 日反而跑输）；有增量的是**订单流结构**——成交方向一致性（正向）、卖压/撤单深度/VPIN 冲击/大单占比（负向）。新增质量分（0~100，各分项截面分位按符号等权）+ 5×5 热力图 + 形态日期级胜率；全部为 **t+1 收盘建仓**的可执行口径，统计产物离线构建（`build_flow_predictive.py`）。个股详情卡新增「之后 5 日涨跌」紫色虚线（仅历史回看）。

# 方法论 — 回测偏差审计

> 移植改写自 quantskills/skill-backtesting-bias-avoidance（GitHub license 元数据 NOASSERTION；仓库内
> LICENSE 为截断的 GPL-3.0 声明文本）。**仅方法论改写，未复制源代码**；数据层由在线行情改为本地 QuantDB。
> 统计工具沿用公开文献：Lo (2002) 夏普 HAC 显著性、Bailey & López de Prado (2014) CSCV/PBO 与
> Deflated Sharpe、Newey-West (1987/1994) 长期方差与自动带宽。仅限本地研究。

## 核心原则

1. **默认假设优势是假的**，直到它扛过「无前视 + 样本外 + 扣费后」的检验。回测最容易骗人的三件事：
   忘了滞后一个 bar、用了幸存者清洗过的标的池、在几百次试验里挑了最好的参数。
2. **把「已证实的问题」与「缺失证据」分开报告**：算不出来的检验如实标注，不得以「没查出问题」冒充通过。
3. **头条数字只有一个口径**：样本外 · 扣费后 · 无前视。样本内/毛/含泄漏的数字只允许作为对照出现。
4. **措辞纪律**：样本外不显著时写「无显著净边际」，**不写「策略无效」**——前者是数据支持的结论，后者是过度解读。

## 判定流水线（按顺序执行）

1. 冻结设定：标的/标的池、信号规则、窗口、训练/测试切分、成本假设。缺哪个问哪个。
2. 无前视引擎复算（见下表检查项），决策/执行滞后一律默认 1 个 bar。
3. 前视量化：同一信号跑「干净（滞后）」与「泄漏（不滞后）」两个版本，报毛口径夏普差。
4. 样本外切分：按时间顺序，末尾 ~30% 严格留出，**永不在测试窗上调参**。
5. 过拟合：CSCV→PBO（多路径划分）+ DSR（多重检验校正），**不靠单次切分下结论**。
6. 成本敏感性：线性成本扫描 + 平方根律冲击，报净口径与穿零成本；毛/净并排。
7. 走查（walk-forward）：锚定或滚动，每期只用当期之前的数据选参，拼接样本外结果。
8. 组装报告：已验证结论 / 缺失证据 / 局限，逐条带触发规则与数值证据。

## 引擎构建规则（前视检查表）

| # | 检查项 | 反例（会造假业绩的写法） | 正确写法 |
|---|---|---|---|
| 1 | 决策→执行滞后 | `pnl_t = position_t · return_t` | `pnl_t = position_{t-1} · return_t`；信号在 t 收盘已知，最早 t+1 成交 |
| 2 | 只用历史信息 | 滚动统计居中（`center=True`）、全样本标准化/分位 | 尾随窗口、扩展窗口，时间戳 ≤ t |
| 3 | 不用决策价成交 | 用产生信号的那根 bar 的收盘价成交且不声明 | 假定下一 bar 成交并明说 |
| 4 | 时点对齐（PIT） | 用重述后的财务、今天的成分股名单回溯 | 公告日+1 可用；成分/财务为当时可见版本 |
| 5 | 成本落在换手上 | 只在开仓收一次费、忽略平仓与冲击 | `cost_t = 线性×|Δw_t| + 冲击×|Δw_t|^1.5`，逐 bar 计 |
| 6 | 标的池无幸存者 | 只回测今天还活着的股票 | 纳入退市/破产标的；指数级演示不受此影响（点位为当时发布值） |

## 统计口径（公式）

- 策略净收益：`r_t = position_{t-1} · ret_t − cost_t`。
- **HAC 夏普显著性（Lo 2002）**：长期方差 `S = γ0 + 2·Σ_{k=1..L}(1−k/(L+1))·γk`（Bartlett 核），
  `SE(μ)=√(S/T)`，`t = μ/SE(μ)`；报**方差膨胀因子 `vif = S/γ0`** 与有效样本 `N_eff = T/vif`
  （vif<1 时 N_eff>T，属正常，翻仓亏损会带来负自相关）。带宽 L 默认取信号视野（本工具=选中慢线窗口），
  上限 T/3。**CI 含 0 = 无显著净边际**。
- **按下注口径**：把日损益按「持仓段」（连续同仓位的最大段）聚成每段一个观测，报段数 n、t 与 95%CI。
  日频样本量会高估独立信息量；两个口径并报、孰宽为准。
- **PBO（CSCV，Bailey & López de Prado）**：T×N 试验收益矩阵按行分 S 块，取 S/2 块为 IS 的所有
  `C(S,S/2)` 种组合；每次在 IS 挑最优，看它 OOS 的排名分位 `w = rank/(N+1)`，取 logit
  `λ = ln(w/(1−w))`；**PBO = λ≤0 的比例**（IS 最优在 OOS 落到后半的概率）。≈常或 >50% 说明选择由过拟合驱动。
  自助 CI 因划分重叠而偏窄，仅作参考。
- **DSR（Deflated Sharpe，Bailey & López de Prado 2014）**：`SR0` 为 N 次试验下零假设最大夏普期望
  `√V·((1−γ)·Φ⁻¹(1−1/N) + γ·Φ⁻¹(1−1/(N·e)))`（γ=欧拉常数，V=各试验 SR 的方差）；
  `DSR = Φ((SR−SR0)·√(T−1) / √(1 − skew·SR + (kurt−1)/4·SR²))`（SR 为单期口径）。
  **DSR<95% 即多重检验后不显著**。DSR 是**乐观上界**：试验数只含显式扫描的网格，
  成本/带宽/多空规则等研究自由度不在内。
- 年化：均值×252（算术）；同时报 Sortino、最大回撤、Calmar、胜率、换手、下注数。

## 成本 / 冲击

- 线性项=佣金+价差（A股撮合口径默认万3 单边，`--cost-bps 3`）；冲击项=`0.0005×|Δw|^1.5`（平方根律的
  风格化近似，**无 ADV/盘口数据，不随规模变化**，`--impact 0` 可关）。
- 输出成本扫描（0/1/2/3/5/10bp）与**穿零成本**：优势完全被成本吃光（毛>0 而净≤0）是高风险发现。
- 冲击系数与现实偏离会同时改变净夏普与穿零点，改变假设必须重跑并保留两版。

## 样本外与走查纪律

- 切分必须按时间（末尾留出），绝不随机打乱；测试窗只碰一次。
- 走查为锚定式：第 Y 年用「<Y 的全部数据」选参，只在第 Y 年验证，逐年拼接。单窗口/单次切分**不构成**稳健性证据。
- 参数扫描必须披露试验数（本工具自动记录网格列数；真实研究还应把成本/带宽/多空规则的尝试计入）。

## 审计阈值（默认，可覆盖）

| 级别 | 触发 |
|---|---|
| 高 | PBO > 50%（IS 最优在 OOS 落到后半的概率过半） |
| 高 | DSR < 95%（多重检验校正后不显著） |
| 高 | 毛夏普>0 且净夏普≤0（优势被成本吃光） |
| 高 | 前视虚高 >0.5（泄漏夏普显著高于干净夏普） |
| 中 | 样本外 HAC 95%CI 含 0（无显著净边际） |
| 中 | 独立下注 <35 笔或 N_eff <60（有效样本不足） |
| 中 | 25% < PBO ≤ 50%（中等过拟合风险） |
| 中 | 穿零成本 < 头条成本的 2 倍（对成本假设高度敏感） |
| 缺失证据 | 幸存者/PIT 未核；input 模式无法量化前视；无日期无法走查；矩阵过小无法算 PBO/DSR |

## 报告纪律（组装人读版时）

- 头条=样本外·扣费后·无前视的夏普 + HAC t + 95%CI + N_eff + 下注数；毛/样本内/泄漏只作对照。
- 每个审计标志必须**同行给规则与数值证据**；结尾附方法附录表（阶段/方法/窗口/结果）与免责声明。
- 不要用「买入/卖出」话术；PBO 低不等于策略好（它只度量选择的稳定性）。

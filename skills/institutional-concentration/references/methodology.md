# 研究门禁 · 证据台账 · 时点纪律（本地化改写）

来源：quantskills/skill-hk-us-institutional-concentration（源仓库许可为空/未声明）。
本文件保留其方法论骨架（研究门禁 10 条、证据台账 7 门、结构三分解读、阈值敏感性、
时点可用性纪律、13F 45 天滞后），改写为以 HK CCASS 为主市场、QuantDB 本地数据为源的版本。

## 研究门禁（先于任何排名/结论）

计算、排名或解释持股结构之前，逐条完成并记入证据台账（静默假设不算完成检查）：

1. 确认市场、样本池、观察日期、持有人定义、用途（单票查询可只留内部台账，但每个失败项必须显式说出）。
2. 确认每个数值是**当日快照**还是**带日期观测**；对历史用途只允许带日期观测。
3. 报告样本数、非空覆盖、缺失与重复、席位深度（CCASS 顶层为 50 席位）与源数据异常计数。
4. 检查百分比标度（0-1 还是 0-100）、HHI 值域、最大席位份额、top 系列一致性（top1 ≤ top5 ≤ top10 ≤ 广度）。
5. 把**参与广度**与**头部主导**与**证据置信度**分开表述，不得合成单一好坏分。
6. `data_anomaly` 与 `insufficient_data` 是**不可排名**状态，不是低风险。
7. 若要求业绩验证：必须有真实带日期的持股观测先于每个收益窗口；否则明说不成立（本技能输出截面诊断，不是伪回测）。
8. 至少用两套主导性/HHI 阈值复判分类，列出翻转的标的（阈值是透明筛选规则，不是经济规律）。
9. 排名前先看最大指标分歧样本，例如「广度很高但 top10 很低」。
10. 区分"观察到的结构 / 数据置信度 / 经济解释 / 收益主张"四层，不得越层。

## 证据台账（报告必须带全部行）

| 门 | 需要的证据 | 失败动作 |
|---|---|---|
| scope | 市场、样本池、日期、持有人定义 | 明说假设 |
| semantics | 数据源、单位（股数/百分比、标度）、快照/报告日期 | 停止历史主张 |
| coverage | 返回标的、缺失、重复、席位深度 | 降置信度 |
| structure | 广度、top1/top5/top10、HHI、差距 | 不得用单一标签下结论 |
| anomalies | 越界百分比与 HHI | 标为不可排名 |
| sensitivity | 两套阈值复判 | 报告标签不稳定 |
| interpretation | 观察 vs 假设 vs 预测 | 修订结论 |

## 结构三分解读（本地标签 ↔ 源标签）

| 本地标签 | 源标签 | 含义 |
|---|---|---|
| `broad_participation` | `broad_institutional` | 广度高（CCASS 前 50 席位合计 ≥50%）且无头部主导 |
| `dominant_seat` | `dominant_holder` | 头部席位份额 ≥20% 或 HHI ≥0.10 |
| `fragmented_or_mixed` | 同名 | 各指标混合，既不广布也不主导 |
| `data_anomaly` | 同名 | 源指标越界，不可排名 |
| `insufficient_data` | 同名 | 证据不足，不可高置信度排名 |

本地化改名原因：CCASS 参与者是托管行/券商/结算通道（含香港中央结算、中国结算南向通道），
**头部席位 = 托管集中，不是实益持有人主导**；"institutional" 一词在 CCASS 语境下会过度承诺，
故降级为"参与/席位"表述。经济解释必须建立在"托管集中"语义上。

## 时点可用性纪律（本技能最重要的防前视规则）

- **HK CCASS 是带日期观测**（每日披露），不是"只有当前快照"，因此可以用于历史截面对比；
  但时点联结必须用 **可得日 = 分区日 T + 1 交易日**（保守口径，脚本在面板 CSV 里给出
  `availability_date` 列）。不得用 T 日数据在 T 日做决策。
- **US 13F：期末 + 45 个日历日 = 可得日**（`availability_date = source_period_end + 45 calendar days`）。
  13F 报告期末不是公开可得日；历史联结、IC 检验、远期收益度量一律用可得日。本地无 13F 数据源，
  该知识点保留备将来接入——接入时同样**不得**把当前快照向历史回填。
- 任何"当前快照复制到过去"的做法都会制造假 IC / 假权益曲线；源技能对此设为硬性禁令，本地沿袭。

## 发行人与上市地去重（本地口径）

- 源技能规则：ADR 与其本地普通股是同一经济发行人的两个上市地，有稳定标识（issuer_id / isin）时
  只保留一个代表上市地（优先级：明确主上市 > 本地普通股 > 证据覆盖更高 > 市场+代码确定性排序），
  并把剔除行写入 `issuer_dedup_exclusions.csv`。
- 本地映射：A/H 两地上市（`quanthk/2_base_sector/ah_membership.parquet`，h_symbol/a_symbol）
  是**同一发行人的不同股份类别**（A 股与 H 股不可互换），CCASS 指标本身就是按上市证券计量，
  **不得跨市场加总 A+H 当作一个集中度**；做发行人级敞口合并时才用 ah_membership 建 issuer_key，
  且要保留"两类股份不可互换"的注记。
- CCASS 面板天然按上市证券一行，不存在 ADR 重复计数问题；去重规则只对自备 CSV 混入跨市场数据时适用。

## 局限（如实声明）

- CCASS 前 50 席位只是托管视图：非 CCASS 登记股份与 50 名以外席位不可见，广度与 HHI 是**下界口径**。
- 席位份额混合机构、零售（经券商名义持有）、结算通道，无法从本数据区分。
- 阈值分类是透明筛选规则，不是普适经济规律；跨市场/跨窗口比较前先对齐口径。
- 本技能只做数据诊断与结构描述，不输出收益预测或交易信号。

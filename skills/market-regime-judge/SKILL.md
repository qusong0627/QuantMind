# market-regime-judge — 市场阶段综合判断

把“长期 / 估值 / 顶风险 / 中期 / 短期 / 盘中”分开看，再合成一个**可对账**的判断：
**长期定基础暴露，估值定赔率，顶风险定减仓，中期定倾斜，短期/盘中只定执行。**
所有参数来自 2016-2026 本地数据实测；没验证的标“待验证”，不混进评分。

> 本技能只做概率与风险描述，不构成投资建议。收益均未扣费，等权/指数口径见各节。

## ⚙️ 运行环境

- 宿主：`/usr/bin/python3`（有 pandas/duckdb/numpy；**无 scipy**，脚本已避免依赖）。
- 容器：`docker exec -w /app quantmind python3 -m backend.scripts.<name>`（`/data/quantdb` 为完整数据）。
- 脚本只用本地 parquet，不依赖外部 API；MCP 数据缺口见 §4。

## 1. 数据源与口径（先锁死）

| 数据 | 路径 | 口径 |
|---|---|---|
| 后复权日线 | `1_kline_data/daily_backward/dt=*/data.parquet` | 广度/涨跌用后复权 close，避免除权伪跌 |
| 未复权日线 | `1_kline_data/daily_unadjusted/` | 盘中 10:10 价格与昨收、当日收盘 |
| 指数日线 | `1_kline_data/index_daily/` | 000001.SH / 000300.SH / 000852.SH |
| 分钟线 | `1_kline_data/l2_min1/dt=*/data.parquet` | 2017-2026，全市场 1 分钟，10:10 快照 |
| 估值 | `5_technical_derived/valuation/dt=*/data.parquet` | 逐票 PE/PB/市值/净资产；**PE 覆盖 2018 起 ~99%** |
| 两融 | `5_technical_derived/margin/panel_market.parquet` | T+1 披露；`fin_chg20`/`fin_bal_pct` |
| 板块情绪 | `5_technical_derived/margin/panel_sector_sentiment.parquet` | 128 个行业，`mom1` 为行业日收益 |
| 广度面板 | `5_technical_derived/market_breadth/trin_daily.parquet` | 2016-2026，全 A 涨跌家数/成交额/TRIN/ADL/MCL |

**口径纪律**
1. 广度涨跌一律 `close_t / close_{t-1} - 1`，后复权；盘中用 10:10 价 vs 未复权昨收。
2. TRIN = (涨家/跌家) / (涨额/跌额)；`TRIN_量` 用成交量，`TRIN_额` 用成交额。
3. `TRIN_额` 的倒数 = 人均成交额比；五个视频指标里有两个是恒等式/派生，**不是独立证据**。
4. 分位一律用滚动/扩张窗口，不用全样本分位（会泄漏未来）。
5. 事件统计用 **HAC t（滞后=预测窗口）**，`n_episodes` 是连续触发段数，不是日样本。

## 2. 五层定义与参数

### 2.1 长期（季度/半年）— 定基础暴露

| 特征 | 参数 | 实测（250 日） | 用法 |
|---|---|---|---|
| 指数 vs MA250 | 250 日简单均线 | 上方+便宜侧 上证 +9.9%/73%、沪深300 +18.8%/88%、中证1000 +15.7%/79% | 趋势过滤 |
| 250 日动量 | close / close.shift(250) − 1 | 同上；下方+贵侧 沪深300 −19.4%/0% 胜（n=125，集中） | 确认趋势 |

**2×2 表**（`market_composite_judge.py`，PB 便宜分位以 0.5 分侧）：

| 趋势 | 估值 | 250 日均值 / 胜率（上证 / 沪深300 / 中证1000） |
|---|---|---|
| 上方 | 便宜侧 >0.5 | +9.85/73.3% · +18.84/88.4% · +15.73/79.2% |
| 上方 | 贵侧 <0.5 | −0.42/47.2% · −2.13/50.6% · +3.34/60.0% |
| 下方 | 便宜侧 | +7.02/65.0% · +6.11/54.7% · +5.48/53.9% |
| 下方 | 贵侧 | −6.77/0%（n=14） · −19.42/0%（n=125） · +2.48/51.5%（n=68） |

> 下方+贵侧的 0% 胜率来自少数几段（2018/2022 类），**不能外推**；中证1000 不一致。

### 2.2 顶风险（季度）— 定“要不要减仓”

| 特征 | 参数 | 实测（上证，20 日） | 判定 |
|---|---|---|---|
| **ADL 背离** | 指数 250 日新高 **且** ADL 未新高 | **−2.01%，t −2.18，39 段**；前半 −3.28%、后半 −0.20%（衰减） | **有效（第五部分唯一通过）** |
| 成交额 HHI 前 10% | 全市场成交额 HHI 扩张分位 >0.9 | 20 日 −1.41（t −1.77）；40 日 **−3.84（t −3.60）**；后半 −0.13% | 候选/衰减，只作 40 日风险提示 |
| 前 10 只成交占比前 10% | top10 share 扩张分位 >0.9 | 40 日 −3.13（t −2.99）；后半 +0.72% | 不稳，不建议单独用 |

### 2.3 估值 / 底部（季度）

| 特征 | 参数 | 实测 | 用法 |
|---|---|---|---|
| PB 便宜分位 | PB = Σ总市值/Σ净资产；滚动 3 年（756 日，至少 500）分位 | 便宜前 20% → 250 日 +8.1/+10.3/+8.1%；最贵 20% → −3.5/−10.6/+0.9% | 定赔率 |
| 底部组合 | PB 便宜分位 >0.8 **且** 5 日涨家均值 <25% | 20 日 +8.4/+8.2/+14.0%，60 日 +9.3/+9.5/+13.8%，胜率 93-100%；**仅 7 段** | 底部区域标记，不是当日扳机 |
| TRIN_量 >2 | 成交量版 TRIN 上尾 | 20 日 +1.42/+1.16/+4.01%，t 2.70/2.00/4.10，70 段 | 投降确认，反抽加仓 |
| ERP | EP − 10Y 国债 | **待接数据**：本地无 10Y 历史，MCP 只有当日曲线 | 未纳入 |

### 2.4 中期（2-6 周）— 定倾斜

| 特征 | 参数 | 实测 | 用法 |
|---|---|---|---|
| 站上 MA60 占比 | 全 A close > MA60 的比例 | 作为 regime 分层有效；单用作见顶不显著 | 倾斜 |
| ADL20 斜率 | (ADL_t − ADL_{t−20}) / n_total | 趋势/拐点描述；案例回放能分顶与延续，但全样本不显著 | 倾斜 |
| 额价差 >20pp | 涨额占比 − 涨家占比 | 40 日 −1.6~−2.5pp，t −2.4~−3.1，89 段；控制动量后不衰减 | 40 日风险状态，收紧止损 |

### 2.5 短期（1-5 日）

| 特征 | 参数 | 实测 | 用法 |
|---|---|---|---|
| 收盘涨家 <15% | 全 A 涨/跌家数 | 次日 +0.13%~+0.22%，20 日 +0.85%~+1.50% | 超卖反抽候选 |
| 收盘涨家 >80% | 同上 | 20 日 +0.88%~+1.58% | 强势延续 |

> 广度**不能做隔夜多头**：隔夜腿长期为负，只能当风险闸（低广度回避）。

### 2.6 盘中（当日）— 定执行

| 特征 | 参数 | 实测（10:10→收盘，等权） | 用法 |
|---|---|---|---|
| 10:10 广度 | 涨/跌家数，vs 昨收 | <30% → **−0.20%**（t −2.62）；>60% → **+0.245%**（t 4.56） | 定基调 |
| 10:10 广度 + MA250 | 上证在 MA250 上方 | >60% → +0.27%（t 4.74），次日 +0.24%（t 2.20） | 强上加强 |
| MCL 5 日变化 | EMA19−EMA39 的 5 日变化 | 扩张 +0.16%（t 4.23）；收缩 −0.08%（t −2.01）；弱广度+收缩 −0.236%（t −2.78） | 动能确认 |
| 30-60% | 中性区 | 无方向；视频的 39% 就在这里 | 不动作 |

### 2.7 个股层（强广度日）

| 特征 | 参数 | 实测（10:10→收盘） | 用法 |
|---|---|---|---|
| 10:10 相对强弱 | 当日横截面五档（Q1 最弱 … Q5 最强） | ≥70% 桶：Q1 +0.41%/59.1% 涨，Q5 +0.20%/50.9%（剔除 ±9% 后仍成立） | **买强市里的落后票，不追最强** |
| 弱广度日 | 10:10 广度 <30% | 约 56% 个股午后继续跌 | 不接飞刀 |

### 2.8 指标数量 ≠ 独立维度（机构“20 个指标”怎么处理）

21 个市场级指标（2018-2026）PCA：**解释 80% 方差只需 6 个主成分，N_eff=6.4**；前三个主成分占 61.9%。高相关对：

| 指标对 | 相关 |
|---|---|
| 涨家占比 / 上涨板块占比 | 0.98 |
| 成交额HHI / 前10只成交占比 | 0.95 |
| 距离MA250 / 距250日高 | 0.89 |
| PB便宜分位 / EP | 0.87 |
| 5日涨家 / MCL | 0.84 |
| 站上MA20 / ADL20斜率 | 0.81 |
| TRIN_量 / TRIN_额 | 0.78 |

**结论：20 个指标不是 20 个独立下注，实际约 6 个 block。** 组合应在 block 层做（块内均值/第一主成分，块间等权或风险平价），不要 20 个指标等权相加。机构保留 20 个，是为了**不同状态的覆盖与数据容错**，不是 20 票独立验证。

## 3. 综合评分规则

### 3.1 基础暴露

```
exposure = 0.5
if 指数 > MA250 and 250日动量 > 0: exposure += 0.2
if 指数 < MA250 and 250日动量 < 0: exposure -= 0.2
if PB便宜分位 > 0.8: exposure += 0.2
elif PB便宜分位 < 0.2: exposure -= 0.2
exposure = clip(exposure, 0.2, 1.0)
```

### 3.2 中期倾斜

```
if 站上MA60 > 50% and ADL20 > 0: tilt += 0.1
if 站上MA60 < 30% or ADL20 < 0:  tilt -= 0.1
if TRIN_量 > 2 or 底部组合触发:   tilt += 0.1
```

### 3.3 顶风险减仓（不改趋势判断）

```
if 指数250日新高 and not ADL新高: 减仓/收紧止损（20日 −2.0%，t −2.18）
if 成交额HHI前10%: 40日风险提示（−3.8%，t −3.6，但后半衰减）
```

### 3.4 短期/盘中执行（不改基础暴露）

```
if 10:10广度 > 60 and MCL5日变化 > 0: 允许加仓/持有到收盘
if 10:10广度 < 30 and MCL5日变化 < 0: 不买/减仓
else: 中性，只做个股
收盘涨家 <15%: 超卖反抽候选（只做短）
收盘涨家 >80%: 强势延续（不提前卖）
```

### 3.5 个股选择

```
强广度日（10:10 >60）：优先 Q1-Q2（早盘落后），不追 Q5
弱广度日（10:10 <30）：不接飞刀
用板块/新闻/财务过滤“该弱”的票
```

### 3.6 风险闸

```
额价差 >20pp: 40日风险偏高，收紧止损/降暴露
路径确认（11:30>50 或 14:00<50）只用于管理仓位：
  低点确认时 88% 的低点已过；高点确认时 96% 的高点已过
```

## 5. 案例回放：同形态为什么一个见顶、一个继续涨

| 日期 | vsMA250 | 250日动量 | PB便宜分位 | 站上MA60 | ADL20 | ADL10日变化 | 后20日 |
|---|---|---|---|---|---|---|---|
| 2021-09-09（博主日） | +6.8% | +8.3% | 0.045 | 68.3% | +79.5 | **−34.5** | **−3.38%** |
| 2025-07-23 | +10.5% | +20.6% | 0.128 | 85.4% | +108.4 | **+57.9** | **+5.13%** |
| 2025-08-12 | +11.7% | +24.7% | 0.086 | 86.7% | +179.5 | **+66.4** | **+3.86%** |
| 2026-03-02 | +13.5% | +25.8% | 0.001 | 59.8% | −135.2 | **−89.2** | **−6.20%** |

**读法**
- 四个案例都贵，估值本身分不出顶与继续涨；
- 差异在**中期广度趋势（ADL20 十日变化）**：转负 → 顶部风险；改善 → 背离是噪声；
- 但该复合条件全样本 n=102、20 日 +0.14%（t 0.23），**只能解释案例，不能当规则**。

**2021-09-09 的 10:10 vs 收盘**：博主读数 39.34%/TRIN 0.34/额价差 +26.09pp；收盘收敛为 45.84%/0.64/+10.33pp，指数收在日内最高附近。**10:10 快照会高估背离**，必须用收盘复核。

## 6. 工作流

1. **锁数据日期**：各层日期是否一致；盘中层可能是热集/前一日。
2. **长期**：指数 vs MA250、250 日动量 → 方向。
3. **估值**：PB 便宜分位 → 便宜/中位/贵。
4. **顶风险**：指数 250 日新高且 ADL 未新高？HHI 前 10%？
5. **中期**：站上 MA60、ADL20 斜率、TRIN_量 → 倾斜。
6. **短期**：收盘涨家 → 超卖/中性/强势。
7. **盘中**：10:10 广度、MCL5 → 当日执行。
8. **合成**：基础暴露 + 倾斜；短期/盘中只定时点。
9. **写结论**：给区间、触发条件、失效条件；不写单点预测。
10. **归档**：报告落 `market_breadth/*.md`；负结果也归档。

## 8. 陷阱与纪律

1. **10:10 快照 ≠ 全天结构**：2021-09-09 的 39.34%/0.34/+26pp 到收盘变成 45.84%/0.64/+10.33pp。必须收盘复核。
2. **五个视频指标不是五个证据**：`TRIN_额 = 1/TRIN`；额价差 = f(广度, TRIN)；五指标合取 n=136、剩余收益 +0.01%（t 0.13）。
3. **量价差（成交量口径）弱**：>20pp 仅 5 日 −0.55%（t −1.47），不要单独用。
4. **路径确认是滞后**：低点确认时 88% 已过、高点确认时 96% 已过；只管理仓位。
5. **隔夜腿长期为负**：广度不能做隔夜多头，只能当风险闸。
6. **重叠样本**：日频 20/40 日收益必须用 HAC t；`n_episodes` 不是 `n_days`。
7. **小样本**：底部组合只有 7 段、HHI 后半衰减、下方+贵侧 n=14；标“样本不足”，不要重仓外推。
8. **复权/口径**：广度用后复权；盘中用未复权昨收；估值是市值加权全市场，不是指数成分股。
9. **成本**：所有收益未扣费；0.2-0.4pp 的盘中效应可能被价差/冲击吃掉。
10. **数据缺口**：ERP/期权 IV/北向/开户未接；不要用“存量/增量资金”叙事替代数据。

### 9.1b 指数口径（universe）

`/regime` 与 `/regime/sector-stocks` 都接受 `universe`，**默认 `ALL`（全A等权）**。
切换后以下全部按该指数成分股重算：

- 广度（涨家/跌家、站上 MA20/60）、ADL/MCL、TRIN_量/额、成交集中度；
- 估值（成分股 Σ净资产/Σ市值、EP，滚动 3 年分位）；
- 板块热力图与板块个股（只保留该指数成分股）；
- 盘中 10:10 广度（用该日快照过滤成分股；无快照则 `available=false`）。

| `ALL` | 全A等权 | 全部 A 股，无筛选 |

| `399001.SZ` | 深证成指 | 全部深市 A 股（近似） |

| `000300.SH` | 沪深300 | 当前成分 |

| `000905.SH` | 中证500 | 当前成分 |

| `000016.SH` | 上证50 | 当前成分 |

**口径边界**：成分股权重是**当前快照**，不是 PIT；历史回看有幸存者偏差，

散点几乎看不出分布）。当前点仍按所选日期单独绘制。

### 9.2c 喂给交易 Agent（收盘 vs 盘中）

- **收盘快照**：`backend/scripts/market_regime_snapshot.py --date YYYY-MM-DD` → `/data/market-analysis/regime/{date}.json`（ALL 另写 `latest.json`）。Celery `engine.tasks.market_regime_snapshot` 在交易日 23:30 与次日 06:30 各跑一次（06:30 补赚钱效应/炸板率，赶在 08:30 首轮交易前）。
- **研究总控**：`research_control.dossier.collect_market` 收盘/夜间档自动 `ensure_snapshot`，把 `render_stage_text`（六块/五层/事件/情绪/Q1–Q5/板块）拼进「市场与资金」事实包；缺失如实写数据缺口。
- **交易 Agent**：`decision_round_io.load_market_stage` 只读最近一份收盘快照；`build_market_state_block` 前置【上一交易日市场阶段·参考】，再拼实时 `qm:regime:intraday`。实时快照超过 **120 分钟**直接降级为「本轮无实时快照」——盘前 08:30/09:00 不会把上周五 15:09 的旧状态当周一当前状态。
- **纪律**：六块/估值/额价差/ADL 等日频指标只在收盘快照里；盘中只认 `qm:regime:intraday` 的实时 state/仓位/指数/广度。两者都带日期/时点，不混用。

### 9.2d 盘中提示词升级（2026-11-14）

- **10:15 新槽**：10:10 全市场快照刚出，给一次盘中决策窗口；原 10:00/10:05 等槽位一个不删。`decision_round_core.SLOTS`。
- **今日 10:10 块**：`shared/intraday_1010.py` → 广度、MCL5（日频，最近交易日）、Q1–Q5 中位；全市场快照缺失回退 L0.5 热集并明确标“非全市场”。10:10 之前整段不出现。
- **槽位守则**：`shared/decision_slot_playbook.py` → 每槽任务、本轮新开预算、阶段（防守默认 0）、失效/退出、历史负向（首板/连板次日高开、弱广度接飞刀不做）；只追加不删减。
- **14:45**：0 新开；14:50 后只限价；弱票收盘卖、强票才留隔夜；写次日卖点/止损。
- **数据缺口**：`intraday_snapshot_1010.parquet` / `intraday_path_panel.parquet` 目前止于 2026-11-10，10:10 块走 L0.5 热集（约 590 只）；要全市场精度需恢复 10:10 快照产出。

### 9.2e 交易 Agent 执行层升级（2026-11-14，P0–P2）

- **风险定额（P0）**：`BuyGate.risk_budget_per_trade = quota × 0.4%`（20 万≈¥800）；`check_buy` 按 `qty × (现价 − stop_loss)` 夹取 `pct`，超预算**缩小而不是拒单**；缺 `stop_loss` 留 note「风险预算未判」并在提示词要求必填。
- **信号期限（P0）**：`build_signal_meta_block` 明确「模型分是 T+5/T+10 截面分位，不是 T+1 方向；T+1 买入必须有板块/量价/L2 第二腿」。
- **上轮状态（P1）**：`_decision_line` 带「已报 order_id/待确认」或「被拒：price_drift/inflight_dup」；一致性规则要求同一代码不得原价重提。
- **同码拥挤（P1）**：`build_cross_agent_block` 对 2 家以上最新买卖同码加「同码拥挤」提示，要求新增证据、最多再加 1 家。
- **12:00（P2）**：`run_exec` 在 12:00 传 `gate=None` → 买入腿 noop，卖出/守护照常；不再浪费午休买单。
- **Agent 反馈（P2）**：`shared/decision_feedback.py` + `feeds.agent_feedback` 读最近 5 笔平仓，提示词显示胜率/平均收益/平均持有；连续低胜率提醒减少低质量交易（样本 <3 不写结论）。
- **决策账定价（P2 数据面，2026-11-14 补齐）**：`qm_decision_ledger` 的 `entry_px`/`fwd`（t1/t5/t20/t60）由**另一条作业**回填（`backend/scripts/decision_ledger.py scorecard`），不是决策轮写；此前没人跑，1682 行只有 162 行带价。现由 Celery `decision-ledger-scorecard`（交易日 07:10）每日兜底，窗口 40 天、已定价行重算（t20/t60 晚到才补得上）、`price_row_monotone` 只升不降。**大批量回填必须切块**：asyncpg 单语句 32767 参数，本表 36 列 ≈ 910 行即撞线（`_UPSERT_BATCH=200`）。记分卡 `report --days 40` 按 agent × 类别 × 形态标签出 T+1/5/20/60 胜率与超额。
- **仍待补（P2 数据面）**：全市场 10:10 快照产出停更（上游 `l2_min1` 分钟分区块止于 2026-11-10，`intraday_1010` 只能回退 L0.5 热集）；跨 agent 硬性同码持仓上限（当前仅提示，硬上限需账户级策略）。

### 9.3 验收

1. `cd electron && npm run typecheck` 通过。
2. `curl` 端点：`date`、5 层、`charts.dates` 最后一天 = 返回 `date`。
3. 日期切换：每张图最后日期跟随；无盘中数据的日期显示“该日期无盘中数据”。
4. 颜色口径：绿=顺/可做，黄=中性，橙=偏弱/防守，红=逆/不做。
5. 文案只写“位置/阶段/动作”，不写买卖指令（执行面另放）。
6. 联动：点板块热力图 → `/regime/sector-stocks` 返回该板块个股，条形图更新；点条形 → 现有股票终端打开。
7. 总结一致：`summary.score = Σ blocks.score`；雷达、评分条、状态卡三处数值一致。
8. 多指数对比：6 行、压力分/分位/T+5·10·20；点行切换主面板；首次计算 20-30 秒后可缓存。
9. 2×2 散点：2018 起、隔日取样，点数 >500（实际约 900）；若只剩 ~30 点，说明误用了 560 日面板窗口。
10. 雷达卡片：六边形居中放大（radius 80%、无图例），六块评分标签固定在卡片底部 3×2 网格。

# market-sentiment-dashboard — 市场情绪温度报告

## 报告结构（脚本输出即此结构）

```
【盘面状态】时段 / 大盘三态（强/震荡/弱）+ 量能 + 位置 + 动作基调 —— 系统判定
【情绪温度】quantdb 昨日收盘全景：上涨/下跌家数、涨跌比、动量均值、买/卖压力
【实时温度提示】盘中用什么信号（量比/失衡/涨速，术语与本系统分析提示词一致）、
   明确不用的（昨日温度、未验证家数）
【解读】AI 基于上面事实写：今日情绪状态一句话 + 对次日操作的 2-3 条含义
```

## 使用方法

```bash
python3 dsh/skills/market-sentiment-dashboard/scripts/market_sentiment_dashboard.py
```

输出 JSON 三节事实，AI 据此生成 Markdown 报告；如需落盘写
`/data/reports/trading_agents/市场情绪/当日日期.md`。

## 口径纪律（与系统分析提示词同一套提纯原则）

- 温度计读数（短事实、每次要）→ 提示词确定性注入（系统已在做：盘面状态块）；
  本技能是**完整报告形态**（给人看的仪表盘），两者不冲突。
- 数据自校验：quantdb 全景若涨跌覆盖 <80% 或极端值占比过高 → 标注"数据缺失"，如实降级。
- 盘后温度 ≠ 今日盘中温度：标注清楚，防止误读。

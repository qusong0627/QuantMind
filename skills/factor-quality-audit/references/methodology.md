# 方法论 — 五道检查与裁决逻辑

本技能是「质检裁决」：给定一个因子面板（date, symbol, factor, fwd_ret），按固定顺序执行五道检查，输出四类裁决之一。不构造因子、不调参、不做衰减曲线（那是 `factor-ic-decay` 的职责）、不给出交易指令。

## 检查顺序与判据总览

| # | 检查 | 判据 | 默认阈值 | 不通过的动作 |
|---|---|---|---|---|
| ① | 票池构造 | 截面宽度、覆盖、停牌/零成交、ST、上市天数、事后选池披露 | 宽度中位 <30 降级说明；停牌/零成交 >5% 降级 | 记入 findings / status=partial（不单独出裁决） |
| ② | 时点对齐（PIT） | 同日口径 IC vs 次日执行口径 IC 的保留率 | 保留 ≥0.70 通过；0.30~0.70 降置信；<0.30 降两档 | alpha 降置信 + 保留意见 |
| ③ | IC/IR 简版 | 均值 IC、ICIR（raw/年化）、Newey-West t、方向命中率、分段方向 | \|NW-t\| ≥2.0，或 ≥1.5 且 \|IC\| ≥0.02；\|IC\| <0.005 直接判噪声 | **样本幻觉**（见决策顺序 ③） |
| ④ | 换手与成本 | 可执行端（方向感知）毛超额、日换手、扣费净额、盈亏平衡单边成本 | 单边 3 bp（撮合保守口径）；毛≤0 或净≤0 → 降置信 + 保留意见 | alpha 降置信 |
| ⑤ | 中性化残差 | 行业+规模 FWL 扣除后的 IC 保留率 | 保留 <0.30 → 行业暴露；<0.15 置信高 | **行业暴露**（见决策顺序 ④） |

## 统计口径（公式）

- **Spearman Rank IC**：对因子值与收益各自取平均秩（并列取平均，与 scipy `rankdata(method='average')` 同口径）后算 Pearson。逐日计算，当日有效标的 <10 只跳过该日。
- **ICIR**：日均 IC / IC 标准差（raw），年化乘 `√252`。
- **Newey-West t**：对日度 IC 序列做 Bartlett 核的 HAC 标准误，lag 默认 5（`--nw-lag`），校正日度 IC 的自相关。
- **方向命中率**：日度 IC 与全样本方向一致的天数占比。
- **分段**：按时间等分 3 段，各段均值 IC 与全样本方向比对（反向段降置信）。
- **时点对齐（PIT）**：同日口径 `ret(t)=close(t+h)/close(t)−1`；次日执行口径 `ret_lag(t)=close(t+h+1)/close(t+1)−1`（信号在 t 收盘后可用、至少滞后一根可执行 bar）。保留率 = 两口径均值 IC 之比——仅当同日 \|IC\| ≥0.005 时展示（近零分母的比值无解释力，改为并列两口径 IC）。
- **中性化（FWL 两步残差）**：① 因子按行业内去均值得残差；② 对规模（`ln_mv_total`，或 `total_mv` 取自然对数）做一元回归扣除。中性 IC = 残差与收益的日度 Spearman；保留率 = 中性 IC / 原始 IC。暴露诊断：行业方差解释（组间平方和/总平方和的中位）、与规模相关的日度 Pearson 中位。
- **换手与成本**：两端各取 10% 等权（`--quantile`），日频调仓；单端换手 `1−|本期∩上期|/|上期|`；往返成本 = 换手 × 2 × 单边费率；可执行端 = 方向感知（正 IC 取高分位、负 IC 取低分位），毛超额 = 该端等权收益 − 全票池等权收益（**不做方向翻转**，负值即该端无超额）；盈亏平衡单边成本 = 毛 / (2 × 换手)；理论多空 = 方向 ×(高分位 − 低分位)，仅作强度参考（A股/港股做空受限）。

## 裁决决策顺序（先到先得）

1. **名称规则泄漏**：因子列名命中黑名单正则（`^label_return$` / `^return_\d+d$` / `^future_return_\d+d$`，不区分大小写）→ **泄漏**，置信高。名称规则不依赖数据，故意把标签传入必被抓住。
2. **数据规则泄漏**：\|均值 IC\| ≥0.90 → **泄漏**，置信高（截面排序几乎复制了未来收益）。真实因子远低于此；该规则兜移名/改名后的确定性泄漏。
3. **样本幻觉**：显著性未过线（\|NW-t\| <2.0 且不符合「≥1.5 且 \|IC\| ≥0.02」），或 \|IC\| <0.005 → **样本幻觉**；置信度：观测 ≥252 天且 \|NW-t\|<1.0 给「高」，否则「中」。附注「不等于经济逻辑上无效，可换窗口/票池重验」。
4. **行业暴露**：中性化保留率 <0.30 → **行业暴露**（保留率 <0.15 置信高，否则中）。
5. **alpha**：其余情况 → **alpha**，置信从「高」起逐项降档：
   - IC 观测 <252 天（样本偏少）；
   - 中性化未执行（行业/规模数据缺失——暴露可能性未被排除）；
   - PIT 保留 <0.70（降一档）/ <0.30（再降一档）；
   - 可执行端毛 ≤0（排序信息没落到尾部）或毛>0 但净 ≤0（成本吃掉）；
   - 存在与全样本方向相反的分段。
   固定保留意见：A股/港股做空受限（多空仅参考）、票池为窗口末日成交额事后选池（轻微选择偏差）。

## 阈值表（CLI 可覆盖）

| 常量 | 默认 | CLI | 含义 |
|---|---|---|---|
| `min_ic_obs` | 60 | —（拒绝线） | 日度 IC 观测少于此数拒绝裁决（退出码 2） |
| `warn_ic_obs` | 252 | — | 不足一年降置信 |
| `sig_t` / `sig_t_soft` / `sig_ic_soft` | 2.0 / 1.5 / 0.02 | `--sig-t` | 显著性双档判据 |
| `weak_ic` | 0.005 | — | 低于视为不可区分噪声 |
| `leak_ic` | 0.90 | `--leak-ic` | 数据规则泄漏阈值 |
| `neutral_retention` | 0.30 | `--neutral-retention` | 中性化保留率下限 |
| `pit_retention_ok` / `pit_retention_warn` | 0.70 / 0.30 | — | PIT 双档 |
| `quantile` / `cost_bp` | 0.10 / 3.0 | `--quantile` / `--cost-bp` | 分位与单边成本 |
| `nw_lag` | 5 | `--nw-lag` | Newey-West 滞后 |

## 边界（不做的事）

- 不构造/不优化因子（只裁决）；不给交易指令与仓位建议。
- 不做 IC 衰减曲线与半衰期（`factor-ic-decay`），不做组合回测与归因（`brinson-performance-attribution`）。
- 因子本身的时点正确性（只用截至当日可知信息计算）由数据生产方保证；本工具只拦标签列与两种口径的对齐衰减。
- 裁决是「现有窗口 + 现有票池」下的证据描述，不是对未来有效的预测；结论须标注窗口、观测数与票池口径。

# 通达信桥 · 渠道交易与行情接口

> 2026-10-28 ｜ 桥：`<BRIDGE_HOST>:8550`（当前 192.168.31.13）｜ 分支 `next` ｜ commit `16399a06`
>
> **原则**：桥是 Windows 侧唯一出口。行情、账户、委托/成交、下单/撤单都走 8550；
> 伴生桥 `127.0.0.1:17720` 只监听本机，外部不直连。
> **TDX 与 QMT 的接口和字段口径分开**，混合下单用 `/api/v1/orders/route` 按 `channel` 分流。

---

## 1. 鉴权与通用约定

- 所有接口（除 `/api/v1/health`、`/ui`、行情缓存只读端点）都要：
  ```
  Authorization: Bearer <BRIDGE_TOKEN>
  ```
- 请求体：`Content-Type: application/json`（POST）。
- 代码统一后缀式：`600519.SH`、`002883.SZ`、`510300.SH`、`920950.BJ`。
- 渠道专用接口的错误信封：
  ```json
  {"success": false, "channel": "qmt", "error": {"code": "...", "message": "..."}}
  ```
- 成功响应带 `channel`（`tdx` / `qmt`）和 `interface`（`tdx_tq` / `qmt_pipe`）。

## 2. 接口总表

| 能力 | 通达信 | QMT |
|---|---|---|
| 买入 | `POST /api/v1/tdx/orders/buy` | `POST /api/v1/qmt/orders/buy` |
| 卖出 | `POST /api/v1/tdx/orders/sell` | `POST /api/v1/qmt/orders/sell` |
| 撤单 | `POST /api/v1/tdx/orders/cancel` | `POST /api/v1/qmt/orders/cancel` |
| 当日委托/成交查询 | `POST /api/v1/tdx/orders/query` | `POST /api/v1/qmt/orders/query` |
| 混合路由（每笔带 channel） | `POST /api/v1/orders/route` | 同左 |
| 账户+持仓 | `POST /api/v1/account/query`（不带 source，或 `source=tdx`） | `POST /api/v1/account/query` `{"source":"qmt"}` |
| 统一行情 | `GET /api/v1/market/quote?source=tdx` | `GET /api/v1/market/quote?source=qmt` |
| 资产口径对账 | — | `GET /api/v1/qmt/reconcile` |
| 健康 | `GET /api/v1/health`（含 `tdx_connected` / `qmt`） | `GET /api/v1/qmt/health` |

兼容旧入口：`POST /api/v1/plans/execute`（TDX 批量计划）、`POST /api/v1/orders/cancel`（TDX 撤单）、`POST /api/v1/orders/query`（按 `source` 选渠道）保持不变。

## 3. 行情（走桥）

### 3.1 统一行情

```bash
curl -s "http://<BRIDGE_HOST>:8550/api/v1/market/quote?code=600519.SH&source=qmt" \
  -H "Authorization: Bearer $TOKEN"
```

- `source=qmt|tdx|ths|aidata` 等价于 `prefer=<source>`；不传 `source` 则用默认优先序（`ths > tdx`）。
- `?qmt=1` / `?aidata=1`：追加为**补缺源**（前面源有值的字段不被覆盖）。
- 返回：
  ```json
  {
    "success": true,
    "data": {
      "code": "600519.SH",
      "prefer": ["qmt"],
      "data": {"last": 1332.02, "prev_close": 1355.9, "open": 1354.98,
               "high": 1354.98, "low": 1330.17, "volume": 20047,
               "amount": 2689281300.0, "change_pct": -1.76,
               "bids": [{"level": 1, "price": 1332.01, "volume": 3}],
               "asks": [{"level": 1, "price": 1332.02, "volume": 5}]},
      "source": {"last": "qmt", "prev_close": "qmt"},
      "missing": ["inside", "outside"],
      "timings": {"qmt": {"ok": true, "ms": 12.3, "error": ""}},
      "fastest": "qmt",
      "ts": "2026-10-28T14:21:00"
    }
  }
  ```

### 3.2 原始数据 / 字段字典 / 源统计

- `GET /api/v1/market/raw?code=600519.SH&qmt=1`：TDX / THS / QMT 原始返回。
- `GET /api/v1/market/fields`：统一字段字典与各源能力。
- `GET /api/v1/market/sources`：各源调用/延迟/错误统计。

### 3.3 账户与持仓

```bash
# TDX
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/account/query \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{}'

# QMT
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/account/query \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"source":"qmt"}'
```

QMT 账户返回：
```json
{
  "account_id": "<QMT_ACCOUNT>",
  "asset": {"currency": "CNY", "balance": 23813815.55, "cash": 21626929.45,
            "asset": 23813815.55, "market_value": 2186886.10, "frozen_cash": 0.0},
  "positions": [
    {"stock_code": "002883.SZ", "stock_name": "*ST中设", "total_volume": 60000,
     "available_volume": 60000, "cost_price": 9.267, "last_price": 8.60,
     "market_value": 516000.0, "pnl": -40020.0}
  ],
  "channel_used": "qmt",
  "account_source": "qmt",
  "snapshot_at": "2026-10-28 14:18:00",
  "age_sec": 2.1,
  "stale": false,
  "snapshot_source": "snapshot"
}
```

- `stale=true`：快照过期（休市或 QMT RPC 停摆），持仓价/市值/浮盈留空，**不混当前价**；QuantMind 同步会跳过落库。
- `GET /api/v1/qmt/reconcile`：并列两套资产口径（`qmt_total_asset = cash + occupied_margin`，`live_total_asset = cash + market_value`），不改 QMT 原值。

## 4. 通达信交易接口

### 4.1 买入 / 卖出

```bash
# 买入（限价）
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/tdx/orders/buy \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"stock_code":"600519.SH","volume":100,"order_type":"limit",
       "price":1332.55,"notify":0,"plan_id":"plan-20261028-1"}'

# 卖出（市价）
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/tdx/orders/sell \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"stock_code":"600519.SH","volume":100,"order_type":"market"}'
```

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `stock_code` / `symbol` | 是 | 后缀式代码 |
| `volume` | 是 | 股数（>0） |
| `order_type` | 否 | `limit`（默认）/ `market` |
| `price` | 限价必填 | 限价价格 |
| `notify` | 否 | 0=客户端确认（默认），1=请求免确认 |
| `plan_id` | 否 | 幂等键；重复 plan_id 返回 409 `DUPLICATE_PLAN` |
| `account` / `account_type` | 否 | 默认账户 / `stock` |
| `stop_loss_pct` / `take_profit_pct` / `trailing_stop_pct` | 否 | 成交后注册止损/止盈 |

返回：
```json
{"success": true, "channel": "tdx", "interface": "tdx_tq",
 "plan_id": "plan-20261028-1", "status": "executed",
 "order": {"stock_code": "600519.SH", "side": "buy", "volume": 100,
           "order_id": "123456", "status": "filled", "message": "ok"}}
```

> TDX 单笔入口内部仍走 `TradePlan`：**卖先买后**、资金/持仓校验、plan 幂等、硬限额（299/秒、1999/日）。

### 4.2 撤单

```bash
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/tdx/orders/cancel \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"stock_code":"600519.SH","order_id":"123456"}'
```

- 撤单是减风险动作：握手失败会按当日委托终态复核（`verified=true` 表示实际已撤）。
- 超时返回 `status=unknown`，**不要当失败重试**。

### 4.3 查询

```bash
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/tdx/orders/query \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"stock_code":"600519.SH","cancelable_only":false}'
```

返回 `{orders: [...], channel_used: "tdx", interface: "tdx_tq"}`。

## 5. QMT 交易接口

> **三道写闸默认全关**，见 §7。关着时买入/卖出/撤单一律返回
> `403 QMT_ORDERS_DISABLED`，不会到 QMT。

### 5.1 买入 / 卖出

```bash
# 限价买入：client_order_id 必填（24h 幂等键）
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/qmt/orders/buy \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"symbol":"510300.SH","volume":100,"order_type":"limit",
       "price":3.50,"client_order_id":"qm-20261028-1"}'

# 市价卖出
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/qmt/orders/sell \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"symbol":"002883.SZ","volume":60000,"order_type":"market",
       "client_order_id":"qm-20261028-2"}'
```

字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `symbol` / `stock_code` | 是 | 后缀式代码 |
| `volume` | 是 | 股数（>0） |
| `order_type` | 否 | `limit`（默认）/ `market` |
| `price` | 限价必填 | 限价价格；市价忽略，发 0.0 |
| `client_order_id` | **是** | 幂等键；重复提交返回首次结果 |
| `account_id` | 否 | 默认伴生桥配置的账号 |
| `strategy_name` | 否 | 默认 `bridge` |

QMT 参数映射（桥内部）：

- `side` → `action` = `BUY` / `SELL`
- `limit` → `price_type=LIMIT`（11）；`market` → `price_type=LATEST_PRICE`（5）。
  **不要传 `MARKET`**：kit 别名表里没有，会静默落成限价。
- `client_order_id` → `remark`（幂等键）。
- 策略侧 `passorder` 的 `quickTrade=2`（免确认）；不需要在请求里传。

返回：
```json
{"success": true, "channel": "qmt", "interface": "qmt_pipe",
 "order": {"order_id": "1080000012", "order_sys_id": "1080000012",
           "client_order_id": "qm-20261028-1", "status": "SUBMITTED",
           "message": "passorder submitted"}}
```

### 5.2 撤单

```bash
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/qmt/orders/cancel \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"order_id":"1080000012","symbol":"510300.SH"}'
```

字段：`order_id` 或 `order_sys_id` 必填；`symbol` / `account_id` 可选。

### 5.3 查询

```bash
# 当日委托
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/qmt/orders/query \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" -d '{}'

# 当日成交
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/qmt/orders/query \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"kind":"trades"}'
```

返回 `{orders|trades: [...], channel_used: "qmt", source: "qmt"}`。

## 6. 混合渠道路由

一笔请求里可以同时有 TDX 和 QMT 单，按每笔的 `channel` 分流：

```bash
curl -s -X POST http://<BRIDGE_HOST>:8550/api/v1/orders/route \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{
    "plan_id": "mix-20261028-1",
    "default_channel": "tdx",
    "orders": [
      {"channel":"tdx","symbol":"600519.SH","side":"buy","volume":100,
       "order_type":"limit","price":1332.55},
      {"channel":"qmt","symbol":"002883.SZ","side":"sell","volume":100,
       "order_type":"limit","price":8.59,"client_order_id":"qm-mix-1"}
    ]
  }'
```

规则：

- TDX 组先执行（组内仍**卖先买后**，plan 幂等 + 资金/持仓校验）；QMT 逐笔走伴生桥。
- `results` 按**输入顺序**返回，每笔带 `channel` / `interface` / `success`。
- 单笔失败不影响其它笔；顶层 `success` = 所有笔都成功。
- `default_channel` 缺省 `tdx`；每笔可用 `channel` 覆盖。

返回示例：
```json
{
  "success": true,
  "plan_id": "mix-20261028-1",
  "channels": ["qmt", "tdx"],
  "results": [
    {"channel": "tdx", "interface": "tdx_tq", "success": true,
     "order": {"stock_code": "600519.SH", "order_id": "123456", "status": "filled"}},
    {"channel": "qmt", "interface": "qmt_pipe", "success": true,
     "order": {"order_id": "1080000012", "status": "SUBMITTED",
               "client_order_id": "qm-mix-1"}}
  ]
}
```

## 7. QMT 写闸与风控

QMT 下单/撤单**三道闸缺一不可**，默认全关：

| 层 | 配置 | 默认 |
|---|---|---|
| 桥 | `config.yaml` → `qmt_orders.enabled` | `false`（改后需重启 8550） |
| 伴生桥 | `bridge_config.json` → `source_http.allow_orders` | `false`（热加载） |
| QMT 策略 | `QMT_BRIDGE_V2.py` → `ALLOW_ORDER_METHODS` | `False`（改后在 QMT 内**重载策略**） |

伴生桥 `risk_gate`（写入前）：

| 项 | 默认 |
|---|---|
| ST/退名称黑名单 | `["ST","退"]` |
| 单笔金额上限 | 200,000 |
| 价格偏离（对昨收） | 5% |
| 每分钟笔数 | 30 |
| 幂等 | `client_order_id` 24h |

风控拒绝会以 `QMT_SOURCE_ERROR`（400）返回，message 形如 `risk: blacklisted name ...`。

## 8. 错误码

| code | HTTP | 含义 |
|---|---|---|
| `AUTH_FAILED` | 401 | 缺失/无效 token |
| `QMT_ORDERS_DISABLED` | 403 | 桥 QMT 写闸未开（`qmt_orders.enabled=false`） |
| `QMT_ORDER_INVALID` | 400 | QMT 下单参数非法（缺 client_order_id / 数量 / 价格等） |
| `QMT_CANCEL_INVALID` | 400 | QMT 撤单缺 order_id/order_sys_id |
| `QMT_SOURCE_ERROR` | 400 | 伴生桥/策略报错（含风控拒绝、`orders disabled on qmt source`、`ORDER_DISABLED`） |
| `QMT_SOURCE_UNAVAILABLE` | 502 | 伴生桥 17720 不可达 |
| `TDX_ORDER_INVALID` | 400 | TDX 下单参数非法 |
| `DUPLICATE_PLAN` | 409 | TDX `plan_id` 重复 |
| `TDX_UNAVAILABLE` | 502 | 通达信 17709 不可达 |
| `INVALID_ORDERS` | 400 | `/orders/route` 的 orders 为空/字段非法 |
| `INVALID_JSON` | 400 | 请求体不是 JSON |
| `METHOD_NOT_ALLOWED` | 403 | 通用 `source=qmt` 只读透传里调了写方法（下单请走专用接口） |

## 9. 网页控制台

`http://<BRIDGE_HOST>:8550/ui` → 「**渠道交易 · 下单 / 撤单**」面板：

- 选渠道 `TDX` / `QMT`、代码、买/卖、数量、限价/市价、价格、`client_order_id`；
- 「下单」调 `/api/v1/{channel}/orders/{side}`；「撤单」调 `/api/v1/{channel}/orders/cancel`；
- 结果直接显示 HTTP 状态与 JSON；QMT 闸关着会显示 `QMT_ORDERS_DISABLED`。
- 同页「QMT · 迅投账户」面板有持仓/委托/成交与「口径对账」。
